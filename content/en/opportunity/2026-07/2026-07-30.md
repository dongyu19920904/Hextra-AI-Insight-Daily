## 今日主推

### [手机也能跑 Cursor Agent 了，帮你配好省自己折腾](https://x.com/dotey/status/2082593013000245412)

Cursor 刚发布 iOS/iPad 版，很多人看到了截图就手痒，下载下来发现不知道从哪开始，环境没有、Agent 没接、自己折腾一圈搞不定就卸了。这单卖的就是这个时间窗：你先帮他们跑通，他们付你一个省事费，事情就这么简单。

同期 AsterMem 这类第三方记忆接入也在传，叠在一起的意思是：Agent 现在有了移动端 + 长期记忆两条线，买家心里的"用 AI 干活"画面感更强了，容易心动。

- 参考来源：[Cursor iOS 上线](https://x.com/dotey/status/2082593013000245412) / [AsterMem 长期记忆接入](https://x.com/op7418/status/2082397091062513738)
- 目标鱼塘：已经听说过 Cursor 但没真正跑起来的人；想用手机也能干活的内容副业新手；小老板、自由职业者
- 适合谁：不会排错、不想查英文文档、看到 iOS 版上线心动但不知道怎么开始的中文用户
- 这钱从哪来：iOS 版刚上线，很多人第一次下载，摸不到门，今天的新鲜感就是付费窗口。等一周之后热度散了，这单就难发了
- 可交付物：Cursor iOS 快速上手说明（截图版）+ 最小可用 Agent 配置示例 + 答疑一次
- 最简单卖法：私聊或朋友圈发一张截图，写"Cursor 出 iPhone 版了，帮你配好直接用，不用自己摸索"，聊进来再报价
- 最低成本验证：今晚自己先把 Cursor iOS 装上跑一遍，截三张关键步骤图，这就是你的交付物核心，也是你的发圈素材
- 今天先做哪一步：装上 App，跑通一个最小 Agent 场景，截图留存，今晚发一条朋友圈或群消息试探反应
- 今天就能发的文案：「Cursor 出了 iPhone 版，你下载了也不知道从哪开始对不对？我整理了一份快速配置说明，直接发给你，不用自己折腾。需要的来」
- 复购/升级路径：基础配置包 → 加 AsterMem 记忆接入服务 → 定制 Agent 工作流 → 月费维护答疑
- 售后边界：只交付配置说明和初始跑通指导，不承诺后续 Cursor 官方更新带来的变化；遇到账号或平台限制问题不在范围内
- 配图建议：用 Cursor 官方 iOS 发布的那张截图，或者你自己手机上跑通的实机截图，比任何说明都有说服力

## 本周可试

### [不同模型各干各擅长的活——多模型 subagent 工作流包](https://m.okjike.com/originalPosts/6a697982a561f233f233ef64)

Codepilot 那个"多模型 subagent"的玩法开始在中文圈传开了——用 Grok 搜信息、DeepSeek 写文案、GLM 统筹，不同的模型干自己最拿手的，效果好还能省钱。这件事现在还在技术圈层，普通用户看到了觉得酷，但自己配不起来。现在先不用冲，因为中文可操作教程还很少，等你先整理一版能交付的流程包，机会就来了。

- 参考来源：[Codepilot 多模型 subagent](https://m.okjike.com/originalPosts/6a697982a561f233f233ef64)
- 适合谁：有点 AI 基础、用过 Claude 或 DeepSeek、但没拼过多模型组合的副业新手和小团队
- 先怎么试：先自己把这个多模型分工流程跑一遍，用截图和流程图整理成一份中文"组合搭配清单"，先在社群里发，测有没有人问"怎么配"
- 最低成本验证：发一张多模型分工的流程图，配文"用 DeepSeek 写文案 + Grok 搜资料 + GLM 统筹，你知道怎么组合吗？"——看有没有人回"不知道，教一下"
- 为什么先别冲太猛：这个流程依赖 Codepilot 平台还不稳，中文文档几乎没有，现在全押进去容易售后解释成本很高；先测反应、积累案例，下周再出跑通包更稳
- 配图建议：用那张"Grok + DeepSeek + K3 + GLM 协作完成一个任务"的流程示意图，直观展示分工逻辑，比写一堆文字强
