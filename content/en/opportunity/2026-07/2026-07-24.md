## 今日主推

### [你不用自己排错——帮人把 Agent 跑通，今晚就能接单](https://github.com/thedotmack/claude-mem)

最近 OpenClaw 这类 Agent 工具在中文社群里开始有人问，但大多数人卡在同一件事上：不知道怎么装、装完不知道配什么、配完跑起来报错不知道去哪找答案。这不是技术问题，是"第一次折腾环境"的问题——愿意花小钱省掉这两三个小时的人，今天就有。

你要卖的不是教程，是"你来，我帮你跑通，跑完截图给你"这件事本身。入门款定个小价试水，验证有人问，再往上走代配置和持续答疑。

- 参考来源：[claude-mem](https://github.com/thedotmack/claude-mem) / [cc-switch](https://github.com/farion1231/cc-switch)
- 目标鱼塘：听说过 OpenClaw / Claude Agent，想用起来但自己配不顺的小白；程序员以外的普通用户
- 适合谁：能把 Agent 工具自己跑通一遍、能截图录屏、能用文字说清楚步骤的人
- 这钱从哪来：OpenClaw 相关工具（claude-mem、cc-switch）这两天在 GitHub 上同时有新项目跟进，说明用的人在增加；但中文社群里还没有人专门帮新手跑通——信息差在，收费空间就在。买家今天的痛点是"我想用但卡住了，不知道找谁问"
- 可交付物：代配置全流程 + 跑通截图或短录屏 + 基础答疑（限定3-5个问题，控住售后边界）
- 最简单卖法：朋友圈或社群发一条"帮你跑通 OpenClaw Agent，含配置+答疑，限3单"，私聊成交，先跑通自己再接人
- 最低成本验证：今晚自己把 claude-mem 或 cc-switch 装一遍，截一张"跑通状态"截图，配一句文案发出去，看有没有人问
- 今天先做哪一步：先自己跑通一遍，截图留存；再写一条朋友圈文案，限量3单，发出去等咨询
- 今天就能发的文案：「最近 OpenClaw Agent 有人开始用了，但安装配置这一步卡了很多人。我帮你跑通、截图交付、附基础答疑，今天限3单，私信我」
- 复购/升级路径：首单代配置 → 后续持续答疑月费 → 打包成"Agent 新手上手包"资料 → 小社群答疑服务
- 售后边界：只做安装配置跑通，不承诺长期稳定运行，不负责 Agent 的内容输出结果；工具本身更新导致的问题按次收费
- 配图建议：用 cc-switch 或 claude-mem 跑通后的界面截图，配上"装好了"的状态感；比任何介绍图都有说服力

## 本周可试

### [不会下 YouTube 视频？这个 Skill 帮你省掉每次找工具的麻烦](https://x.com/vista8/status/2080150051872276990)

这是一个反常识的组合方向：买家不是在找"下载工具"，他们是在找"一个不用每次重新找工具、不用担心失效"的稳定方案。vista8 今天分享的这个 YouTube 下载 Skill 背后逻辑是——yt-dlp 得持续跟 YouTube 对抗更新，普通人根本跟不上，这就是信息差和服务差的空间。

现在还不用重仓，因为这类工具用户群体不够聚焦，买家在哪个鱼塘里还不清晰。先发一个"帮你配好、拿来就用"的轻包，看谁在问，再决定往哪个方向深挖。

- 参考来源：[vista8 推文](https://x.com/vista8/status/2080150051872276990)
- 适合谁：自己用过 yt-dlp 但总跟不上更新的人；想帮内容创作者剪辑素材的副业新手；做 AI 工具搭配教程的卖家
- 先怎么试：把这个 Skill 自己装一遍（`npx skills add joeseesun/qiaomu-youtube-download`），录一段 30 秒内的操作视频，配一句"一键装好、持续更新、不用自己追版本"，发到内容创作群或副业群试试水
- 最低成本验证：今天录一个操作截图或短视频，在 1-2 个群里@提问，看有没有人回"在哪买"或"怎么弄"
- 为什么先别冲太猛：这个 Skill 依赖 yt-dlp，而 yt-dlp 本身需要持续维护更新，如果你打包卖出去之后工具失效，售后解释成本会很高；加上 YouTube 下载本身存在版权灰色地带，定价和话术要谨慎，不要主动往灰色场景引导
- 配图建议：截一张"命令行一行装好、直接下视频"的终端截图，或者直接录一个视频下载成功的短屏幕录像，对比感最强
