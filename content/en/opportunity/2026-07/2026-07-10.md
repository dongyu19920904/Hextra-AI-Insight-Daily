## 今日主推
### [丢个视频链接进去，Claude 替你看完还帮你总结——这套跑通包今天就能挂](https://github.com/bradautomates/claude-video)

你有没有遇到过这种情况：一个 40 分钟的英文教程，拖到最后五分钟，结果根本看不下去。现在有个工具叫 claude-video，一条命令下去，视频被下载、帧被提取、内容被转录，全部喂给 Claude 处理，你只要问问题就好。这个东西在 GitHub 上刚冒头，技术圈已经在聊，但大多数中文新手根本不知道它存在，更不知道怎么跑起来。

你今天卖的不是"帮我安装 GitHub 项目"，你卖的是：把视频扔进去、Claude 帮你看，这个结果直接交付到对方手里。信息差还没消化完，窗口在。

- 参考来源：[claude-video GitHub](https://github.com/bradautomates/claude-video)
- 目标鱼塘：看英文视频头大的内容副业新手、短视频创作者、自学 AI 的小白；想总结会议录屏、课程视频的小老板
- 适合谁：不会装环境、不会用命令行、但听说 Claude 能看视频后很心动的那批人
- 这钱从哪来：很多人订了 Claude，却只会发文字；今天他们刚看到"Claude 能看视频"这个消息，第一反应是"我要怎么弄"，你就是那个帮他弄好的人
- 可交付物：跑通截图+操作说明文档（1页）+一个可复用的视频问答 prompt 模板；进阶版可加录屏演示
- 最简单卖法：闲鱼挂一个"Claude 看视频跑通包"，9.9-29.9，包含说明文档+截图+模板，有问题私聊答疑一次
- 最低成本验证：今晚先跑一遍，截三张图（下载中、提取中、Claude 回复结果），配一条文案，今晚发朋友圈或社群，看有没有人问
- 今天先做哪一步：先把 claude-video 本地跑通，截图留好，写一段"以前手动整理视频要多久，现在一条命令几分钟出结果"的对比文案
- 今天就能发的文案：「你有没有遇到过：视频太长、没时间看，但又不敢跳过。现在我用 claude-video，把视频丢进去，Claude 替你看完、替你总结。40分钟的内容，问三个问题就能提走核心。整套跑通包+模板，私聊。」
- 复购/升级路径：跑通包是入口 → 升级到"帮你把自己的视频素材库接进去"代配置服务 → 再升到"视频转爆款内容"月费陪跑
- 售后边界：只交付跑通说明和模板，不承诺对方的网络环境一定成功；说清楚需要有 Claude 账号和基础命令行权限
- 配图建议：用 claude-video 跑通后 Claude 回复视频内容的截图，最好能看到视频标题和 Claude 的分析结果对比，一眼就有"哇这真的在看视频"的冲击感

## 本周可试
### [有工具、有账号，就是不知道用在哪——flomo Agent 场景模板包正在等买家](https://mp.weixin.qq.com/s/uLzl9_WLFe_DMWchgVThSA)

flomo Agent 刚更新了记忆系统和几个新 skill，核心用户圈子在聊，但大多数买了工具账号的普通用户根本不知道这次更新能帮他们省什么。这钱卖的不是"新功能介绍"，卖的是"你装好了但一直没用起来的那个工具，现在我给你一套直接能跑的场景配置"。

先试水，别一上来就做全套。找一个场景切进去——比如"每天读完文章自动整理重点"或"会议记录自动归类"——做成一页说明+截图，本周先发，看有没有人问。这类模板包竞争开始多了，现在做窄切口比做大全集更容易成交。

- 参考来源：[flomo Agent 更新](https://mp.weixin.qq.com/s/uLzl9_WLFe_DMWchgVThSA) / [Telegram 频道原帖](https://t.me/aigc1024/21961)
- 适合谁：已经用 flomo 做笔记、但没搭过 Agent 的用户；内容副业新手想把 AI 用进日常工作流的人
- 先怎么试：挑一个最具体的场景（比如"读文章→自动归档进 flomo"），做一版配置说明截图，朋友圈或社群先发，问有没有人想要
- 最低成本验证：一张截图+一句"帮你配好 flomo Agent 自动整理笔记，需要的私信"，今晚就能发，不用录屏不用做课
- 为什么先别冲太猛：flomo Agent 的用户圈子还不算大，且对方需要有 flomo 账号才能用，成交范围比纯 Claude 工具窄；先测反馈再决定要不要做成正式货盘
- 配图建议：flomo 页面里自动整理好的笔记截图，标注哪些是 Agent 自动填进去的，有"整齐对比乱糟糟"的视觉反差最好
