## 今日主推

### [写完 Markdown 直接粘进公众号，帮你打包好这套排版神器](https://x.com/op7418/status/2074527631559798981)

做公众号的人都懂那个感觉：在外面排好的格式，一粘进编辑器全乱，要么字体变，要么间距崩，要么背景色消失。每篇都要手动调，千篇一律不说，还费时间。今天甲木和摸鱼小李联名开源了一套叫 `gzh-design-skill` 的排版工具，写完 Markdown 一键生成能直接粘进公众号的 HTML，样式不掉、6套风格可选。这是今天成交门槛最低的方向：痛点高频，目标人群明确，你今晚就能发一条文案挂上去。

- 参考来源：[gzh-design-skill 原始推文](https://x.com/op7418/status/2074527631559798981) / [qiaomu-design skill 相关讨论](https://x.com/vista8/status/2074532402098221520)
- 目标鱼塘：每周要发文的公众号运营者、自媒体副业新手、小老板自己写内容的人
- 适合谁：已经在写公众号但每次排版都要多花半小时的人，不想学代码、只想拿结果
- 这钱从哪来：公众号排版是每周必踩的坑，不是一次性问题——买家今天就会遇到，花小钱省大麻烦是愿意付的逻辑。开源工具刚出，中文新手大多不知道怎么装、怎么用，信息差就在这里。
- 可交付物：中文上手教程（截图版）+ 6套风格示例效果图 + 使用 SOP 一页纸 + 可选搭售 Claude/ChatGPT 账号入口
- 最简单卖法：闲鱼挂一个"公众号免排版配置包"，9.9–19.9 元，交付教程+效果图+答疑群入口
- 最低成本验证：今晚把这套工具自己跑一遍，截两张排版前后对比图，发一条闲鱼商品或朋友圈，看有没有人问
- 今天先做哪一步：截一组"粘进去不掉格"的对比截图，做成商品主图，配三行文案挂上闲鱼
- 今天就能发的文案：「公众号排好格式一粘就乱？这套工具写完 Markdown 直接生成能粘的 HTML，6套样式随选，不用自己调。9.9 拿走配置教程，今天就能用。」
- 复购/升级路径：低价包引流 → 进群答疑 → 升级到"公众号内容全套模板库"月费 → 代配置1对1 → 搭售 Claude 账号或写作提示词包
- 售后边界：只交付安装说明、截图教程、效果示例，不承诺"永久更新"，不代写内容，不保证所有编辑器兼容——开源工具有时会更新，说清楚交付的是当前版本
- 配图建议：直接用排版前后对比截图，左边是乱掉的样式，右边是生成后干净的 HTML 效果，放在同一张图里，比任何文字都有说服力

## 本周可试

### [让 Claude 直接"看懂"你的视频，帮你把这个跑通卖给剪辑党](https://github.com/bradautomates/claude-video)

这个 GitHub 项目让 Claude 能下载视频、提取帧、转录内容并直接分析，相当于给 Claude 装了"眼睛"。对短视频剪辑、内容运营和做视频带货的人来说，以后可以直接丢一个链接问 Claude"这个视频讲了啥、哪一段最吸引人、帮我写脚本"——这个方向有苗头，但项目刚上 GitHub Trending，中文配置教程还几乎空白，今天先做个小范围跑通测试比直接重投更稳。

- 参考来源：[claude-video GitHub 项目](https://github.com/bradautomates/claude-video)
- 适合谁：做短视频内容的副业新手、剪辑接单者、视频带货运营——他们想要"看完竞品视频马上出脚本"的自动化工作流
- 先怎么试：自己先把这个工具本地跑通，录一段"丢视频链接 → Claude 输出内容摘要和脚本框架"的演示录屏，发到剪辑类社群或微博，问有没有人想要这份配置包
- 最低成本验证：一段30秒录屏 + 一条"Claude 现在能直接看视频了，我把安装方法打包了"的朋友圈或群发，看反馈量
- 为什么先别冲太猛：项目刚出，依赖环境比较复杂（需要 Python + ffmpeg + Claude API），中文新手踩坑率高，售后解释成本不低。先验证有人愿意付钱，再决定要不要做成正式商品，现在只适合轻量试水
- 配图建议：录屏截图最好，重点截"输入视频链接 → Claude 输出脚本/摘要"那一步的画面，让人一眼看出"原来可以这样用"
