# 今日AI商机

## 先说结论

AI写出来的内容越来越像，今天有个开源项目专门治这个毛病——把它做成"让你的AI不再说废话"交付包，今晚就能挂。

---

## 今日主推

### [你的AI老是输出废话？这个配置包帮它"长出品味"](https://github.com/Leonxlnx/taste-skill)

你有没有发过一种稿，写完自己都觉得没劲，但说不出哪里有问题——句子通顺、逻辑没错，就是没有那种"这只有你能写"的感觉。AI生成的内容大多是这样，太整齐了，太普通了，读完像喝了一杯白开水。

GitHub 上今天一个叫 Taste-Skill 的项目就是专门解这个问题的：给 Claude Code、Cursor、Gemini CLI 这些 AI 编程和写作工具装上一套"审美规则"，让它学会拒绝输出千篇一律的平庸内容。普通用户看到这个项目会兴奋——但大多数人装不上去，也不知道配好了能用在哪里。

这就是你的切入口：不是卖项目本身，而是卖"装好之后你的AI会变成什么样"这个结果交付包。

- 参考来源：[taste-skill](https://github.com/Leonxlnx/taste-skill) / [graphify](https://github.com/Graphify-Labs/graphify)
- 买家鱼塘：用 Cursor 或 Claude 写内容的小红书博主、自由职业文案、在跑 AI 写作副业的人；他们已经在用 AI，但输出质量一直让自己将就
- 第一次成交：卖一个"AI品味配置包"——包含 Taste-Skill 的中文安装说明、给 Cursor/Claude Code 的现成配置文件、3个场景示范截图对比（装前/装后）；定价 29-49 元，低价引流款
- 每一次复购：第一单买了配置包的人，后续可以推"场景扩展包"（比如小红书专用品味规则、产品文案专用品味规则）；或者升级成一次性答疑陪跑，帮他们调出自己的风格偏好
- 增长杠杆：客户数——用"装前/装后对比截图"做小红书或朋友圈内容，这类视觉反差很容易拉新；每一个转发就是一个低成本获客
- 独特卖点：不是卖一个开源项目的链接，而是卖"你不用自己踩坑，我已经跑通了，你买来直接用"
- 风险逆转：交付物限定清晰——安装说明文档 + 配置文件 + 截图示例，不承诺帮买家改写风格、不承诺长期支持；不确定的不说，确定能交付的才写进商品页
- 杠杆资产：这次跑通的配置文件和说明文档，可以复用给之后每一个买家；截图案例沉淀成内容素材；FAQ沉淀成售后文档，越卖越轻
- 适合谁：已经在用 Cursor 或 Claude Code、对输出质量有点不满意但不知道怎么调的内容创作者和副业新手
- 这钱从哪来：AI生成内容同质化是今天内容圈真实的痛——很多人已经觉得"AI写的都差不多"，而 Taste-Skill 今天登上 GitHub Trending，正好给了一个"今天有新解法"的时间节点；买家心动的理由是"有人替我搞好了，直接用就行"
- 最简单卖法：先在闲鱼或私域发一条，标题写"让你的AI不再输出废话——Cursor/Claude品味配置包"，带一张装前装后对比截图，定价 29 元；先看有没有人问，有问的再补齐交付物
- 今天先做哪一步：把 Taste-Skill 在本地跑通，截一张"用了之前/用了之后"的输出对比图，就这一张图就是今天最核心的资产
- 今天就能发的文案：「AI写的内容你自己看着都将就？不是你要求低，是它没有品味。GitHub上有个新项目专门治这个，我帮你装好配置好，买来直接插进 Cursor 或 Claude Code 用。装前装后差别自己看👇」
- 配图建议：用同一个写作任务分别跑"装前"和"装后"的输出结果截图拼成左右对比图，左边标"普通AI输出"，右边标"加了品味规则后"——这张图可以直接当商品主图和朋友圈配图

## 本周可试

### [把任何代码库或文档变成"可以直接问答"的知识图谱——帮人配好这一套](https://github.com/Graphify-Labs/graphify)

Graphify 做的事情有点反常识：不是帮你写代码，而是把你已有的代码、数据库结构、文档、甚至视频，变成一个可以直接用 Claude Code/Cursor/Codex 提问的知识图谱。对于有私有文档库、内部知识库需求的小团队和独立开发者来说，这个需求真实存在——但配置起来需要一定折腾成本。

这件事今天还不够急，是因为买家群体稍微窄一点，主要是有"我有一堆文档/代码，但 AI 不认识它们"这种具体痛点的人；普通新手暂时感知不强，需要先等一批早期用户踩出反馈再跟进。

- 参考来源：[graphify](https://github.com/Graphify-Labs/graphify)
- 适合谁：独立开发者、有内部文档库的小团队、在跑 RAG 相关需求但不想自己搭的内容创作者
- 增长假设：客单价——这类需求有明确痛点，愿意付代配置费；配好一套可以卖的比普通入门包贵
- 先怎么试：先在技术社群或独立开发者群里发一条"谁有这个需求"的摸底帖，描述场景不描述工具名；有人回应再做跑通包
- 为什么先别冲太猛：目前 Graphify 的用户反馈和配置稳定性还没跑出足够多的中文案例，贸然接单有售后压力；先低成本测需求，再决定要不要做标准交付
- 能沉淀什么：跑通过程中的配置笔记、常见报错 FAQ、场景案例截图——这些就是下周或下个月可以直接变成产品页的原材料
- 配图建议：用一张"上传文档→生成知识图谱→用 Claude 直接问答"的三步流程截图，比文字说明直观得多；今天先截图备用

## 地图感

### [MiniMax M3发布：AI公司开始不只比模型了](https://www.36kr.com/p/3882467938040710)

大模型竞争正在从"谁的模型最聪明"转向"谁能跑通实际任务"——MiniMax M3 发布，重点打的是 BrowserComp 这种任务完成能力，不再只是 Benchmark 分数。对普通用户来说不需要现在深究，但知道这个方向有用：以后买家问的不是"哪个模型更聪明"，而是"哪个工具能帮我把这件事做完"。

## 今日动作

- 先发什么：发一条朋友圈或小红书，带一张 AI 输出"装前/装后"对比截图，文案用上面那条直接发，今晚发
- 先录什么：录一段 30 秒屏幕录屏——打开 Cursor，展示加了 Taste-Skill 规则之后输出一段文案，对比不加规则的输出；不用剪辑，就这一段原始录屏就够当交付物和营销素材
- 先卖哪一款：闲鱼先挂 29 元的"AI品味配置包"，限定交付：中文安装说明 + 配置文件 + 对比截图；先挂着看有没有人问，有问的再补答疑
- 先沉淀什么：今天跑通 Taste-Skill 的配置步骤，写成一份自己能复用的 SOP 文档——这份文档以后每卖一单都用得上，是今天唯一值得花时间做的资产
