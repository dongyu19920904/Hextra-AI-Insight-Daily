## 今日主推

### [丢一篇文章进去，配图自己出来——这套提示词今天就能卖](https://x.com/vista8/status/2073450347167944992)

做内容的人都卡在一件事上：写完文章，配图还得另外找、另外改、另外求设计师。现在有人已经把提示词跑通了——整篇文章扔进 ChatGPT 或 Codex，直接出一组字形图标，风格统一，16:9，能直接用。

问题是这个提示词大多数人看了不知道怎么调，改一下参数图就乱了，自己折腾半天也不知道哪里出了问题。你要卖的，不是教他们看懂提示词，而是给他们一个"丢文章进去就出图"的交付状态——跑通的参数、改好的模板、一句话说明怎么用。

GPT-5.6 传言这周发布，正好是推这种场景包的最好时机。不用等，今晚就能试发。

- 参考来源：[vista8 原推](https://x.com/vista8/status/2073450347167944992) / [GPT-5.6 传言](https://www.36kr.com/p/3880971920584962)
- 买家鱼塘：小红书博主、公众号运营、短视频创作者、自媒体团队；这类人天天要配图，最烦就是配图没风格、找图费时间
- 第一次成交：卖一个"文章配图提示词场景包"，包含跑通版提示词、参数说明、3 种风格变体示例截图、一句话使用说明；定一个低价引流款，9.9 到 19.9 都能试
- 每一次复购：出"视频号版""长推文版""知识付费封面版"等细分场景包，或者出"每月新款提示词更新包"；买过一次的人最容易回购
- 增长杠杆：购买频次——同一个人会持续做内容，隔几周就需要新风格、新场景，只要你有更新就有理由复购
- 独特卖点：不是教提示词原理，而是给一个开箱即用的状态；买家丢进去就有图，不用自己调
- 风险逆转：发一张示例截图当预览，买家买之前就知道出图长什么样；如果出不了效果，说明版说清楚只支持 ChatGPT 和 Codex，不是所有工具通用
- 杠杆资产：每做一个新场景包，就沉淀一份可复用模板；做三个场景以后，可以合并成"内容创作配图全场景包"卖更高价
- 适合谁：手边有 ChatGPT 或 Codex 入口、在做内容但不会用 AI 配图的人；或者已经有这类买家私域的卖家
- 这钱从哪来：内容创作者天天需要配图，这件事的痛够高频；GPT-5.6 传言刚出，买家对"新版本新玩法"的好奇心今天最高
- 最简单卖法：在闲鱼或私域发一条"文章丢进去自动出字形配图"的示例截图，说明包里有什么，挂上链接
- 今天先做哪一步：把 vista8 那条提示词自己跑一遍，截一张效果图，写三行说明，今晚先试发一条朋友圈或小红书，看有没有人问
- 今天就能发的文案：「写完文章最头疼的不是写，是配图。昨天发现一个提示词，整篇文章扔进 ChatGPT，直接出一组风格统一的字形配图，不用改不用找素材。我把参数调好了，你直接用，19.9，感兴趣私信我。」
- 配图建议：用 vista8 原推里的图标效果截图，深色背景+高对比汉字，最直观；或者自己用这个提示词跑一张实际效果图，更有说服力

## 本周可试

### [主流 AI 工具的系统提示词全泄露了——先把这个做成"拆包教程"再等等](https://github.com/asgeirtj/system_prompts_leaks)

GitHub 上有个仓库这两天在 Trending，把 Claude Fable 5、Opus 4.8、ChatGPT 5.5、Codex、Gemini 3.5、Grok、Cursor 等主流工具的系统提示词全扒出来了，还在持续更新。对内容创作者和 AI 学习者来说，这是一份"看懂大厂在怎么调教模型"的一手材料。

但今天还不用押注太重——Anthropic 刚宣布要封禁地下通道，这块的走向还不清楚，做成账号类或代配置风险偏高。更稳的方向是把它做成**信息差翻译包**：把这些系统提示词用中文拆解清楚，告诉买家每个工具"在让模型怎么做事"，再附上"你照着这个思路写自己的提示词"的练习模板。

- 参考来源：[system_prompts_leaks](https://github.com/asgeirtj/system_prompts_leaks) / [Anthropic封禁地下通道](https://www.36kr.com/p/3881112560005381)
- 适合谁：想搞懂提示词怎么写、想了解大厂思路的 AI 学习者；内容博主、教 AI 课程的人
- 增长假设：提升客单价——同样卖提示词包，有"大厂级别原版拆解"的背书，能卖更高价、更容易让人觉得值
- 先怎么试：先挑 1-2 个最有代表性的系统提示词（比如 Claude Code 或 ChatGPT 5.5 Thinking），写一篇中文拆解，发到公众号或小红书测反馈；有人问再做成完整包
- 为什么先别冲太猛：Anthropic 封禁地下通道的消息刚出，平台对"绕过限制"相关内容可能会收紧审核；这份仓库本身的合规状态也不确定，先观察一周再押资源
- 能沉淀什么：中文提示词拆解库、提示词写作模板、大厂调教思路总结——这三样都是可以持续卖的知识资产
- 配图建议：截一张仓库里的系统提示词原文截图，加一行中文注释说明"这是 ChatGPT/Claude 在让模型做什么"，对比感强，最容易吸引好奇心

## 今天别碰

### [cc-switch 跨平台 Agent 切换工具——别急着帮人配](https://github.com/farion1231/cc-switch)

工具本身支持 Claude Code、Codex、OpenClaw、Gemini CLI 等一堆 CLI 工具的切换，看着很全。但今天 Anthropic 刚宣布封禁地下通道，这一类"绕过限制/多账号切换"相关服务的售后风险在快速上升。新手帮人配了，出了问题客户找你，解释成本很高，不合适作为今天的主推方向。

## 地图感

### [open-design：本地桌面版 Claude Design 替代品来了](https://github.com/nexu-io/open-design)

一个开源的本地优先设计工作空间，支持 Claude Code、Codex、Cursor、Gemini 等 20 多种 CLI，能直接出 HTML、PDF、PPTX、MP4。对设计师和内容创作者来说，是"不依赖官方 Claude Design 也能用 AI 出设计稿"的入口。现在知道这东西存在就够了，等它社区成熟一点再考虑做成服务。

## 今日动作

- 先发什么：朋友圈或小红书发一张"文章扔进去出字形配图"的效果截图，配那条可以直接复制的文案，先测有没有人问价
- 先录什么：录一个 30 秒屏幕录屏——把一段文章粘进 ChatGPT，提示词一发，图出来——不用剪辑，就这一段，当成最直接的产品演示
- 先卖哪一款：9.9 到 19.9 的"文章配图提示词场景包"，内容就是跑通的提示词 + 3 张示例图 + 一页使用说明，今天先挂闲鱼或私域测单
- 先沉淀什么：把今天跑通的提示词、参数和截图存档，这是第一版模板；后面每加一个新场景（视频号封面、知识付费配图、长文摘要图），就是一次更新，也是一次给老客户发消息的理由
