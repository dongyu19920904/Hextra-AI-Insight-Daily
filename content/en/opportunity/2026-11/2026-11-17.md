## Today's Main Pick

### Validate Whether Freelance Video Editors Will Pay for an FFmpeg-MCP Local Setup Package

**This project wraps FFmpeg into 42 tools that a coding agent can call directly. It runs locally with no API required. The real question to validate is: will any freelancers pay someone to get this setup working for them?**

ffmpeg-skill appeared on GitHub Trending today. Its potential value for freelance video editors is saving the time spent typing commands and looking up parameters when processing batch jobs — but that remains an unverified assumption.

- **Evidence and confidence:** Medium. [ffmpeg-skill repository: confirms the project exists, lists 42 tools, and describes the MCP server functionality](https://github.com/kajisho5/ffmpeg-skill). Gap: the source material for this issue provides no data on willingness to pay, records of Chinese freelancers using it, or actual deployment time.
- **Target pool and ground-level approach:** Unverified assumption: freelance video editors and small short-video teams may currently look up commands or write scripts by hand each time; developers who want an MCP toolchain configured and might pay to avoid doing it repeatedly — also unverified.
- **Minimum deliverable:** Product name: FFmpeg-MCP Local Setup Package. Contents: ① a screenshot showing successful execution (one demo each for trimming, subtitles, and platform export); ② a config file for Claude Code or Cursor; ③ notes on common errors. Not included: modifications to FFmpeg source code, or cross-platform environment compatibility guarantees. Acceptance criterion: buyer can complete one full editing task locally by following the instructions.
- **48-hour validation:** First, run through the whole thing yourself — trim a video, add subtitles, adjust loudness, export — and record the actual time and any failure points, with screenshots or screen recording. Send the sample to 3–5 people who use FFmpeg for freelance or batch video work, ask how long they currently spend setting it up themselves, and ask whether, after seeing this package, they have any willingness to pay. Watch whether anyone asks about pricing unprompted.
- **First sale and repeat purchases:** Outreach line to test: "I've got FFmpeg set up locally so Claude Code can call it directly — I ran through the whole thing myself and wanted to check whether this is something you'd find useful." Scope of the first sale: deliver only the config file, setup instructions, and one remote Q&A session; no custom scripts, no ongoing maintenance. Repeat purchase likelihood is low — this is closer to a one-time delivery — but could become repeatable if packaged as export-spec bundles for different platforms.
- **Risks and stopping conditions:** After-sales and compliance risk is **low**; MIT license, but verify dependency libraries and trademark boundaries. Stop if: the setup steps turn out to be more complex than target users can handle; or all 5 target users see the sample and none express interest; or the actual time required exceeds the value buyers are willing to pay for.
