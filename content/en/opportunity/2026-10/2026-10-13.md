## Today's Main Bet

### Validating whether any small team would buy a "Multi-Tool System Prompt Side-by-Side Comparison Pack"

**This repo pulls the system prompts and underlying models of 26 AI coding tools into one place, saving people who'd otherwise have to stumble through each one separately the time of searching and comparing.** The opportunity isn't in the repo itself — it's whether small teams doing evaluations or tool selection would pay for "already read it for you, organized the differences, here's exactly what's different" comparison results. 🎯

- **Evidence & confidence:** Medium. [system-prompts-and-models-of-ai-tools official repo — confirms the project contains system prompts and model info for 26+ tools](https://github.com/x1xhlol/system-prompts-and-models-of-ai-tools). Gap: the candidate input this time didn't include the license type or a clear statement on whether commercial redistribution is allowed — that needs to be checked first.
- **The pond & the grunt work:** Unvalidated assumption: small-team tech leads doing tool selection, indie devs, or AI tool consultants may currently be opening each tool's website and docs one by one, manually comparing behavior boundaries and model differences — a repetitive process that can't be reused.
- **Minimum deliverable:** "AI Coding Tool System Prompt Side-by-Side Comparison Pack v1" — covers 3–5 mainstream tools (e.g., Claude Code, Cursor, Windsurf, Kiro, Devin) with a core prompt-diff comparison table + known limitations summary per tool + 1 quick-reference tool-selection card. Buyer's check: within 10 minutes of opening the deliverable, they can understand the behavioral boundary differences between two tools without digging through the repo themselves. **Not included:** accounts, subscriptions, or any real-time update commitments.
- **48-hour validation:** Pick 3 tools from the repo, spend 2 hours putting together 1 screenshot-able comparison table (diff dimensions, limitations, models) as a sample. Send that sample to 3–5 developers or tech consultants who are currently using or evaluating AI coding tools, and ask directly: "Is this useful to you? Would you be interested in asking about pricing for the full 5–8 tool comparison pack?" Watch for: anyone who proactively asks for a price or says "I actually need this right now."
- **First sale & repeat purchases:** Test pitch: "Save yourself the pain of individually stumbling through 5 AI coding tools — all 26 are already collected, I've organized the most-compared 5, and I'll tell you straight up what's different." First sale is fixed scope: comparison pack for 5 specified tools, delivered as PDF or Notion page, no real-time updates, no tool installation service. **Repeat purchase potential:** Tool system prompts change with version updates — if any user confirms they'd subscribe to a "monthly updated edition," this could mature into a lightweight data product; otherwise it's more of a one-time purchase, and you should be upfront about that.
- **Risks & stop conditions:** Post-sale compliance risk is **medium** — the repo's license type wasn't included in the candidate input this time, commercial redistribution boundaries need to be verified; system prompts themselves may involve each tool's copyright or terms of use, so you can't directly resell large chunks of original text — deliverable should be "organized comparative analysis," not raw copy-paste. Stop conditions: license prohibits commercial use; 5 target users see the sample and nobody asks about pricing; organizing costs clearly exceed what buyers are willing to pay.
