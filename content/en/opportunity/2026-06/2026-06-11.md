## 今日主推
### [帮你把 Claude 变成 23 个专业角色，直接能用那种](https://github.com/garrytan/gstack)

Y Combinator 前总裁 Garry Tan 自己在用的 Claude 配置包，23 个角色分工明确：CEO 帮你拍板、设计师帮你提意见、QA 帮你挑毛病，工程经理、发布经理、文档工程师一套齐。问题是这东西在 GitHub 上，全是英文，还要自己知道怎么装进 Claude Code。大多数人看完截图心动，打开仓库就卡住了。

你今天要卖的不是这个 GitHub 地址，是"我帮你装好、配好、告诉你每个角色怎么召唤"的结果包。买家付钱买的是：不用自己踩坑，打开就能用。

- 参考来源：[gstack](https://github.com/garrytan/gstack) / [claude-mem 跨会话记忆](https://github.com/thedotmack/claude-mem) / [Fable 5发布背景](https://www.36kr.com/p/3847167864703496)
- 适合谁：看见 AI 工具截图很心动、但一打开 GitHub 就懵的中文新手；用 Claude 但不知道怎么发挥最大效果的人
- 这钱从哪来：Claude Fable 5 刚发布，全网都在转 Garry Tan 这套配置的截图，今天正是心动高峰期，有截图、有话题、有流量；买家今天看到别人晒"23 个专业角色帮我干活"，第一反应是想要，第二反应是不会装——你卖的就是那一步
- 最简单卖法：打包成"Claude 角色配置跑通包"，含中文配置说明 + 角色唤醒模板 + 1 次基础答疑，定个低价引流款先测反馈，有人问再出标准款
- 今天先做哪一步：自己先把 gstack 跑一遍，截 2-3 张"不同角色各自在干什么"的对话图，今晚配一段 100 字内的中文说明，发朋友圈或闲鱼
- 今天就能发的文案：「Garry Tan 自己在用的 Claude 配置，23 个角色分工，CEO 拍板 / QA 挑错 / 文档工程师跟着写。全是英文 GitHub，我帮你装好配好，打开就能召唤。低价体验名额，先到先得。」
- 配图建议：截一张 Claude 对话界面，同时显示 2 个不同角色在同一个任务里各自给出反馈的画面，最能说明"多角色分工"这个结果

## 本周可试
### [AI 帮你操控网页，不用再猜按钮在哪了](https://t.me/aigc1024/21127)

Google 在 Chrome 146 推了 WebMCP，让网站直接把自己的功能"说给" AI 听，AI 不用再截图猜按钮了。这件事今天还不是"马上能卖"的成熟商品，但它说明了一件事：Browser Agent 跑通服务这条线，接下来会有越来越多人愿意付钱让别人帮自己配好。

现在先试发"Agent 帮你自动填表 / 自动搜航班 / 自动下单"的轻服务概念卡，观察有没有人来问。等 WebMCP 支持的网站多起来，这张牌就能打重一点。

- 参考来源：[WebMCP 介绍](https://t.me/aigc1024/21127) / [cc-switch 多平台支持](https://github.com/farion1231/cc-switch)
- 适合谁：对自动化操作感兴趣、但不会配环境的人；已经在用 Agent 工具、想升级体验的人
- 先怎么试：先发一条"AI 帮你自动操作网页，我来帮你配好"的轻服务说明，不承诺什么都能做，只说先接 1-2 个具体场景试单，比如"帮你自动搜比价"或"帮你填固定表单"
- 为什么先别冲太猛：WebMCP 刚推，支持的网站还少，买家拿到手可能立刻找不到能用的场景；现在主要是测有没有人问，别急着做课程或大包
- 配图建议：找一张 AI Agent 在浏览器里完成一个具体操作（比如自动填好一个表单）的录屏截图，比任何文字都直观
