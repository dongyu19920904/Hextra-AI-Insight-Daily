## 今日主推
### [自动盯盘，不用自己看——股票 AI 分析系统跑通服务](https://github.com/ZhuLinsen/daily_stock_analysis)

买股票的人每天都有一件烦事：盯盘太累，但又怕错过。有个开源项目今天登上 GitHub 热榜，能用 AI 自动抓行情、读新闻、出决策看板，还能定时推送——关键是作者说零成本可以跑。但"零成本跑通"对大多数人来说，就是一堆环境配置和 API 接入，一个报错就卡死了。你帮他把这套东西跑起来，截图交付，他不需要懂代码，只要看结果。

这单的买家画像很清晰：关注股市、手里有点仓位、买过各种选股软件、但从没自己配过 AI 工具。他愿意付钱的理由不是"AI 很厉害"，而是"这玩意帮我省时间盯盘，你帮我装好就行"。

- 参考来源：[daily_stock_analysis](https://github.com/ZhuLinsen/daily_stock_analysis)
- 适合谁：有股票仓位、想用 AI 辅助看盘但不会配环境的普通散户；也适合做 AI 工具代配置的新手卖家，今天就能试挂
- 这钱从哪来：买家每天盯盘很烦，但现成的选股软件又贵又泛，一个能帮他自动推送分析结果的私人系统，有明显的替代动力；加上今天刚上热榜，他刷到项目但配不起来，需求就在这里
- 最简单卖法：收一个"跑通配置费"，交付内容是：帮买家在他的机器或云端部署好、跑通截图或录屏证明、附一份简单使用说明。可以从 39-69 元低价试水，跑顺了再出标准服务款
- 今天先做哪一步：先自己把这个项目本地跑通一遍，截两张图——一张是行情抓取结果，一张是推送效果；今晚就能把服务说明和截图发出去试反应
- 今天就能发的文案：
  > 你有没有每天开盘前手忙脚乱查行情的烦恼？我最近帮人配了一套 AI 自动盯盘系统，能抓多市场行情、读实时新闻、出决策看板，还能定时推你。你不用自己装，我帮你配好交付截图。感兴趣的私我，先做几个名额。
- 配图建议：用 daily_stock_analysis 项目页的决策看板截图，或者自己跑通后的推送效果图；别用 GitHub 项目首页，买家看不懂

## 本周可试
### [一套 AI 角色配置包，替你在 Claude Code 里变出一个小团队](https://github.com/garrytan/gstack)

Y Combinator 合伙人 Garry Tan 的 Claude Code 配置今天上了热榜，23 个专项工具，分别扮演 CEO、设计师、工程经理、文档工程师和 QA，用一套提示词配置让 Claude Code 在不同场景自动切角色。这个东西本身不难，但你要把它翻成中文、整理成"开箱即用的角色包"卖给不懂英文的新手，是有信息差空间的。

现在还不确定中文用户买这类配置包的意愿有多强，先小批量试探比较稳。发一两条"我整理好了，感兴趣的留言"，看反应再决定要不要出正式商品。

- 参考来源：[gstack](https://github.com/garrytan/gstack)
- 适合谁：在用 Claude Code 做开发或内容工作、但从没系统配过角色提示词的中文用户；也适合已经在卖 Claude 相关服务的卖家顺手搭售
- 先怎么试：把这 23 个工具翻成中文说明，整理成一份可以直接导入的配置包或提示词清单，先在群里或朋友圈发一版"感兴趣的来找我"，不用先挂商品页
- 为什么先别冲太猛：这个配置本身偏开发者向，中文普通用户不一定有 Claude Code 使用习惯；而且这类提示词包竞争不少，信息差窗口不会太长，先测有没有人问再说
- 配图建议：截一张 gstack 的角色列表，旁边加一列中文说明对照；或者做一张"Claude Code 多角色分工示意图"，比直接截 GitHub 更有传播性
