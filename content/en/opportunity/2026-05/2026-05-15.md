## 今日主推
### 用 Claude Code 写代码，但每次都要重新交代背景？这个问题今天有了可以卖的解法

很多人已经在用 Claude Code 或 Cursor 写代码，但有个小麻烦一直没解决：每开一个新会话，AI 就忘了你上次说的所有事——项目背景、你的习惯、踩过的坑，全部清零。今天 GitHub 上同时出现了两个专门解这个问题的项目：`everything-claude-code` 和 `claude-mem`，一个做技能和记忆框架，一个做跨会话持久上下文。两个项目同一天冒出来，说明这个需求真的到了爆发点。

买家今天心动的理由很简单：他们已经在用这些工具，已经被这个问题烦过，但自己去 GitHub 装配置大概率会卡在环境上。你卖的不是教程，是"我帮你装好、跑通、截图给你看"这个结果。

- **适合谁：** 已经在用 Claude Code、Cursor 或 Codex 的人，不会自己配 GitHub 项目，想直接用上跨会话记忆功能
- **这钱从哪来：** 他们今天刷到这两个项目，心动但看不懂怎么装；你帮他们省掉踩坑的两三个小时，这钱就来了。今天两个项目同时出现，话题热度刚起，是最好的发帖时机。
- **最简单卖法：** 先自己跑通一个（`claude-mem` 更轻量，建议先从它开始），截一张"新会话里 AI 还记得上次内容"的对比图，挂一个代配置服务，定价低一点先跑量
- **今天先做哪一步：** 本地跑通 `claude-mem`，截一张前后对比截图——左边是没有记忆的新会话，右边是有记忆的新会话，这张图就是你今天最好的成交素材
- **今天就能发的文案：**
  > 用 Claude Code 写代码，每次新开对话都要重新介绍项目背景？今天帮你配好跨会话记忆，下次打开直接接着上次说。代配置，跑通截图给你看，有问题随时问。
- **配图建议：** 两个并排截图：左边新会话 AI 说"我不了解你的项目"，右边配置后 AI 直接接上上次的上下文；或者直接录一段 15 秒的操作录屏

## 本周可试
### Mac 用户的启动器突然变成了 AI 工作台——Raycast Beta 的配置包有人会买吗？

Raycast 昨天悄悄推了 V2 Beta，从一个快捷启动器变成了带 Agent 和 Skill 的 AI 工作台，还能免费调用顶级模型。这个变化对 Mac 用户来说挺大，但 Beta 版 Bug 多、不支持云同步，很多人装完发现快捷键和 Prompt 全没了，需要重新配。

这个方向有苗头，但今天还不用重投入——Beta 版本不稳定，用户基数还在观望，现在做的话先试发一个"Raycast Beta 上手配置包"，看有没有人问，有人问再深做。

- **适合谁：** 已经在用 Raycast 的 Mac 用户，或者想试 AI 工作台但不知道怎么配置 Skill 和 Agent 的人
- **先怎么试：** 整理一份"Raycast Beta 装完第一步该配什么"的中文清单，配上截图，先发朋友圈或社群，看有没有人主动问；有人问就说"我有配置包，需要的话私我"
- **为什么先别冲太猛：** Beta 版本变化快，今天配好的模板下周可能就失效；而且 Bug 多，售后压力不小。先用低成本内容测反馈，确认有人愿意付钱再做完整包
- **配图建议：** Raycast V2 Beta 的界面截图，重点框出 Agent 和 Skill 入口，旁边加一行字"这里怎么配，很多人卡住了"
