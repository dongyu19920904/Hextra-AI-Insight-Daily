## 今日主推

### [自学党的救星来了，这套 AI 辅导系统帮你把课本变成私教](https://t.me/aigc1024/22700)

你有没有遇到过这种情况：买了课，资料一堆，但没人陪着看，一遇到难点就卡住，最后躺在硬盘里。港大出品的 DeepTutor 就是冲着这个问题来的，不是问答机器人，而是把你导入的教材、笔记、论文，直接拆成推理解释、自动出题、图表动画、知识薄弱点追踪，整个学习路径 AI 来调整。

对小白卖家来说，这个项目的机会不在"教人用开源工具"，而在帮考研党、职场自学人、副业充电的人省掉自己折腾环境的时间。你今天做一个"考研英语/职场 Excel/产品经理备考"的 DeepTutor 跑通截图，就是一张能成交的图。

- 参考来源：[DeepTutor 原帖](https://t.me/aigc1024/22700)
- 目标鱼塘：考研党、职场自学人、副业充电的人、在线课程买了不看的人
- 适合谁：手里有工具账号，想顺手多卖一单"学习类跑通包"的卖家；或者自己在做学习类内容副业的人
- 这钱从哪来：自学的人最大的痛是"没人陪着学"，这套系统能模拟私教陪跑，买家买的是"我不用自己折腾环境就能跑起来"
- 可交付物：DeepTutor 跑通配置说明（含 Docker 一键启动步骤）+ 3 个场景示范截图（比如导入考研词汇表、导入行业报告、导入职场技能笔记）+ 简单上手说明
- 最简单卖法：定一个具体场景包，比如"考研自学版跑通包"，含环境配置 + 场景导入教程，低价挂闲鱼试探
- 最低成本验证：今天先本地跑通 Docker 部署，截两张图，写一条朋友圈或闲鱼标题：「考研备考全靠这套 AI 私教，自己导教材就能用」
- 今天先做哪一步：把 DeepTutor 跑起来，截一张"导入笔记 + 自动出题"的效果图，这张图就是你的成交工具
- 今天就能发的文案：「备考/自学最难的不是没资料，是没人陪着看。这套 AI 系统导入你的教材、笔记，帮你拆推理、出练习题、还记录你的薄弱点——现在有跑通包，不用自己折腾环境，直接导材料就能用。需要的私信。」
- 复购/升级路径：跑通包是入口 → 升级定制场景包（考研/英语/Excel 各一个版本）→ 陪跑答疑月卡 → 小圈子"AI 自学工具"会员
- 售后边界：只交付配置方案和截图说明，不保证学习效果，不承诺长期维护开源版本更新；如买家本地环境报错，提供一次基础排查
- 配图建议：用"导入一份笔记 → 自动生成练习题"的操作截图最能说明问题，别截 GitHub 主页，截实际运行界面

## 本周可试

### [DeepSeek Flash 能力升级，能帮你省的不只是 API 费——先把对比包做出来](https://m.okjike.com/originalPosts/6a6c416e141b85b2929cee72)

DeepSeek V4 Flash 正式版上线，Agent 能力直追 V4 Pro 的预览版，这个变化对普通卖家的意义是：以前很多人用贵模型跑 Agent，现在有理由换。但这个机会现在不适合押太重，因为"Flash vs Pro"这种对比读者还需要教育，不是今天一发就能成交的单。

先小范围试：做一个"主流 AI Agent 工具选哪个模型"的中文对比清单，不卖技术，卖省时间做决定的判断感。这种"对比试错型"包今晚就能发一条，先探一探谁在问。

- 参考来源：[即刻原帖](https://m.okjike.com/originalPosts/6a6c416e141b85b2929cee72) / [Twitter 同步](https://x.com/op7418/status/2083078178180890662)
- 适合谁：在用 Agent 工具做自动化的独立开发者、小老板，或者研究 AI 降本的内容博主
- 先怎么试：做一个"DeepSeek Flash / GPT-4o / Claude Sonnet 三款模型跑 Agent 任务对比"的简版清单，可以做成一页 PDF 或截图，标注各自适合的场景
- 最低成本验证：今晚发一条"你现在跑 Agent 用哪个模型？"的选择题，在微信群或朋友圈探反应；或者先挂一版标题：「AI Agent 选模型，我替你先试了这三个，直接告诉你怎么选」
- 为什么先别冲太猛：Flash 正式版才刚上线，真实使用口碑还没跑出来；对比包要有真实场景截图才有说服力，今天先做轻版，等几天跑出来更多实测再加深
- 配图建议：用一张三列对比表截图（Flash / GPT-4o / Sonnet × 任务类型 / 速度 / 适用场景）最直观，不要只截测评数字，小白看不懂分数
