## 直接结论

- **直接答案：** 今天 GitHub Trending 出现三个 Agent 技能项目，优先验证科研团队是否愿意为跑通技能库的场景配置包付费。
- **做不做：** 做。三个项目都有公开仓库，可以先跑通一个样品测试付费意愿。
- **先验证：** 科研、数据分析或内容团队是否愿意为省配置时间付费；先做样品，再找 3-5 位目标用户询价。
- **何时停：** 样品无法复现、5 位用户都无意愿、或需求超出能力范围需长期定制。

## 今日主推

### 验证科研团队配置包需求

**今天 GitHub Trending 出现一个包含 163 个验证技能和 100+ 科学数据库的 Agent 技能库。** 待验证假设：科研团队、数据分析师可能正在手动整理文献、反复调用 API，若有人帮他们跑通 3 个高频场景，可能愿意付费省配置时间。

- **证据与可信度：** 中。[GitHub 原项目仓库](https://github.com/K-Dense-AI/scientific-agent-skills) 显示项目包含 163 个技能和 100+ 数据库，兼容 Cursor、Claude Code 等工具。本次候选输入未提取到中文用户使用记录或付费行为证据。
- **鱼塘与笨办法：** 待验证假设：科研工作者、数据分析师可能正在花时间研究如何把 Agent 工具接入工作流，若有现成配置包，可能愿意为省时间付费。
- **最小交付：** 商品雏形「科研 Agent 技能库场景配置包」，包含中文安装说明、3 个场景配置示例（如文献整理、数据库查询、实验数据分析）、可复用调用模板、30 分钟答疑。买家检查配置能否本地跑通及场景是否符合需求。不含定制开发、数据库授权、长期支持。
- **48小时验证：** 先本地跑通技能库，记录步骤和报错，制作 1 个场景配置样品（如调用 PubMed 整理文献）。找 3-5 位科研团队成员或数据分析师，展示样品并询问：你们现在怎么做文献整理？若有人帮你跑通 3 个场景，愿意付多少？观察他们说「自己能搞定」还是追问「能否加我们的数据库」。
- **第一单与复购：** 测试邀约句「帮你跑通科研 Agent 技能库：3 个场景配置 + 中文说明 + 轻量答疑」。第一单固定 3 个场景，不含定制、数据库对接、超 30 分钟答疑。若客户只需一次性跑通，将配置沉淀成文档或视频降低成本；若验证后有持续需求，可卖新增场景、版本更新或数据库接入。
- **风险与停止：** 售后/合规风险中，需核对各数据库使用条款和 API 限制。停止条件：样品无法复现、5 位用户都无意愿、客户需求超出技能库能力且需长期定制。

## 本周小试

### 验证架构图生成服务需求

- **证据来源：** [GitHub 原项目 archify](https://github.com/tt-a1i/archify) 显示这是生成架构图、工作流图、序列图的 Agent 技能，输出独立 HTML 文件，支持动画和导出。
- **目标鱼塘：** 待验证假设：技术团队、产品经理可能正在用 draw.io 或 PPT 手工画图，若有 AI 生成可交互图表，可能愿意付费。
- **最小交付：** 商品雏形「AI 架构图生成服务」，交付 1 份可交互 HTML 架构图、1 次修改机会、生成记录和源文件。买家检查图表是否准确反映系统结构及导出效果。
- **48小时验证：** 先本地跑通 archify，生成 1 个架构图样品（如微服务架构或数据流图）。找 3-5 位技术团队成员或产品经理，展示样品并询问：你们现在怎么画架构图？若有人帮你生成可交互 HTML 图表，愿意付多少？观察他们说「有专人画」还是追问「能否加我们系统」。
- **为什么只是小试：** 架构图需求可能集中在项目启动或汇报阶段，不一定高频，需先验证目标用户是否为画图烦恼及生成质量是否达标。
- **停止条件：** 生成质量不达标、用户表示有专人负责、5 位用户都无意愿、或需求超出工具能力需大量手工调整。

### 验证视频制作系统部署需求

- **证据来源：** [GitHub 原项目 OpenMontage](https://github.com/calesthio/OpenMontage) 显示这是开源代理式视频制作系统，含 12 条流水线、100+ 工具、700+ 技能。
- **目标鱼塘：** 待验证假设：小型视频团队、内容创作者可能正在手工剪辑或反复调用多个工具，若有人帮部署 AI 系统，可能愿意付费。
- **最小交付：** 商品雏形「AI 视频制作系统部署包」，交付中文部署说明、1 个可运行测试环境、2 个场景演示（如自动剪辑和字幕生成）、轻量答疑。买家检查系统能否本地运行及场景是否符合需求。
- **48小时验证：** 先本地部署 OpenMontage，记录步骤、依赖和报错，制作 1 个视频样品（如自动生成带字幕短视频）。找 3-5 位小型视频团队或创作者，展示样品并询问：你们现在怎么做视频？若有人帮你部署 AI 系统，愿意付多少？观察他们说「有剪辑师」还是追问「能否定制风格」。
- **为什么只是小试：** 系统复杂度高，部署调试可能耗时长，需先验证能否稳定运行、输出质量是否达标及用户是否愿意付费。
- **停止条件：** 系统无法稳定运行、输出质量不达标、用户表示外包更划算、5 位用户都无意愿、或需求超出能力需大量定制。
