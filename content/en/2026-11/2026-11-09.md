## **🔥 Today's Top 10 Highlights**

### 1. Claude Code Permission Files Leak Over 1,000 Credentials on GitHub

**Permission files may be hiding secrets.** Apiiro [Claude Code permission files leak over 1,000 credentials on GitHub](https://apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-again), finding **1,122** files containing what appear to be real credentials. The trigger path is: after a user permanently approves a command containing secrets, the full command is written to the permission file and pushed public with the commit 🔒. The research team did not actually connect to any target hosts, and whether the credentials are still valid has not been verified. **Local developers today** can check whether this file is being tracked by Git and add it to `.gitignore`.

### 2. MaxxBench: Score Gap More Than Doubles After Rewording Tasks

**Change the filename requirement and scores can differ by nearly half.** Gavin Lo and Justin Lo published [MaxxBench: score gap more than doubles after rewording tasks](https://maxxbench.unlap.ai/research/why-maxxbench/), with the median reference patch growing by only **17 lines**. Claude Opus 5.5 and Gemini 3.8 Flash both scored around 74% on DeepSWE, but scored 76.4% and 53.4% respectively on MaxxBench. The maximum gap across 15 configurations widened from 20.9 to **48.3 percentage points**. Benchmark buyers can use this to reassess the reference value of existing SWE scores.

### 5. Small Model Pre-Judges Then Routes to Opus, Cutting Identity Resolution Cost to One Quarter

**Hard cases go to Opus; simple ones are handled locally.** Hightouch [tested a hybrid Jev routing approach for identity merge review](https://hightouch.com/blog/llm-judges-identity-resolution): on the easy set, accuracy was **98.8%** at **$0.88 per thousand**, versus $3.86 with Opus 5.5 alone. On the hard set, the hybrid approach achieved similar accuracy to Opus, with the cost advantage narrowing to roughly 1.8×. The key caveat is that results depend on specific prompts, thresholds, and synthetic distributions and cannot be directly generalized to all scenarios.

### 10. macOS Local Knowledge Graph Contains 181 Entity Types, Including Family Relationship Profiles

**Your Mac has been building a file on you all along, including family relationship scores.** Eighth Rank researchers reverse-engineered macOS and [found 51 SQLite databases locally](https://8rank.ai/game/apple-intelligence-personal-knowledge-graph), with the main graph using **181 entity types** and 278 predicates to record provenance, confidence, and timestamps. Two sets of XGBoost classifiers use **144 features** to infer family relationships, with scores stored separately in `entityTagging.db` across 17 relationship columns. The databases are stored in plaintext, with the directory protected by TCC full-disk access; the research is based on macOS 26.6.2, and the relevant components have existed since macOS 13 🔒.
