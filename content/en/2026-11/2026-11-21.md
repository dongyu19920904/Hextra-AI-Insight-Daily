### 7. Sol 6.2 Refuses to Review AI-Generated Code

**Sol 6.2 refuses to review projects with an entirely AI-generated commit history.** 💻 A V2EX user [documented in a hands-on post](https://www.v2ex.com/t/1258613#reply1) that when all project commits are done by AI, using Codex to call Sol 6.2 for code review is directly refused. **Switching back to Sol 6.1** does not have this issue, the cause is currently unknown. Developers using AI for end-to-end project development should watch for this type of **version behavioral difference**.

### 9. Personal Agent Evaluation Criteria Revisited

**The core of a good Agent is understanding the user's global goals.** 📏 Product researcher Jeremy points out in [Personal Agent evaluation criteria revisited](https://m.okjike.com/originalPosts/6b004eca136b2761c63e274d) that what matters for an Agent is not how long a task it can complete, but whether it can understand across stages what the user **truly wants**. Existing memory mechanisms follow a "**recency principle**", optimizing only recent local goals while ignoring global consistency. Developers designing Agent memory systems can reference this assessment.
