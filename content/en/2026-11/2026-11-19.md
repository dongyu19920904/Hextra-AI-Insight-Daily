### 5. OpenJDK Base64 Optimization Path Has Heap Memory Out-of-Bounds Vulnerability

**A remotely exploitable serious issue has emerged in the Java ecosystem.** Calif disclosed CVE-2026-114938 (Java4Shell), a [heap memory out-of-bounds vulnerability in OpenJDK's Base64 optimization path](https://calif.io/java4shell/). Malformed input can write out of bounds to heap memory before an exception is thrown. The research team demonstrated **unauthenticated remote code execution** on Keycloak, Jira, Confluence, and Jenkins. Affected versions start from **17.0.6**; ARM64 is unaffected. Installing a patched JDK is recommended; if immediate upgrade isn't possible, Base64 intrinsics can be disabled as a workaround. The team reported that AI assistance was used for vulnerability discovery and developing the first exploit prototype, with token costs **under $200** and total time of about three hours.

### 6. Two Nginx HTTP/2 Vulnerabilities Both Reach CVSS 9.2

**Nginx high-severity vulnerabilities require immediate upgrade.** Wiz disclosed CVE-2026-123633 and CVE-2026-123007. The former is a use-after-free issue in HTTP/2 connections, and the latter stems from flow control integer underflow. [Both can lead to unauthenticated remote code execution](https://www.wiz.io/blog/nginx-http2-rce-vulnerabilities), both rated **9.2** under CVSS 4.0. Both require the target to have HTTP/2 enabled. Affected versions are **1.9.5—1.31.8** and **1.19.7—1.31.8**. Versions 1.30.7 and 1.31.9 are patched; those unable to upgrade immediately can temporarily disable HTTP/2.

## **◎ Industry Changes and Personal Impact**

### Agent Collaboration in the AI Era Is Shaking WeChat's Core Logic

**Collaboration between humans and agents is thinning the moat of purely interpersonal products.** Jike user -Will pointed out in [this discussion post](https://m.okjike.com/originalPosts/6afe6668320fd7e1b576d82b) that WeChat's core value is built on the premise that value is created through human-to-human collaboration, but the AI agent era adds two new collaboration modes: **human-to-agent** and **agent-to-agent**. Over the past few years, WeChat's average usage time per user has dropped from over 80 minutes to over 70 minutes, propped back up by Channels and mini-games. But this time the pressure comes from a structural change in collaboration patterns themselves. For developers and product managers relying on the WeChat ecosystem for business, it is worth reassessing today which part of user stickiness truly comes from social relationships and which comes from information relay that could be replaced by agents.
