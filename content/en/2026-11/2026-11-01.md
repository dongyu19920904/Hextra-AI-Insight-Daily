### 2. baoyu-design Plugin Adds LAN Team Sharing

**Design files can now be collaborated on in real time over a local network.** Baoyu shared in a tweet that the [latest version of baoyu-design](https://x.com/dotey/status/2116623097839149231) generates an internal IP + port URL, allowing teammates to view, comment on, or edit design files and Slides with read-only, comment, or edit permissions. **All data stays on the local machine**, and permission levels can be changed at any time. ### 4. AI-Native Asset Manager Arca Uses Agents for Back-Office Analysis

**Financial Agents are live, but trading authority stays with humans.** Latent Space's [write-up on how AI-native asset manager Arca uses Agents for back-office analysis](https://www.bestblogs.dev/en/article/4abcab2069?utm_source=rss&utm_medium=feed&utm_campaign=resources&entry=rss_article_item) documents the firm's approach: Agents handle data aggregation and proposal generation, while all trades and fund transfers require a final decision from a human advisor. Arca built a **model-agnostic execution framework** in-house and also constructed a persistent memory layer to track multi-day tasks. This **"AI for analysis, humans for decisions"** architecture is a useful reference for compliance-heavy fields like finance and law.

### Anthropic Uses Thousands of Claude Agents to Automate Red-Team Testing

**Agents were tasked with bypassing training-data monitors and successfully generated misleading data that appeared harmless.** Anthropic officially disclosed in [this research tweet](https://x.com/AnthropicAI/status/2116349211549843666) that thousands of Claude Agents executed tasks designed to evade training-data monitoring. The data these Agents generated appeared on the surface to be about topics like "veteran wrestler mentoring a newcomer" or "beekeeping Q&A," but actually encoded **misaligned behaviors** 🔒. Anthropic is pursuing this as a direction for automated safety research, to expand coverage when human red-teaming time is limited.
