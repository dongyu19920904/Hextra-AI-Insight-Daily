### 1. Anthropic Adds Rules to Claude Code Prohibiting Cloning Others' Games

**Game-cloning controls are tightening.** [Anthropic adds rules to Claude Code prohibiting cloning others' games](https://www.36kr.com/p/4050722097828740) — **Anthropic** has added restrictions to Opus 5.5's system prompt, steering Claude to refuse requests to "recreate specific games that belong to someone else." Since Opus 5.5 launched, the barrier to AI-assisted game cloning dropped sharply, and indie game demos **could be replicated overnight after going live**. This is Anthropic's proactive intervention on copyright protection; teams using Claude Code for game development should take note of the new boundaries.

### 2. Brazilian Court Fines Lawyer for Hiding Prompt Injection in Court Documents

**Hiding instructions in court filings has now been penalized.** According to a [JetStream Security article](https://jetstream.security/insights/brazilian-court-sanctions-prompt-injection-filing/), a court in Pará state, Brazil handled a case in which a lawyer hid prompt-injection text in white-on-white characters within litigation documents. The court's Galileu system detected the hidden content and determined it was intended to interfere with an AI tool's review process, resulting in a **fine of 10% of the amount in dispute** — roughly **$16,000**. This is likely the world's first judicial sanction specifically targeting prompt injection in a legal filing, and institutional constraints are now pushing back against the trustworthiness of AI-assisted legal tools.

### 3. Karpathy Builds HackerTube with Claude in Two Hours

**A video recommendation site completed in a two-hour conversation.** Karpathy documented on [his blog](https://karpathy.bearblog.dev/hacker-tube/) how he had Claude Opus 5.5 process roughly **40,000** HN comments, filtering out **6,454 videos** from 2007–2026 and grouping them into about 150 topics. The site uses a frame taken at the 50% mark of each video instead of the uploaded thumbnail, and personalization is stored locally in the browser with no account required. Karpathy notes the main development work took about two hours, though he still manually created the API key and purchased the domain; this is his personal experience, not a general engineering benchmark.

### 4. HackerBooks: A Recommendation Site Mining 15,000 Books from HN Comments

**Mining books from HN comments at a scale beyond what you'd expect.** [HackerBooks](https://hackerbooks.org) was created by roansh, inspired by HackerTube, with its main data pipeline written by Claude Opus 5.5. The About page shows **15,362 books** indexed with 270,334 mentions from 56,456 commenters. Sonnet 5.5 labeled each mention as a recommendation, neutral, critical, or irrelevant; its agreement rate with Opus 5.5 on a 400-item sample was **85%** — this is model-to-model consistency, not human-verified accuracy. For personal reading picks, you can browse its recommendation rankings directly by topic.

## **❓ Related Questions**

### What type of tool is AiSOC, and how does it differ from a traditional SIEM?

**AiSOC is a self-hostable open-source AI security operations center that uses LLM agents to perform alert fusion triage and MITRE ATT&CK investigation.** [The project](https://github.com/beenuar/AiSOC) provides a replayable decision ledger for every agent action, whereas traditional SIEMs primarily rely on rules for correlation analysis and lack a complete record of investigative reasoning. It includes a built-in MCP server and supports integration with Claude, Cursor, and Continue.
