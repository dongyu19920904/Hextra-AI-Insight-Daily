### 10. [Paper: Random Cloud—Find Minimal Neural Network Architecture Without Training](https://arxiv.org/abs/2604.26830)

Current approach: train a big model, then prune it. Expensive. Random Cloud proposes an alternative: skip backprop entirely, use random initialization + random exploration + progressive structural compression to find the minimal feedforward network topology directly. Training cost near-zero, output quality reportedly matches traditional pruning. As compute gets pricier, "find structure without training" could reshape edge deployment and low-resource scenarios.
