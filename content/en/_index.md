### 2. [OpenAI Codex Launches Chrome Extension: Browsers Are Now Agent Territory](https://x.com/dotey/status/2052492340892221800)

Codex used to live in terminals and IDEs. Now it's moving into your browser. Mac and Windows users can now install the Chrome plugin in the Codex app, letting it run multi-tab tasks in the background without touching your active window. The real magic: it handles "stuff that requires login"—checking internal dashboards, refreshing CRM records, filling out multi-step forms that need authentication. Codex's strategy is "use plugins when possible, go through Chrome when login's required, mix both." This is the first time Agent reach truly extends into private, authenticated systems. EU and UK access pending, but the direction is crystal clear.

### 8. [Mirage: S3, Google Drive, Slack, Gmail—All Plugged Into One Virtual Filesystem](https://x.com/dotey/status/2052439472533295553)

Six weeks, rewrote bash, wrote 1.1 million lines of code. Mirage is a unified virtual filesystem for AI Agents.
