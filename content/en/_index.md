### 10. [Codex Long-Task Hands-On: 17 Hours of Reverse Engineering, How to Keep Agents on Track](https://x.com/dotey/status/2051673437727346838)

Running an AI Agent for 17 hours straight without crashes, drift, or needing you to type "continue" repeatedly—harder than it sounds.

dotey shared battle-tested methods: plan with Codex first, write acceptance criteria clearly; don't execute directly, save the plan as a doc, initialize Agents.md; find a real file as a template, show it "this is what done looks like"; run in phases, track progress each time.

Core insight: the goal isn't making Agents run longer, it's making them understand "what completion means." This playbook works for any long-running AI task, way more practical than most tutorials.
