### 5. Chrome 155 Starts Supporting JPEG XL Decoding

**Browser adds new image format.** [Official blog announces](https://developer.chrome.com/blog/jpeg-xl-in-chrome) Chrome 155 provides JPEG XL decoding. Can save roughly **30%-50%** file size vs JPEG. **Supports lossless compression**, HDR, and lossless transcoding from existing JPEGs. Implementation uses pure Rust decoder jxl-rs. Team states that after fuzzing and AI code review, no memory safety bugs🔒 have been found as of release.

### 6. Google Releases 740M-Parameter Multimodal Embedding Model

**Unified embedding space supporting five modalities.** [Official blog introduces](https://blog.google/innovation-and-ai/technology/developers-tools/embeddinggemma-2/) EmbeddingGemma 2 mapping text, code, images, audio, and video into a unified space. Total **740 million** parameters, modules loadable on demand. Supports 8K token context, up to roughly 5.5 minutes audio, 29 images, or 58 video frames. In Pixel 11 Pro quantized config, text-only active memory can drop to about **191 MB**.
