### 1. [OpenAI Releases GPT-5.4 Mini and Nano Models](https://m.okjike.com/originalPosts/69b9fb9229af73cea46cdac1)

Remember when running an Agent task would drain your token budget faster than you could say "lunch money"? OpenAI just distilled GPT-5.4's capabilities into two smaller models. Mini targets code assistance and sub-Agent execution layers—better code reasoning, multimodal support, full tool-calling; Nano goes extreme, handling classification and data extraction at just $0.20 per million tokens. Performance ranking: GPT-5.4 > Mini ≈ Nano > GPT-5 mini. For developers, this means "big brain plans, small hands execute"—Agent architecture finally has an official best practice. The wait-and-see crowd just won.

### 2. [Midjourney V8 Model Finally Drops](https://m.okjike.com/originalPosts/69b9f8a8c5a1d4e649d5e84f)

Currently testing on Midjourney's alpha site. For designers, this upgrade isn't about "drawing better"—it's about "drawing what you actually want."

### 3. [Claude Code Creator Shows You How to Master Skills](https://m.okjike.com/originalPosts/69ba030e6dafb2c0ff414b71)

Most people think Claude Code Skills are just a Markdown doc you dump in. Dead wrong. Anthropic's running hundreds of Skills internally—everything from API docs to deployment workflows—and the creators just spilled the beans. Skills are actually a folder that can hold scripts, resource files, data, even hook functions—Agents can discover, read, execute, and trigger them at specific moments. Anthropic mapped out nine Skill types; good Skills fit cleanly into one category, messy ones sprawl across several. If you're using Claude Code, this is required reading.

### 5. [Mistral Open-Sources Mistral Small 4: 119B MoE Model](https://x.com/Gorden_Sun/status/2033729603416756708)

Open-source just got another heavyweight. Mistral dropped Small 4—119B total parameters but only 6.5B active—classic MoE architecture, runs light and fast. Supports 256K context, text and image inputs. Honest take: benchmarks lag slightly behind Qwen3-Next-80B, gap widens vs. Qwen3.5 122B. Mistral's edge is European compliance-friendliness and solid inference efficiency. If your use case cares about latency and multilingual support, worth a shot.

### 6. [Codex Adds Subagents Support—Parallel Multitasking Finally Here](https://x.com/op7418/status/2033699960664039612)

Used to be with Codex, one task bottleneck meant the whole pipeline stalled. Not anymore. Codex now lets you spin up multiple sub-Agents running in parallel, switch windows to track each one's progress in real-time. Picture this: one Agent writing frontend, one fixing backend APIs, one running tests—you just sit back and watch the progress bars. For large projects, this is a quality-of-life upgrade that's actually a game-changer. OpenAI's getting serious about Agent infrastructure.

### 7. [Alibaba Open-Sources OpenSandbox: A Safe Playground for Agents](https://x.com/Gorden_Sun/status/2033941005368774953)

What's the scariest thing about running Agents? Them trashing your production environment. Alibaba's OpenSandbox solves that—isolated sandbox for Agents, multilanguage SDKs + unified API, Docker/Kubernetes deployment, built-in headless Chrome and Playwright automation. Best part? Direct support for Claude Code, Gemini CLI, Codex CLI and other mainstream Agents—basically plug-and-play. For teams wanting to run Agents in production without sweating bullets, bookmark this one.

![OpenSandbox Architecture](https://pbs.twimg.com/media/HDoCjpZaoAAPt7-?format=jpg&#x26;name=orig)

### 8. [Kimi Publishes Attention Residuals Paper—Rethinking Residual Connections](https://m.okjike.com/originalPosts/69b8a68b9f3cd84f65fc64ff)

Anyone doing deep learning knows residual connections are make-or-break—without them, deep networks won't train. But Kimi (Moonshot AI) just dropped a bold paper: what if residual connections' fixed, uniform weighting isn't actually optimal? They propose Attention Residuals—let the model learn how to aggregate information across depths. Someone visualized it with K2.5, super intuitive. If this architectural innovation pans out, the ripple effects could be massive.
