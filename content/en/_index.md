### 3. [OpenAI Codex App Lands on Windows: Native Sandbox Is the Game-Changer](https://x.com/dotey/status/2029308744795082981)

Windows developers have been waiting forever—it's finally here. Codex App runs natively on Windows and WSL, with full terminal support for PowerShell, Command Prompt, and Git Bash. But here's what matters: the sandbox mechanism. It's a textbook security move—locks down AI permissions at the OS level. The model can only write files in directories you specify, network requests are blocked by default unless you manually allow them. AI coding assistants having too much power has always been a hidden risk; Codex just showed everyone how to do it right. Plus, new WinUI and ASP.NET skills built specifically for Windows. OpenAI's even hiring for Windows full-stack engineers—they're swinging big.
