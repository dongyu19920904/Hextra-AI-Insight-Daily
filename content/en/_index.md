## **🔥 Top 10 Headlines**

### 1. [Claude Opus 4.6 and Sonnet 4.6 now support 1 million context window at no extra cost](https://x.com/Gorden_Sun/status/2032630022352285850)
Previously, handling massive projects meant either cutting context or paying double. Now Claude opens the 1 million token context to all users—no 2x markup for exceeding 200K tokens. Even better: cache hits cost less and throughput doesn't throttle with longer context. Single requests can now handle 600 pages of images and PDFs (up from 100). Opus 4.6 achieves 78.3% recall at 1 million context, crushing GPT-5.4's 36.6%. Max, Team, and enterprise users get Claude Code with 1 million context enabled by default—the 5x Max subscription suddenly looks like a steal.

### 2. [Cursor's two core leaders defect to join Musk's xAI to build coding products](https://x.com/dotey/status/2032242549574758636)
Cursor's engineering lead Andrew Milich and product lead Jason Ginsberg announced they're joining SpaceX/xAI, reporting directly to Musk. These two were the architects behind Cursor's rise from zero to $2B ARR, overseeing the web version, CLI, backend Agent, Cursor 2.0, and nearly every critical product milestone. AI coding is now a $5B+ market: Cursor $2B, Claude Code $2.5B, GitHub Copilot $1B+. xAI has the compute (Memphis's Colossus cluster with 100K H100s) and Grok 3, but was missing the team that actually scaled AI coding from zero to $2B. That puzzle piece just clicked into place—xAI's coding product timeline is now the biggest wildcard in the AI coding race.

### 3. [WIRED deep dive: Inside OpenAI's race to catch up to Anthropic in AI coding tools](https://x.com/dotey/status/2032266652893790437)
Reporters interviewed 30+ insiders, including Altman and Brockman, painting a rare picture: OpenAI is playing catch-up. Claude Code pulls in $2.5B+ annualized revenue, accounting for nearly a fifth of Anthropic's total revenue; Codex just crossed $1B as of late January. Last September, Codex usage was only 5% of Claude Code's; by January it had climbed to 40%. OpenAI shipped the original Codex back in 2021, but after ChatGPT's explosion, the coding team got scattered and resources poured into consumer products. Anthropic trained Claude Sonnet 3.5 on massive real-world codebases in early 2024; the June launch wowed developers. Brockman himself admitted OpenAI "started late" on training with real code repositories. GPT-5.2 finally helped Codex catch up, but the gap isn't closed yet.

### 4. [Google Maps gets a major overhaul: Ask Maps conversational Q&A + Immersive Navigation 3D experience](https://x.com/Gorden_Sun/status/2032470333580792293)
Finding a charging spot with no queue for coffee used to mean clicking through reviews one by one. Now Ask Maps handles complex, multi-condition, personalized queries and delivers answers with ETAs and real user tips. It taps into 300M+ location data points and 500M+ contributor reviews. Immersive Navigation is even more impressive—a brand-new 3D view that reflects surrounding buildings, overpasses, and terrain in real time. Key intersections show lane markings, crosswalks, traffic lights, and parking signs; smart zoom and transparent buildings help you anticipate tricky turns and lane changes. No more missed exits.

### 7. [Wholembed v3: Ultra-high-performance multimodal retrieval model](https://x.com/Gorden_Sun/status/2032402385566634302)
Retrieves text, images, audio, and video simultaneously, hitting top scores on both LIMIT and BrowseComp-Plus benchmarks. LIMIT tests semantic retrieval specifically—traditional lexical matching (BM25) crushes 1B-parameter models, and Wholembed is the first to beat BM25. BrowseComp-Plus measures whether a retrieval model helps Agents answer complex questions; higher scores mean better Agent support. Uses late interaction to balance precision and speed—precise like database queries, flexible like vector search.
