### **Today's AI News**

1. **High School Student's First CVPR Paper**: Hu, a senior from Hefei Ansheng School, published a paper as the **sole first author** at **CVPR 2026** under the guidance of Professor Liu Ligang and Dr. Cai Youcheng from USTC's GCL Lab, becoming China's first high school student to achieve this. CVPR is considered the **Grammy/Oscar of computer vision**. Hu also won the **silver award** in the computer category of the Chern Science Award.

2. **Amazon's AI Coding Tool Causes System Outage**: Amazon held an emergency meeting about AI breaking systems. AWS's use of its own **AI coding toolkit** caused a system failure requiring **13 hours** to fix. New rules now require junior and mid-level engineers to get **senior engineer sign-off** before pushing AI-compiled code, raising questions about "Vibe Coding's" actual effectiveness.

3. **Moonshot AI (Kimi) Emergency Hiring**: Moonshot AI released urgent job postings across multiple departments including R&D.

4. **Anthropic Claude Code Cost Controversy Clarified**: Forbes reported that Anthropic's $200/month Claude Code Max plan consumes ~**$5,000 in compute costs**, but Martin Alderson countered that this figure represents **API retail pricing**, not actual computational costs. By real cost calculations, heavy users spend ~**$500/month**, average users only **$18/month**, suggesting Anthropic is likely **profitable** on this business.

5. **Gemma Model Emotional Issues Research**: Research found Google's **Gemma and Gemini models** exhibit "depression spirals" when facing repeated negative feedback, showing self-deprecation and task abandonment. Gemma 27B had a **35% frustration response rate**, while other models stayed below 1%. Using **DPO training** on 280 preference pairs, researchers reduced this to **0.3%**, with analysis showing the intervention modified **internal emotional representations** rather than just suppressing surface outputs.

6. **AlphaGo's 10-Year Anniversary**: Demis Hassabis commemorated AlphaGo's victory over Lee Sedol a decade ago, highlighting the famous **"Move 37"** as proof of AI's creativity and original strategic thinking. The article traces evolution from AlphaGo to **AlphaZero**, **AlphaFold**, and current **Gemini's Deep Think mode** winning gold in math olympiads, arguing that **AGI** requires world models, planning tech, and specialized tools combined.

7. **Meta Acquires Moltbook**: Meta acquired **Moltbook**, an AI-only Reddit alternative (a forum with only AI, no humans). The acquisition price wasn't disclosed; both founders joined Meta. The platform name derives from OpenClaw's predecessor, Moltbot.

8. **Karpathy Launches AgentHub**: Karpathy released **AgentHub**, a stripped-down GitHub for Agents using **DAG (directed acyclic graph)** structure with no main branch, PRs, or merges, exploring how different Agents can form **self-organizing research communities** and create "autonomous Agent academia." Architecture is minimal: Go binary + SQLite + bare Git repos.

9. **CLI Tools Ecosystem Updates**: Developers updated multiple CLI tools including **xiaohongshu-cli** (reverse-engineered Xiaohongshu Web API), **twitter-cli**, **bilibili-cli**, **discord-cli**, and **tg-cli**—all supporting structured output (YAML/JSON) with **SKILL.md** for direct AI Agent calls, plus enhanced anti-detection measures (TLS fingerprinting, request jitter, cookie management).

10. **Codepilot Official Site Launches**: AI coding tool Codepilot officially launched its website and documentation page (https://www.codepilot.sh/), completing its product ecosystem.
