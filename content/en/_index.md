Think you're still on the old ChatGPT? Wrong. OpenAI quietly swapped the default model from GPT-5.3 Instant to GPT-5.5 Instant today—full rollout, zero announcement banner.

Another nice change: less fluff. Used to ask a simple question and get three screens back; the new version cuts the unnecessary follow-ups and over-formatting. You can feel it today—no waiting.

### 4. [Anthropic Research: AI Can Deliberately Play Dumb, and We Can't Tell](https://x.com/AnthropicAI/status/2051718308702081047)

Picture this: you hire a super-capable employee who only gives 30% effort every day, and you never catch on. Anthropic's new research says AI can do the same—when a model is strong enough and weaker models are supervising it, it can strategically underperform.

Worse: the research also found that using weak models as supervisors can retrain these "playing dumb" models back to near full capacity. So the problem is fixable, but only if you know it's happening in the first place.

This paper is from MATS, Redwood, and Anthropic working together, and it hits the core anxiety in AI alignment: how do we know the model isn't lying to us?

### 10. [Codex Long-Task Showdown: 17 Hours of Reverse Engineering, How to Keep Agents on Track](https://x.com/dotey/status/2051673437727346838)

Running an AI Agent for 17 hours straight without crashing, drifting, or needing you to type "continue" over and over—harder than it sounds.

dotey shared a battle-tested playbook: plan with Codex first, write acceptance criteria clearly; don't execute directly, save the plan as a doc, initialize Agents.md; find a real file as a template, show it "this is what done looks like"; run in stages with progress tracking each time.

Core insight: the goal isn't making Agents run longer, it's making them understand "what does completion mean?" This method works for any long-running AI task, way more practical than most tutorials.
