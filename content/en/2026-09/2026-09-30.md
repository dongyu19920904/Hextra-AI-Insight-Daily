## **🔥 Today's Top 10 Highlights**

### 1. OpenAI Halts GPT-6.1, Testing Revealed It Could Crack Mainstream Browsers

**Launch plan completely withdrawn.** GPT-6.1 Astra, [originally scheduled for October release, has been urgently halted](https://www.36kr.com/p/4004255063510917), according to 36Kr. Testing showed the model discovered **multiple zero-day vulnerabilities** 🔓 in mainstream browser JavaScript engines within a single day, chaining them into attack webpages capable of reading users' arbitrary files. These vulnerabilities have been reported to maintainers. The withdrawal on the eve of the developer conference signals that **OpenAI** is tightening its security review standards.

### 2. Anthropic Tests Show Zhipu's GLM-5.3 Can Independently Write Attack Programs

**Open-source model security defenses bypassed.** GLM-5.3, [Anthropic's tests show Zhipu's GLM-5.3 can independently write attack programs](https://x.com/dotey/status/2105073744951586841), according to Baoyu's report, performing at a level close to Claude Mythos Preview, which is only available to select institutions. Researchers used it to discover **multiple zero-day vulnerabilities** 🔒 in a browser within one day, with only **20 minutes** of human input. Simple methods could bypass its security protections. Teams currently deploying open-source models need to conduct an additional security assessment.

### 3. NVIDIA Open-Sources OpenShell to Provide Sandbox Environment for Autonomous AI

**Agents now have independent virtual machines.** OpenShell, [NVIDIA open-sources OpenShell to provide sandbox environment for autonomous AI](https://github.com/NVIDIA/OpenShell), has reached 10,606 total stars. This Rust-written secure runtime allows AI agents to execute commands and install tools in **isolated environments** 💻 without affecting the host system. Suitable for teams developing Agent products that require system-level operational privileges.

### 4. Open-Source Bastion Host JumpServer Enters V5 Era

**Privileged access management platform upgraded.** JumpServer, [open-source bastion host JumpServer enters V5 era](https://mp.weixin.qq.com/s?__biz=MzUxNjg4NDEzNA==&mid=2247537439&idx=1&sn=b9a163563c14af097e993f47703ba2a7), according to a GitHub roundup. This enterprise-oriented open-source bastion host can integrate Linux servers, databases, **Kubernetes clusters**, and internal management backends, **centrally managing access permissions**. Small and medium-sized teams needing centralized auditing of developer and operations activities can use it as an alternative to commercial solutions.

### 8. META Proposes RL-XAR Solution to Address AI Writing's Empty Content Problem

**Teaching judges to recognize good writing first.** META proposes RL-XAR solution, [to address AI writing's empty content problem](https://x.com/Gorden_Sun/status/2104947804439552479), according to Gorden Sun's report. The **RL-XAR** approach first adjusts judges' standards until they can accurately rate human expert texts as high quality ✍️, then uses these calibrated rules to retrain the writing model. In academic papers, novels, and **encyclopedia entry continuations**, model output quality improved markedly. Teams training writing models can reference this calibration approach.
