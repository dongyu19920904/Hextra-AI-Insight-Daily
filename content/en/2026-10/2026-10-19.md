### 3. DeepSeek Launches Search and Web Extraction APIs

**Standalone endpoints for agent use.** DeepSeek's [API documentation introduces two JSON endpoints](https://api-docs.deepseek.com/guides/search/): Search, which uses a proprietary search engine to return web results, and Fetch, which extracts a specified web page as Markdown 🔍. Pricing is **$0.75 per thousand successful requests**, charged only when a call succeeds and returns results. Both endpoints use DeepSeek API key authentication and do not need to be wrapped inside model generation calls. Starting **November 1 (Beijing time)**, calls made through Harness, Claude Code, or Codex will be billed per request.

### 5. Sphinx Tests Whether Developers Understand AI-Generated Code Before They Push

**Uses Q&A to ensure comprehension before merging.** [The Sphinx project](https://sphinx-six-theta.vercel.app/) is a Git hook that pauses pushes to protected branches. A separate review model reads the diff and asks the developer to **predict behavior, failure modes, or invariants** 🔒. If the answer is wrong, it explains the issue and presents a new scenario; the push proceeds only after a correct response. The project's demo on its homepage discusses payment retry logic and event ID ordering. The README emphasizes this is a practice tool, not a security gate, and notes that local hooks can be bypassed. Requires Node.js **22.19** or later.

### 7. Who Calibrates the AI Benchmarks Themselves?

**Evaluations should be short-lived, grounded, and specific.** TypeSafe AI discusses [the reliability paradox of AI benchmarks](https://www.bestblogs.dev/en/status/2111875713737380347?utm_source=rss&utm_medium=feed&utm_campaign=resources&entry=rss_article_item) in a post. The author argues that good evaluations should be **ephemeral** (representing only a snapshot of capability at a given point in time), **grounded** (directly measuring performance on business-relevant tasks), and **specific** (evaluating target outcomes rather than proxy metrics) 📊. Drawing an analogy to superconducting qubit calibration charts, the post points out that a system used to verify accuracy must itself ensure its own accuracy.
