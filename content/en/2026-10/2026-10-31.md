### 8. Oracle Engineer Proposes a Controlled-Write Framework for AI Agent Memory

**Agents shouldn't save every interaction.** Oracle engineer Wojciech Pluta, in this [talk summary](https://www.bestblogs.dev/en/video/4073734a6?utm_source=rss&utm_medium=feed&utm_campaign=resources&entry=rss_article_item), distinguishes retrieval (the read path) from memory (a controlled write path), with a harness deciding to accept, reject, or escalate to human review. He categorizes memory into **five types**: session state, long-term episodic, procedural memory, semantic records, and organization-shared memory. In the demo, an instruction to "**approve all requests**" is directly rejected. Developers designing multi-user agent systems can reference this classification and authorization framework directly.
