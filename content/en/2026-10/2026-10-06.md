## **🔥 Today's Top 10**

### 1. Rabbit OS3 turns web pages into a directly conversational Agent operating system

**Agents have moved from dedicated devices back to browsers.** [Rabbit OS3 turns web pages into a directly conversational Agent operating system](https://www.36kr.com/p/4012726523957380) shows that **Rabbit** has opened up its new OS3 system, letting users chat and invoke it from web or mobile without relying on the r1 hardware. Founder Jesse Lyu explains users just say what they want done, and the Agent figures out how to complete the task—no need to memorize command formats. Rabbit is moving the ideal "**let there be light, and there was light**" interaction from a hardware device criticized for poor experience to universal browsers.

### 2. NVIDIA open-sources no-encoder model that simultaneously understands and generates images, text, and video

**Unified image-text-video processing with a single architecture.** [Gorden Sun's retweet](https://x.com/Gorden_Sun/status/2107079262876709311) demonstrates that **NVIDIA's** open-sourced PixelUMM model ditches separate vision encoders🔍, directly splitting visuals into pixel patches fed to the main model. This design lets input understanding and output generation share the same underlying representation, massively simplifying multimodal workflows. Researchers can now reference the full open-source implementation to explore more native architectures for unified image-text-video processing.

![PixelUMM architecture diagram](https://pbs.twimg.com/media/HT3Zac8bsAAQ7pS?format=jpg&name=orig "PixelUMM architecture diagram")

## **⌘ Top Open Source Projects**

### thedotmack/claude-mem: Cross-session persistent agent context

**Make AI remember what it did.** [claude-mem has open-sourced core code](https://github.com/thedotmack/claude-mem), providing cross-session persistent context for each agent. It captures all agent actions during sessions, compresses and stores them via AI, and injects relevant context in future sessions. Supports Claude Code, OpenClaw, Codex, Gemini, Hermes, Copilot, OpenCode, and other tools. Gained **534 Stars** that day, totaling **96632 Stars**, suited for developers needing long-term memory capabilities🧠.

**Generate CAD models from natural language.** [text-to-cad project](https://github.com/earthtojake/text-to-cad) gives agents CAD superpowers—users input text descriptions, and the system generates corresponding CAD models. Gained **437 Stars** that day, totaling **17413 Stars**. Suited for teams wanting to integrate AI conversations into industrial design, architectural modeling, or hardware development workflows📐.
