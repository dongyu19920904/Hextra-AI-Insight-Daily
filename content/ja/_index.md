### 3. [Cursor 3 上线 /multitask，多个 Agent 同时跑不用排队](https://x.com/dotey/status/2047790274949132357)

以前用 Cursor 跑 Agent 任务，就像在银行柜台排号——前一个没完，后一个只能干等。现在不用了。

Cursor 3 推出 `/multitask` 功能，支持同时启动多个异步子 Agent 并行处理任务。更贴心的是，已经在排队中的任务也可以随时切换成并行模式，不用重新提交。对于同时在跑多个代码模块、多个文件重构的开发者来说，这个更新直接把等待时间砍掉了一大截。

AI 编程工具的竞争，已经从"谁的模型更聪明"卷到了"谁的工作流更顺手"。

### 7. [PRD 要不要单独写一版给 Agent 看？这个问题本身就是答案](https://x.com/dotey/status/2048212030482509960)

有人问：现在写产品需求文档，要不要专门写一版给 Agent 用？

dotey 的回答很直接：没必要。理由是——如果人能看懂，模型更应该能看懂；如果 PRD 可以直接给 Agent 执行，那大部分场景程序员的角色就变了；而且很多场景下，几句话直接让 Agent 实现，比写 PRD 更快更好。

这个讨论戳到了一个真实的行业焦虑点：当 Agent 能力越来越强，传统软件开发流程里的哪些环节会先消失？PRD 可能只是个开头。
