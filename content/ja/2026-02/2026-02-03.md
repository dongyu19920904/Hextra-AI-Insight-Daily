### 3. [李想が 2025-2026 年最も革新的な AI 製品をリストアップ：GUI Agent が主役](https://x.com/dotey/status/2018241889275670770)

李想が朋友圈に投稿し、6 つの製品を指摘した：Claude Code、豆包手机、Manus、OpenClaw、MoltBook、Chrome Gemini。一見無関係に見えるが、背後では同じ問題を解決している——AI に本当に仕事をさせるにはどうするか。答えは GUI Agent だ：AI が直接画面を見て、クリックをシミュレートし、アプリが API を公開していない問題を回避する。ユーザーは Jarvis を望んでいるが、Jarvis はどこに行っても門前払いを食らう。GUI Agent はその万能鍵だ。

### 4. [DeepThink オープンソース化：Gemini 3 Pro DeepThink を模倣した複数専門家協力システム](https://linux.do/t/topic/1557953)

Gemini 3 Pro DeepThink のオリジナル版は高すぎて、動作もブラックボックスだ。そこで有志が自分たちでオープンソース版を作った。複数専門家の動的協力、Planner が問題の複雑さに応じて 2～7 人の専門家を自動配置し並列処理する。Exa と Tavily 検索を統合し、リアルタイムで最新情報を注入する。WebSocket ストリーミングで各専門家の独白、ドラフト、推論チェーンを配信し、深い思考プロセス全体を見守ることができる。OpenAI API 互換、フロントエンドとバックエンドが分離され、保守と拡張が容易だ。貧乏人の DeepThink、本当に素晴らしい。

### 8. [Claude Code 使用テクニック：Anthropic 内部総括、並列作業が最大の秘訣](https://m.okjike.com/originalPosts/6980a770c5a1d4e6496677ac)

Claude Code の作成者 Boris が再び Anthropic 内部総括の使用テクニックを共有した。最大の秘訣は並列作業だ：同時に 3～5 個の git worktree を開き、各々が独立した Claude セッションを実行する。複雑なタスクはまず計画を立て、CLAUDE.md を維持することは長期投資で、繰り返し操作をスキルに変える。もう 1 つの裏技がある：Claude に自動的にバグを修正させ、Slack MCP を有効にし、バグ討論スレッドを貼り付けて、「修正して」と言うだけだ。コンテキストを切り替える必要がない。

### 9. [即刻が超級椰子をリリース：AI 音声入力法、Prompt モード対応](https://x.com/vista8/status/2018270395028181094)

即刻が超級椰子という AI 音声入力法をリリースした、Typeless と闪电说に似ている。転写と Prompt の 2 つのモード対応、ローカルとクラウドモデルがある。入力ボックスの中にいなくても使え、Raycast AI Shortcut 音声版のようだ。記事を選んで音声で「要約して」と言うと、任意のテキスト、画像、スクリーンショットが Prompt 処理に対応する。スクリーンショット機能の出来が良く、スクロール翻訳、矢印注釈、モザイク、ウォーターマーク追加、実用性が高い。現在 Mac 版のみ。
