### 10. [LLM が Web API を呼び出すのはまだ不安定だが、解決策を見つけた人がいる](https://x.com/omarsar0/status/2003570764868649154)

みんなコードモデルが API を呼び出すのは簡単だと思っていますが、実際にテストしてみると、オープンソースモデルで 40% 以上のタスクを解決できるものはありません。URL の幻覚率は 14～39% に達しています。原因は Web API が普通の関数呼び出しと大きく異なるからです。HTTP メソッド、長い URL、ネストされたパラメータ型など、モデルは覚えられません。良いニュースは、研究者が制約付きデコード方案を提案したことです。OpenAPI 仕様を正規表現制約に変換すると、正確率が直接 90% に上がります。
