### 1. [OpenAI が Prism をリリース：科学者向けの AI ワークスペース](https://x.com/dotey/status/2016223577112989873)

論文を書く人なら誰もが知っている苦しみ：数式を打ち込んで手が痙攣し、参考文献の管理がめちゃくちゃになり、TikZ で図を描くのに午後中かかる。今、OpenAI は GPT-5.2 をクラウド LaTeX エディタに直接組み込みました。論文全体の文脈を理解できます——章、数式、図表の間の論理関係を理解し、単に一段落のテキストを見て適当に変更するのではありません。さらに凄いのは、ホワイトボードに手書きした数式を写真に撮るだけでコードに変換できることです。Kevin Weil ははっきり言いました：2025年 AI はソフトウェア開発を変え、2026年は研究の番です。すべての ChatGPT ユーザーが無料で使用できます。

### 9. [MCP はプロトコル、Agent Skills は規範：1枚の図で明確に説明](https://x.com/dotey/status/2016197577771831575)

多くの人が MCP と Agent Skills の違いを区別できません。簡単に言うと：MCP はプロトコルで、Agent が様々なツールに接続でき、「能力」を獲得できます；Agent Skills は規範で、Agent が自分がどんなスキルを持っているか知り、必要な時にオンデマンドでロードできます。知識は Skill の一部として機能でき、Skills は Agent に MCP ツールを呼び出すよう指導できます。この図は非常に明確に説明しており、保存することをお勧めします。
