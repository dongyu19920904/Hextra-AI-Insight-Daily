### 2. [CodePlan ユーザーが国産モデルで Claude を代替し始めた](https://linux.do/t/topic/1502664)
**Claude サプライチェーン危機の間、CodePlan のユーザーは慌てなかった。** 過去半月間、GPT/Gemini + 国産オープンソースモデルのトークン使用量はすでに Claude シリーズをはるかに超え、毎日の消費量も増加中。**これは何を意味するか？国産モデルのプログラミングシーンでの実戦能力はもう通用する。** CodePlan は複数モデル API プロトコルのクロス互換性変換を通じて、ユーザーが Claude 品切れ時に他のモデルにシームレスに切り替えて作業を続けられるようにし、返金ゼロ、クレーム極少。Anthropic よ、お前は勝ったが、俺たちは負けていない。

### 3. [TELOS フレームワーク：AI に本当にあなたを理解させる「北極星」](https://x.com/vista8/status/2014405967023374392)

### 4. [Claude Code を自己学習進化させるちょっとしたコツ](https://x.com/vista8/status/2014401267553235123)
**バグを修正するたびに、Claude に経験をグローバルメモリに書き込ませる。** Claude.md は毎回ロードされるため、経験を反思・要約することで次回のエラーを避けられる。ただし、公式は全体的な Claude.md が 200 行を超えないことを推奨しているため、サブファイルにして Claude.md インデックスに置き、経験を確認するタイミングを指示して token 浪費を避けるのが最善。**これは AI に「間違い帳」を装備させるようなもので、使うほど賢くなる。**

### 6. [Google 論文：同じ質問を 2 回すると、Gemini の精度が 5 倍向上](https://linux.do/t/topic/1502485)
**これはジョークに聞こえるが、実は効く。** Google の論文が発見したのは、推論をしないまたは推論をオフにしたモデルの場合、質問を繰り返すことで精度が向上し、長さと応答速度に影響しないということ。**原理は何か？** モデルが 2 回目に質問を見たとき、コンテキストをより良く理解できるのかもしれない。ただし、推論思考が必要な問題には向上がなく、悪化もしない。シンプルで粗いが、効く。

### 7. [宝玉の Claude Code 使用経験：コンテキスト満杯を避ける](https://x.com/dotey/status/2014395924143820896)
**コンテキスト圧縮は Claude Code で最もイライラさせる部分。** 宝玉が共有した経験：自動圧縮をオフ、中間結果をファイルに保存、1 つのセッションで 1 つのことだけ、詰まったら Git でロールバック。**コア原則は：チャットをメモリに、ファイルをハードディスクに、Git をタイムマシンに。** このやり方で Claude Code での作業がより効率的になり、毎回 2 分間のコンテキスト圧縮を待つ必要がなくなる。
