### 2. [Claude Code が自動的に X に投稿：Agent スキルの進化](https://github.com/JimLiu/baoyu-skills)
**記事を書いたら手動で投稿？ダサすぎる。** 開発者 @JimLiu が @wshuyi の Playwright MCP に基づいて実装した Claude Code スキル：Agent が Markdown 記事を直接 X（Twitter）に投稿でき、長文と画像の自動アップロードに対応。さらに投稿前にプレビューできる。**重要なのは実際の Chrome ブラウザを使ってアンチスクレイピング検出を回避し、アカウント停止されない。** インストールはワンコマンド：`npx add-skill jimliu/baoyu-skills`。その後 Claude に「この記事を X に投稿して」と言うだけ。**これが Agent の正しい使い方：AI に退屈で面倒な仕事をさせる。**

### 4. [Zhipu オープンソース SCAIL：静止イラストを「生き生き」させる、3D スケルトン駆動の二次元](https://github.com/zai-org/SCAIL)
**以前はアニメーション作成に「ガチャ」（複数回生成して使える部分を探す）が必要だったが、今は 3D スケルトンで直接制御。** 清華大学チームと Zhipu GLM が共同でオープンソース化した SCAIL フレームワークは、静止イラストやキャラクターを映画レベルの動的ビデオに変換でき、複雑なアクション転移と複数人インタラクションに対応。**コア技術は 3D シリンダースケルトン表現 + 全コンテキスト注入メカニズムで、複雑なオクルージョンシーンでの肢体構造完全性が 47% 向上。** 海外プラットフォームの再生数 267 万回。フランスの芸術家 @NebSH がそれを使って落書きを踊らせ、B 站のクリエイターは「次元の壁を破る」バーチャル格闘シーンを作成。**3D から 2D へ、2D から 3D へ、二次元クリエイターは大喜び。**

### 5. [Black Forest Labs が FLUX.2 [klein] をリリース：最速の画像生成モデル](https://bfl.ai/models/flux-2-klein)

### 6. [Codex vs Claude Code：開発者の「派閥分け」の時](https://x.com/dotey/status/2012590417250857467)
**コード作成は Codex、その他のタスクは Claude Code。** 宝玉老師の実戦経験：Codex CLI は使いにくいが、モデルはコード作成が安定で Token 量が大きい；Claude Code は使いやすいが、コード作成は Codex ほどではなく、汎用タスク実行がより優れている。**OpenAI Codex チームは反省すべき。こんなに優れたモデルを持ちながら、毎日華やかだが実用的でない更新をしている。** この比較は本当にリアル。開発者は今、タスクの種類に応じてツールを切り替える必要があり、「万能王」は存在しない。

### 9. [Quarkdown：Markdown にタイポグラフィとプログラミング機能を付与](https://github.com/iamgio/quarkdown)
**Markdown と LaTeX の中間形態。論文作成から PPT 作成まで対応。** Quarkdown は Markdown の読みやすさを保ちながら、プログラミング言語のような論理制御とタイポグラフィ機能を導入（変数、条件判定、ループ、関数）。**コンパイル後は HTML、PDF、スライドショーを生成でき、ページ分割、ヘッダーフッター、ページ番号制御に対応。** Markdown のシンプルさは好きだが、タイポグラフィ機能に不満を感じるユーザーに最適。コードを書く方法で本を書き、論文を書き、PPT を作成。
