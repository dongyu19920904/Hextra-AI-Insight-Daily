## 今日主推
### [不会写代码，也能用 Cursor 做出一个能玩的小游戏](https://x.com/Gorden_Sun/status/2058939766742335643)

有人昨天用 Cursor 做了一个真能玩的飞机射击游戏，发出来之后评论区全是"这也行？"。2D 游戏这件事，以前门槛在代码，现在门槛在"你知不知道可以这么做"。

买家今天心动的原因很简单：看到别人做出来了，自己也想试，但不知道从哪开始、怎么配、第一步干嘛。你卖的就是这个"第一步"——一个 Cursor 账号，加一份"做出你第一个 2D 小游戏"的上手包。

卡牌、塔防、对话类、回合制，挑一个最简单的场景做成模板，截图或录屏证明跑通了，今晚就能挂。

- 参考来源：[Cursor 做飞机射击游戏原帖](https://x.com/Gorden_Sun/status/2058937631246057796) / [AI 利好 2D 游戏开发分析](https://x.com/Gorden_Sun/status/2058939766742335643)
- 适合谁：想做点小东西、不会写代码、看到别人做出游戏就心动的人；也适合想给孩子做个小玩具的家长
- 这钱从哪来：买家看到"真人用 Cursor 做出了能玩的游戏"，第一反应是"我也想试"，但自己摸索要踩很多坑——你卖的是省掉这段折腾，直接拿到一个能跑的起点
- 最简单卖法：Cursor 账号 + "做出你第一个 2D 小游戏"上手包（含场景选择建议、提示词模板、跑通截图），打包成一单
- 今天先做哪一步：用 Cursor 自己先跑通一个最简单的 2D 场景（比如对话类或塔防），截图或录 30 秒屏，这就是你的商品封面
- 今天就能发的文案：「有人昨天用 Cursor 做了个真能玩的飞机游戏，不是 demo，是真的能打。2D 游戏现在门槛低了很多，卡牌、塔防、对话类都能做。我整理了一份上手包，账号+模板+提示词，拿到就能开始。想试的扣 1」
- 配图建议：用原帖里飞机游戏的截图或录屏，或者自己跑通的游戏画面截图；比任何文字都有说服力

## 本周可试
### [AI 生成内容发不出去？这个一键部署工具帮你解决](https://x.com/vista8/status/2058939593588949066)

AI 生成的 HTML 页面、Markdown 文档、SVG 图表，微信根本发不出去——这个痛点每天都在发生，但大多数人不知道有工具能解决。这个 Cloudflare 一键部署版的分享工具，刚更新了管理后台，时机刚好。

现在还不用重投入，因为买这类工具的人需要先被教育"原来可以这样"，转化链路比游戏那单慢一拍。先发一条科普帖测反馈，有人问再挂服务。

- 参考来源：[vista8 原帖](https://x.com/vista8/status/2058939593588949066) / [GitHub 项目页](https://github.com/garrytan/gstack)
- 适合谁：经常用 AI 生成内容、但苦于微信分享不方便的内容创作者、自媒体、写稿人
- 先怎么试：先发一条"AI 生成的页面怎么发给别人看"的科普短帖，文末带一句"有需要帮你部署的扣 1"，观察有没有人问；有人问再整理成代部署服务挂单
- 为什么先别冲太猛：这个需求真实，但买家还没被充分教育——很多人不知道自己有这个痛点，需要先被内容触达，再转化成付费意愿；现在适合用内容引流，不适合直接重仓备货
- 配图建议：截一张"AI 生成的 HTML 页面变成可分享链接"的前后对比图，左边是代码，右边是干净的预览链接
