## 今日主推
### [Claude Agent 用完就忘？帮你配好"记忆"，下次接着干](https://github.com/thedotmack/claude-mem)

用 Claude Code 或各种 Agent 工具的人，最头疼一件事：每次开新会话，AI 全忘了，上次说好的风格、偏好、项目背景，重新说一遍。claude-mem 就是专门解这个问题的——它把 Agent 每次干了什么压缩存下来，下次自动带进去，不用你再重复交代。

问题是，这东西要自己装、自己配，对小白来说就是一道坎。你今天把它跑通、截图、录个30秒演示，就是一个能卖的东西了。

- 参考来源：[claude-mem](https://github.com/thedotmack/claude-mem) / [cc-switch（多工具切换助手）](https://github.com/farion1231/cc-switch)
- 适合谁：已经在用 Claude Code、OpenClaw、Codex 或 Gemini CLI 的人，但每次开新对话都要重新交代背景，烦了
- 这钱从哪来：买家今天的痛点很具体——AI 没记忆，重复劳动。claude-mem 刚出来，中文教程几乎没有，你做第一个中文跑通版，信息差就是钱
- 最简单卖法：跑通包，交付内容：中文安装说明 + 配置截图 + 一个可直接复用的配置模板 + 基础答疑。低价引流款先挂 9-19 元，验证有人问再出代配置服务款
- 今天先做哪一步：先把 claude-mem 本地跑通，截两张图——一张"没记忆时重复交代"，一张"配好后自动带入上次内容"，对比图就是最好的商品主图
- 今天就能发的文案：「用 Claude 写东西，每次开新对话都要重新说一遍你是谁、项目是什么——烦不烦？有个工具专门解这个，叫 claude-mem，帮 AI 记住你。中文跑通版整理好了，9 块钱，直接用。」
- 配图建议：左右对比截图最直观——左边是新会话 AI 一问三不知，右边是配好 claude-mem 后自动带入上次上下文。用真实终端截图，不要做成 PPT 风格

## 本周可试
### [谷歌自己说 Coding 落后了——这时候卖"Claude vs Gemini 代码对比包"最顺手](https://www.36kr.com/p/3823020763746435)

谷歌 CEO 皮查伊公开承认 Gemini 在 Coding 上落后，这句话本身就是一个天然的对比钩子。现在有一批人正在纠结：我该用 Claude Code 还是 Gemini CLI？这个问题没有标准答案，但你可以卖"我替你先试过了"的对比包。

苗头是有的，但现在还不用重投入——因为这类对比内容保鲜期短，等官方有新动作随时要更新。先做一个轻量版，试发看反应，有人问再加深。

- 参考来源：[谷歌CEO承认Coding落后了](https://www.36kr.com/p/3823020763746435) / [橘鸦AI早报 2026-05-25](https://imjuya.github.io/juya-ai-daily/issue-101/)
- 适合谁：在用 AI 写代码、做自动化的人，正在选工具，不想自己一个个试
- 先怎么试：做一个 2-3 页的中文对比清单——同一个任务，Claude Code 和 Gemini CLI 各跑一遍，截图对比结果、速度、报错频率。先发朋友圈或社群，看有没有人问"能不能发我一份"
- 为什么先别冲太猛：谷歌说落后不等于 Gemini 就废了，后续可能很快更新反转；对比内容时效性强，做太重容易白忙。先做轻版验证需求，有成交再出完整版
- 配图建议：截两个工具处理同一段代码的结果截图，并排放，加一行小字"同一个任务，两个工具，差距在这里"——真实截图比任何设计都有说服力
