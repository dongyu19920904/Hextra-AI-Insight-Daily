## 直接结论

- **直接答案：** 今天有三个能跑通的开源项目，但都缺少中文用户的真实付费证据。优先验证知识图谱代跑通服务是否有人要。
- **做不做：** 先做 graphify 的测试环境样品，用 48 小时确认有没有开发者愿意为省搭建时间付钱。没有就立刻停，不要凭热度硬推。
- **先验证：** 今天在本地跑通 graphify 并记录失败点,明天拿样品去访谈 3-5 位正在手工整理代码文档的开发者,看他们是否愿意为代跑通或代配置付费。
- **何时停：** 如果 5 位目标用户都表示自己能搞定或不愿意为这个结果付钱,或者本地复现失败无法解决,立刻停止。

## 今日主推

### 验证代码库知识图谱跑通服务有没有人要

**今天最大的变量是三个开源项目都能本地运行,但没有人证明中文开发者愿意为跑通它们付钱。** graphify 可以把代码库、文档和配置转成可查询的知识图谱,支持 Claude Code 和 Cursor 等工具。项目本身能跑,问题是谁会为省搭建时间付费、付多少、复购逻辑是什么,这些都要先验证。

- **证据与可信度：** 中。[graphify 官方仓库](https://github.com/Graphify-Labs/graphify)证明项目存在、本地可运行、支持多种 CLI 集成。本次候选输入未提供用户付费记录、issues 中的实际需求讨论或中文用户的复现案例。
- **鱼塘与笨办法：** 待验证假设：正在维护多个代码库、需要频繁查文档或配置关系的开发者,可能正用手工搜索、复制粘贴或反复问 AI 来理解代码结构。
- **最小交付：** 商品雏形名称：代码库知识图谱跑通包。交付内容包括：在买家指定的测试代码库上运行 graphify 并生成可查询图谱、提供本地复现说明、记录失败点和环境要求、明确不包含后续维护和二次配置。买家可检查的验收结果：能在本地或测试环境看到生成的知识图谱,能通过 CLI 查询到代码关系。
- **48小时验证：** 今天在本地跑通 graphify 并用一个真实代码库测试,记录安装耗时、失败步骤和依赖问题。明天找 3-5 位正在手工整理代码文档或频繁查配置的开发者,展示跑通样品并询问:「如果我帮你在测试环境跑通这个,你愿意付多少钱?」观察他们是否表达付费意向、询问具体范围或直接拒绝。
- **第一单与复购：** 测试标题:「帮你在测试代码库上跑通知识图谱查询,省搭建时间」。第一单固定范围:只跑通一个指定代码库、只在测试环境、只交付一次性结果和复现说明,不包含后续更新、多项目配置或长期答疑。复购可能性:如果买家有多个代码库或需要定期更新图谱,可以按项目或按月提供更新服务;如果只是一次性需求,更像一次性单。
- **风险与停止：** 售后/合规风险中。graphify 使用的许可需要核对,依赖项、商标和二次分发边界需要确认。停止条件:如果 5 位目标用户都表示自己能搞定或不愿意为这个结果付钱、本地复现失败无法在 48 小时内解决、或者发现许可条件不允许商业代跑通,立刻停止。

## 本周小试

### 验证文档转 Wiki 部署包有没有人要

- **证据来源：** [llm_wiki 官方仓库](https://github.com/nashsu/llm_wiki)证明项目存在、跨平台桌面应用、能将文档转成持久化 wiki
- **目标鱼塘：** 待验证假设:看见热门项目很心动但不会安装部署的中文新手,可能正在手工整理文档或反复问 AI 同样的问题
- **最小交付：** 部署说明包:在买家指定操作系统上安装 llm_wiki、跑通一次文档转 wiki 流程并截图、提供中文配置说明、明确不包含后续更新和定制功能
- **48小时验证：** 先在本地复现完整安装和转换流程,记录失败点和耗时。明天找 3 位正在手工整理文档的用户,展示部署样品并询问他们是否愿意为省安装时间付费
- **为什么只是小试：** 项目本身能跑,但没有证据表明中文用户愿意为部署包付钱,而不是自己照着 README 装一遍
- **停止条件：** 如果 3 位目标用户都表示自己能装或不需要这个结果、或者本地复现失败无法解决,立刻停止

### 验证 Claude Code 配置服务有没有人要

- **证据来源：** [claude-code 官方仓库](https://github.com/anthropics/claude-code)证明 Anthropic 官方智能编码工具存在、支持终端集成和 git 工作流
- **目标鱼塘：** 待验证假设:正在使用 Claude Code 但不熟悉配置或集成流程的开发者,可能正在反复手动操作或试错
- **最小交付：** Claude Code 配置包:在买家指定环境下完成 Claude Code 安装和基础配置、跑通一个 git 工作流示例、提供配置文件和中文说明、明确不包含后续定制和长期答疑
- **48小时验证：** 先在测试环境跑通 Claude Code 并记录配置步骤和失败点。明天找 3 位正在使用或打算使用 Claude Code 的开发者,展示配置样品并询问他们是否愿意为省配置时间付费
- **为什么只是小试：** 这是 Anthropic 官方工具,文档相对完整,需要先验证中文开发者是否真的愿意为配置服务付钱,而不是自己看文档配一遍
- **停止条件：** 如果 3 位目标用户都表示自己能配或不需要这个服务、或者配置过程中遇到无法解决的环境问题,立刻停止
