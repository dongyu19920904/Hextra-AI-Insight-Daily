## 今日主推
### [你的 AI Agent 用完就忘？帮你把记忆接通](https://github.com/thedotmack/claude-mem)

很多人买了 AI 工具，每次开新对话又要重新介绍自己，说了一遍又一遍——不是他们不会用，是工具根本没给他们配好"记忆"。`claude-mem` 这个项目刚好解决这件事：跨会话持久化上下文，支持 OpenClaw、Codex、Gemini、Copilot 一堆平台，配一次，以后开口就能认出你。

问题是：这东西配起来不直观，新手看文档就卡住了。你能卖的，就是"帮你配通、给你截图、有问题问我"这一单轻服务。今天挂出去，问的人大概率比你想的多。

- 参考来源：[claude-mem](https://github.com/thedotmack/claude-mem) / [cc-switch 多平台切换工具](https://github.com/farion1231/cc-switch)
- 目标鱼塘：已经在用 AI 工具但嫌麻烦、每次重复配置觉得烦的人；想让 Agent 真正"记住自己"的小白用户
- 适合谁：有闲鱼/微信小摊子、会操作基本工具、能录一个简短操作视频的人
- 这钱从哪来：买家每次开 AI 对话都要重新介绍自己，早就烦了；今天有现成开源工具解决，但自己配要踩坑——花小钱省这个折腾是今天就有的冲动
- 可交付物：代配置截图 + 运行验证录屏 + 一页中文配置说明 + 基础答疑（3 天内）
- 最简单卖法：闲鱼发"AI Agent 记忆配置服务，帮你一次配通，告别每次重复介绍自己"，定价 19-39 元试水
- 最低成本验证：今晚自己先跑通 claude-mem 配置，截一张"配置前 vs 配置后"对比截图，发到朋友圈或群里，看有没有人问
- 今天先做哪一步：先本地把 claude-mem 跑起来，截对比图；再写一版闲鱼标题和商品说明
- 今天就能发的文案：「用了这么久 AI，每次还是要重新自我介绍？——其实有工具能解决，配一次就好。帮你弄好，附说明，有问题我在。」
- 复购/升级路径：配完记忆 → 顺手卖 cc-switch 多平台切换配置 → 后续升级"全套 Agent 环境搭建包"→ 私域答疑会员
- 售后边界：只做配置交付和截图验证；不承诺平台永久稳定；不代替账号出问题兜底
- 配图建议：用 claude-mem 的 README 里"配置前后上下文注入"示意图，或自己截一张"新会话自动带入历史信息"的真实截图

## 本周可试
### [不会建站的人，今天其实可以试试这个开源替代](https://github.com/CoreBunch/Instatic)

Instatic 今天进了 GitHub 日榜——它是 Webflow、Framer 和 WordPress 的开源替代，支持自托管，带可视化 CMS，输出静态页面，功能一点不少。对于想给客户建简单官网、产品页的小老板或自由接单者，这是个成本低很多的选择。

但现在中文上手资料几乎没有，自己部署要踩不少坑——这就是你这周可以慢慢做一套"中文部署跑通包"的窗口期。先跑通，再包装，不用急着今晚就卖。

- 参考来源：[Instatic](https://github.com/CoreBunch/Instatic)
- 适合谁：会基础操作、有建站或帮小商家做页面需求的人；想做"低价帮人建轻官网"副业的人
- 先怎么试：先自己本地或服务器上把 Instatic 跑起来，截几张效果图；做一份中文安装说明，这周发到目标群里或社区试探反应
- 最低成本验证：发一张"用开源工具 10 分钟搭出来的页面"截图，问一句"有没有人需要帮搭这种轻官网"，看回复
- 为什么先别冲太猛：项目刚进日榜，中文社区认知度还低；买家对"开源建站工具"的感知转化路径稍长，需要先建立认知再成交，不是今晚就能大量出单的方向
- 配图建议：截 Instatic 官方 Demo 的页面效果图，或自己搭一个简单的中文页面截图，直观展示"这是能用的东西"
