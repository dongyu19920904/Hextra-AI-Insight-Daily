## 今日主推

### [AI Agent 搜索接不好？我帮你先跑通这一步](https://m.okjike.com/originalPosts/6a67fc2abd0563695ba099ef)

很多人买了 AI 工具，用着用着发现它"不知道今天的事"——问汇率答错，问新闻答旧，问实时价格直接编。这不是模型笨，是搜索没接好，或者根本就没接。现在连 Gemini 都被内行吐槽搜索越来越差，等于替买家把这个坑摆明了。你今天能卖的，就是帮他把搜索接通、测试能用、交付结果这一单，不用他自己折腾。

- 参考来源：[AI探索站即刻帖子](https://m.okjike.com/originalPosts/6a67fc2abd0563695ba099ef)
- 目标鱼塘：已经在用 AI Agent 或 AI 助手、但老觉得答案过时或不准的人；想把 Agent 用起来但不知道为什么"它不知道今天的事"的新手
- 适合谁：不懂配置、不想自己排错、想直接用到结果的小白用户；在用 Dify、Coze、Gemini 或类似工具的人
- 这钱从哪来：买家今天就会遇到这个问题——问 AI 今天涨停的股票，答案全是旧的；问汇率，出来一个过期的数字。Gemini 被指搜索越来越差，这个槽点今天就有人在传，买家的不满正好在发酵，切入时机对
- 可交付物：一份"Agent 接搜索"跑通包——包含工具筛选清单（哪个搜索 API 今天好用）、接入说明截图或录屏、测试结果对比图、答疑一次
- 最简单卖法：在闲鱼或私域挂一个"Agent 搜索跑通服务"，先限 3 单，只承诺帮配置好、测试能用，附截图为证
- 最低成本验证：今晚先自己跑一遍，把"Agent 接上搜索前后对比"做成两张截图或一段 30 秒录屏，明天就能挂图卖
- 今天先做哪一步：自己先测一个搜索接入方案（比如给 Dify 接 Tavily 或 SerpAPI），截两张对比图：没接之前答旧、接上之后答对，这就是你的交付样本和主图
- 今天就能发的文案：「问 AI 今天的汇率，它给你一个三个月前的数字——这不是 AI 笨，是搜索没接好。我这边帮你配好，测试能用再交付。感兴趣私信"搜索"。」
- 复购/升级路径：跑通包是入口 → 下一步可以升级到"帮你整套 Agent 工作流接入搜索+知识库" → 再往后是月费维护或定期更新搜索工具推荐
- 售后边界：只承诺帮配置 + 测试能用 + 交付截图；不承诺长期稳定、不承诺搜索结果 100% 准确；不处理买家自己改坏配置后的问题
- 配图建议：用"问 AI 今天汇率/今天涨停股"的前后对比截图，左边答案过期，右边接上搜索后答对——这张图比任何文字都直接

## 本周可试

### [MCP 协议大版本升级，插件接入迎来结构性变化](https://x.com/dotey/status/2082235315675144569)

MCP 刚发了第五个大版本，从有状态变成无状态，开发者圈子今天正在议论。但这件事对小白卖家来说不是今天就冲的信号，原因很简单：协议刚更新，现有工具适配程度参差不齐，今天代配置进去，明天可能就出兼容问题，售后会比较被动。

值得先盯的原因是：协议稳下来之后，会有一批工具同步支持新版本，那时候"帮你按新版接好、旧版迁过来"才是最干净的一单。现在先把"MCP 接入服务"的模板和说明备好，等两周后再上架。

- 参考来源：[宝玉 X 解析](https://x.com/dotey/status/2082235315675144569)
- 适合谁：有 Cursor、Claude Code 或 AI 编程工具用户的卖家；手上有 MCP 插件接入经验的人
- 先怎么试：现在先整理一份"MCP 新旧版本有什么区别、哪些工具已经支持新版"的中文对比清单，当作引流内容先发；不要急着挂代配置服务
- 最低成本验证：先发一条"MCP 刚升级了，你现在用的插件有没有受影响？"的测试文案，看有没有人来问；有人问再上架服务
- 为什么先别冲太猛：协议刚发，主流工具适配进度不明，今天接进去的配置可能下周就要重新弄；售后成本高，不适合现在做主推
- 配图建议：用宝玉帖子里的协议对比说明截图，或者自己画一张"旧版有会话 ID、新版无状态"的简单对比图，技术感不用太强，关键是让人看懂"变了什么"
