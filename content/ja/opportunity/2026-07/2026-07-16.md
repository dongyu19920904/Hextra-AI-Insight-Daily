## 今日主推
### [手机AI终于开了，但大多数人还不知道怎么真正用起来](https://www.36kr.com/p/3896830991320962)

昨天网信办一口气批了7款手机端侧AI：苹果、华为、小米、OPPO、vivo、三星、努比亚全在列。消息出来很热，但热完之后大部分人卡在同一个地方——找不到入口、开不了功能、不知道要不要换语言区、设置完没反应。

这就是今天最值得试的一单：不卖账号，卖"帮你把手机AI真正开起来"的跑通服务。买家不缺手机，缺的是有人替他走完那5个步骤、确认能用、用了有效果。你只要比他多跑一次，就能收这笔钱。

- 参考来源：[36氪 - 国行苹果AI终于通过备案](https://www.36kr.com/p/3896830991320962)
- 目标鱼塘：国行iPhone用户、刚升级系统的小米/华为机主、想试AI写文案的个体小商家
- 适合谁：不想看教程、想直接有人告诉他"你这款手机怎么开、开完能干嘛"的普通用户
- 这钱从哪来：备案刚批，大量用户今天才知道自己手机有AI功能，但设置路径绕、区域限制多、开完不知道用在哪——愿意花小钱让人帮他"确认能用"的窗口期就是这两周
- 可交付物：分机型的开启步骤说明（PDF或截图包）、跑通验证截图、常见问题答疑、1-2个适合普通用户的上手场景（比如苹果AI写回复、小艺记录健康数据）
- 最简单卖法：发一条"我帮你把XX手机的AI功能真正开起来，开完给你3个今天就能用的场景"，先定9.9-29.9试水，私聊交付
- 最低成本验证：今晚先做一张苹果Intelligence或小米澎湃AI的"开启前后对比截图"，配文案发朋友圈或闲鱼，看有没有人来问
- 今天先做哪一步：选你手头有的机型（哪怕就一台iPhone），走一遍AI功能开启流程，截图记录5个关键步骤，做成说明单页
- 今天就能发的文案：「国行苹果AI今天正式开了，但99%的人开完还是不知道用在哪。我整理了一份3步开启+5个今天就能用的场景，9.9拿走，帮你省2小时摸索。」
- 复购/升级路径：基础跑通包→分机型深度包（华为小艺用法、苹果AI写作场景）→月更新维护包→私域答疑群（按月收费）
- 售后边界：只交付开启步骤和基础场景说明，不承诺AI功能长期稳定，不代操作买家手机；系统更新导致步骤变化时说明范围，不提供无限次答疑
- 配图建议：用苹果iPhone设置页面截图（语言/地区→Apple Intelligence开启前后）或小米澎湃AI功能界面截图，最能说明"真的开起来了"

## 本周可试
### [一个开源工具，帮你用AI直接生成可导出的原型和落地页](https://github.com/nexu-io/open-design)

open-design 这个项目最近在 GitHub 冒头，定位是 Claude Design 的本地替代——输入描述，直接出 HTML/PDF/PPTX 甚至 MP4，支持接 Claude Code、Cursor、Gemini 等一堆工具。对于做设计外包、做落地页、做提案PPT的人来说，这个思路很有吸引力。但项目还比较新，中文配置说明几乎没有，一般小白自己跑通要踩不少坑。

先别冲太猛，但可以这周花半天把它跑通一次，做一个"我帮你用AI生成第一版落地页/提案页"的轻服务卡片，先小范围试一试有没有人问。

- 参考来源：[open-design - GitHub](https://github.com/nexu-io/open-design)
- 适合谁：接设计小单的自由职业者、做电商落地页的闲鱼卖家、想用AI做提案的独立顾问
- 先怎么试：本地跑通一次，生成一张落地页或一份PPTX，截图做成"交付样本"，发一条"9.9帮你生成第一版落地页，看效果再决定要不要深合作"的测试文案
- 最低成本验证：一张跑通截图 + 一条朋友圈/闲鱼标题，今晚就能发，看48小时内有没有咨询
- 为什么先别冲太猛：项目更新频率还在快速变化，中文文档不完整，部分导出格式在不同环境下效果不稳定；现阶段更适合先摸清交付边界，再决定要不要做成标准化产品
- 配图建议：用 open-design 生成的落地页或幻灯片截图，最直观；如果还没跑通，先用官方 README 里的效果示意图配说明也行
