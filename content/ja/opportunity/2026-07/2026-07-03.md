## 今日主推

### [数学老师折腾了一周没做出来，你帮他跑通收一单](https://x.com/Gorden_Sun/status/2072577589525541265)

辽宁一个中学老师，自己用 Gemini 折腾了很久，最后只做出个"效果一般的 html 文件"。他想要的是：把书上的几何题变成可交互的 GGB 文件，动点能动，图形能跟着变。用 Claude 加 Codex 跑了一遍，做到了。

这件事的意思是：有一批老师或辅导机构，手上有一堆书上的几何题，想把它们"电子化"，但自己完全不知道从哪下手。你只需要能帮他们跑通这一步，就能收钱。不是卖账号，不是卖教程，卖的是"你帮我做好、我直接能用"的结果。

- 参考来源：[Twitter @Gorden_Sun](https://x.com/Gorden_Sun/status/2072577589525541265)
- 买家鱼塘：初高中数学老师、教培机构助教、做题辅助内容的UP主和公众号作者，以及想给孩子做可视化辅助的家长。找鱼塘：数学教师群、家长群、教育类小红书评论区、知乎数学教育话题。
- 第一次成交：卖一个"几何题可视化跑通包"，限定交付 3 道题的 GGB 文件或截图录屏，定一个低价试水单，先问有没有人想试。
- 每一次复购：第一单跑通后，老师手上往往有几十道题。可以做"按题计费的批量服务"，也可以打包成"一学期题库可视化维护包"按月或按学期收。
- 增长杠杆：客户数——先做 1-2 个案例截图和录屏，发到数学老师聚集的地方，让别的老师看到"这居然能做到"，自己来问。
- 独特卖点：老师自己试过了，知道自己搞不定；你能直接交付 GGB 文件，他打开就能用在课堂上，不需要他懂任何技术。
- 风险逆转：先做1-2 道免费样例发出去，让买家看到效果再付钱；限定每单只交付明确数量的题目，不做无边界承诺。
- 杠杆资产：沉淀一套"几何题可视化 SOP"——哪类题适合做、用什么 prompt、哪个模型跑更快——以后每一单变得越来越轻。案例截图和录屏可以一直用来引流。
- 适合谁：能用 Claude 或 Codex 跑一遍几何题转 GGB 的人，哪怕现在还不熟，今天先试跑两道题摸摸流程，明天就能试卖。
- 这钱从哪来：数学老师手上有真实需求，而且亲自试过"自己搞不定"——这是今天最值得先试的理由。刚好 Gorden Sun 昨天公开了这个跑通案例，今天就是发现它、比别人早试一步的窗口。
- 最简单卖法：拍一张 GGB 文件在电脑上打开、动点可以拖动的截图或短录屏，配一句"帮数学老师把书上几何题做成可交互文件，这道题他自己折腾了一周没做出来"，直接发朋友圈或群里，看谁来问。
- 今天先做哪一步：找一道初中几何题，用 Claude 或 Codex 跑一遍，截图或录一段 30 秒内的屏，有动点更好。今晚就能发出去。
- 今天就能发的文案：「数学老师找我说，他用 AI 折腾了好久想把几何题做成动图——动点能拖、图形跟着变的那种，但最后没搞出来。我帮他跑了一遍，做到了。有老师或机构想把书上的题电子化的，可以聊聊，先发你一道试试效果。」
- 配图建议：用 GGB 文件打开后的截图，要能看到可拖动的动点和图形，不要只截代码界面。最好录一段 15-30 秒的操作录屏，展示动点被拖动、图形实时变化的效果。

## 本周可试

### [你的 Claude Agent 每次重开都忘事？帮他接上"记忆"这一单有人愿意付钱](https://github.com/thedotmack/claude-mem)

用 Claude Code 或各类 Agent 工具的人，最常抱怨的一件事就是：昨天刚跟它说好的事，今天重开会话全忘了，每次都要重新交代一遍。`claude-mem` 这个开源项目专门解决这个问题——自动压缩上下文、跨会话持久化记忆。但问题是，大多数想用的人，看到 GitHub README 就不知道从哪下手了。

这件事值得盯，但今天还不用大力投入。原因是：愿意付钱配置"Agent 记忆"的人，目前主要集中在开发者周边，真正"用 Agent 跑业务但不懂技术"的小白用户还在逐渐形成，需求还在教育阶段。先做一个轻版跑通截图试发，看看有没有人直接问"帮我装一下"，再决定要不要做成服务。

- 参考来源：[claude-mem](https://github.com/thedotmack/claude-mem) / [open-design](https://github.com/nexu-io/open-design)
- 适合谁：已经在用 Claude Code、OpenClaw 或其他 Agent 工具的中文用户，尤其是在意"会话连续性"、不想每次重开都重新交代背景的人。
- 增长假设：客单价——帮人代配置"记忆模块"是一个有明确结果的轻服务，可以比普通安装说明贵一档。
- 先怎么试：自己先把 claude-mem 装起来跑一遍，截图展示"装前 vs 装后"的对比效果（比如同一个 Agent 在不同会话里的记忆差异）。先发一张对比图到感兴趣 Claude 工具的群里，看有没有人直接问"这怎么弄"。有问的，报一个代配置小价，先收第一单。
- 为什么先别冲太猛：这个需求现在主要在开发者圈子里热，真正愿意付钱让人"帮我配记忆"的普通用户还在验证中。先低成本观察，不要上来就投入大量时间做教程库或录课。
- 能沉淀什么：跑通一套"claude-mem 代配置 SOP"和对应的截图素材，后面每接一单时间成本越来越低；对比截图可以长期当引流素材用。
- 配图建议：做一张"装前 vs 装后"的对比截图——左边是 Agent 重开会话后"我不记得上次的内容"，右边是装了 claude-mem 之后能自动接续上下文的效果。简洁清晰，一张图说明问题。

## 今日动作

- **先发什么**：发一张几何题 GGB 文件打开、动点可拖动的截图或 15-30 秒录屏，配上"数学老师自己折腾了一周没搞出来，我帮他跑通了"这个开场，今晚发朋友圈或数学教师群。
- **先录什么**：录一段几何题转 GGB 的操作过程——从一道书上的几何题文字描述，到最后打开 GGB 文件、拖动动点的全流程，30 秒以内，不用加任何解说，画面说话。
- **先卖哪一款**：几何题可视化跑通包，限定 3 道题，低价试水，先问有没有人想试效果再定价，不要一上来就定高价或做复杂套餐。
- **先沉淀什么**：把今天跑通的 prompt 和操作步骤记下来，存成一个最简版 SOP——用什么模型、输入什么格式、哪类题容易出错——这是以后每一单的时间成本杠杆。
