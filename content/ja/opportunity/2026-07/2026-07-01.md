## 今日主推

### [Mac 上说话就能打字，帮你把本地语音工具装好跑通](https://github.com/altic-dev/FluidVoice)

很多用 Mac 的人都在用 Wispr Flow 或系统自带听写，要么贵、要么飘、要么根本不知道有更好的选项。FluidVoice 今天上了 GitHub Trending，设备端本地跑，不联网也能用，还能自定义训练。问题是——它还是个 GitHub 项目，中文新手打开页面就懵：环境怎么配、依赖怎么装、跑不起来怎么办？这就是你今天能卖的东西：**帮他们把这一步走完**。

买家不需要懂代码，他们只需要知道"装好之后说话就能打字"。你卖的是这个结果，不是教程本身。

- 参考来源：[FluidVoice GitHub](https://github.com/altic-dev/FluidVoice)
- 目标鱼塘：Mac 用户、内容创作者、经常需要语音转文字的远程办公人群，尤其是觉得 Wispr Flow 太贵或用不惯系统听写的人
- 适合谁：能帮人远程指导安装、或者自己先跑通过一次的卖家；不需要写代码，只需要把安装步骤整理成中文
- 这钱从哪来：Wispr Flow 收费，Mac 系统听写精度不稳定，很多人今天就在找替代方案——FluidVoice 上了 Trending，搜索量跟着涨，这个时间窗口有点短，但今天进场最顺
- 可交付物：中文安装教程 PDF 或截图版、环境配置清单、踩坑说明、可选加一次远程陪跑（30 分钟内跑通为准）
- 最简单卖法：先发一版闲鱼/朋友圈，写"Mac 本地语音转文字，不联网、不涨价，帮你装好"，标价 9.9 或 19.9 试水；如果有人问，再升级到带答疑版
- 最低成本验证：今晚自己先把 FluidVoice 装好，截一张"正在听写"的实操图，配上一句"本地跑，不用联网"，发出去看有没有人问
- 今天先做哪一步：按照 GitHub README 自己装一遍，把卡住的步骤用中文记下来，这就是你最值钱的内容
- 今天就能发的文案：「Mac 用户注意——本地语音转文字，不联网、不订阅，说话就能打字。最近找到一个替代 Wispr Flow 的开源方案，帮你装好跑通，9.9 试试，装好为止。」
- 复购/升级路径：基础装好版（9.9）→ 带自定义训练配置版（29.9）→ 月度答疑群（适合工具重度用户）→ 后续如果 Windows/iOS 版出来，直接升级换代，老买家优先通知
- 售后边界：只负责帮安装跑通，不承诺识别率达到某个百分比；如果系统版本不兼容，退款或换方案；不做长期维护承诺
- 配图建议：用 FluidVoice 实际在 Mac 上听写的截图，最好能看到波形或文字实时出现的界面，比 README 封面图更有说服力

## 本周可试

### [AI帮你写代码已经来了，现在卖"新手怎么用好它"比卖工具更值钱](https://www.36kr.com/p/3875321145929728)

Claude Code 之父自己半年没写过代码——这个信号今天传得很广，很多人看了会觉得焦虑，但也有人会立刻想：那我能不能也用 AI 帮我写点东西？这批人今天会去搜、去问，但不知道从哪下手。**先别冲着"教编程"这个大方向做**，先切一个最窄的口子：比如"用 Claude Code 帮你生成一个闲鱼商品描述脚本"，或者"用 AI 帮你做一个简单的自动回复模板"。卖法是场景模板包，不是编程课。

- 参考来源：[36氪原文](https://www.36kr.com/p/3875321145929728)
- 适合谁：对 Claude Code 感兴趣但不会写代码的内容副业新手、小卖家、个体商家；卖家最好自己先试跑过一个小场景
- 先怎么试：选一个最具体的场景——比如"用 Claude Code 帮闲鱼卖家自动生成 5 条标题"——自己先跑一遍，截图记录，整理成一页 A4 的使用说明，今晚就能发
- 最低成本验证：发一条朋友圈或小红书，写"AI 帮你写闲鱼标题，我帮你配好用法，试用版 9.9"，看有没有人截图转发或私信问
- 为什么先别冲太猛：这个热点今天靠一篇访谈带动，买家的需求还在"感兴趣但没想好要买什么"阶段，教程类产品需要看到具体场景才会下单。先做最窄的一个场景包验证，确认有人问再扩
- 配图建议：用 Claude Code 实际输出一段闲鱼标题或商品描述的截图，最好对比"你自己写的版本"和"AI 生成的版本"，反差越大越有说服力
