## 今日主推

### [你的 Agent 每次都从零开始？帮你配好记忆，下次接着用](https://github.com/thedotmack/claude-mem)

很多人已经在用 Claude Code、OpenClaw、Codex 这类 Agent 工具了，但每次新开一个会话，Agent 就忘了上次的偏好、忘了你的项目背景、忘了你叫它别干什么。就像雇了个助理，每天上班都失忆一次。

claude-mem 这个项目解决的就是这件事：把每次 Agent 操作自动压缩成记忆，下次会话自动注入。技术上不复杂，但对不懂 Git 的人来说，光是"怎么装、装完配哪里、测没测通"就能卡掉大半天。这就是今天能卖的口子——你帮他跑通，他省一天折腾。

- 参考来源：[claude-mem](https://github.com/thedotmack/claude-mem) / [cc-switch 多工具一体助手](https://github.com/farion1231/cc-switch)
- 目标鱼塘：已经在用 Agent 编程工具但嫌麻烦的小白；买过 Cursor/OpenClaw 账号但没真正用起来的人
- 适合谁：有 Agent 工具、想让它"越用越懂我"、但不想自己研究配置的中文用户
- 这钱从哪来：买家已经花了钱买工具，现在发现每次都要重新交代背景——这个"失忆感"今天就在烦他，一个跑通包正好解决这个小麻烦
- 可交付物：claude-mem 安装配置说明（中文）、跑通截图或录屏、初始记忆模板 3 份（编程助理 / 文案助理 / 通用工作流）、基础答疑 1 次
- 最简单卖法：闲鱼挂"Agent 记忆配置包，装完让 AI 记住你的习惯"，含说明文档 + 模板 + 答疑，19-39 元
- 最低成本验证：今晚自己跑一遍安装流程，截 3 张图（安装完成 / 记忆生成 / 下次会话自动读取），做成一张对比图，今晚就能挂
- 今天先做哪一步：先把安装流程自己走一遍，截图记录每个关键步骤，整理成中文说明文档
- 今天就能发的文案：「用了三个月 Claude Code，才发现它一直在"失忆"。找到一个插件，能把每次操作自动压缩成记忆，下次开新会话直接续上。帮朋友配好了，他说感觉像换了个人。现在出配置包，感兴趣的来拿。」
- 复购/升级路径：初级卖配置包 → 中级卖"全套 Agent 工具链跑通服务"（claude-mem + cc-switch 组合配置）→ 高级卖月费答疑群，帮人持续维护记忆模板
- 售后边界：只交付安装说明和初始模板；不承诺 Agent 输出质量；不代管账号；工具本身更新导致的兼容问题不在服务范围内
- 配图建议：用"会话对比截图"最有说服力——左边是没有记忆时每次重新介绍项目背景的截图，右边是有记忆后直接续上的截图，反差一眼就懂

## 本周可试

### [一次 brief 出整套设计稿——腾讯 Miora 跑通体验包](https://t.me/aigc1024/22411)

腾讯 Miora 刚全量上线，多 Agent 协作生图、视频、3D、UI/UX 一次搞定，听着很猛。但它刚开放，真正用过、踩过坑、能说清"哪些场景好使、哪些还嫩"的人还很少——这个信息差现在有价值，但等一两周市场摸清楚之后就没了。

先小范围试发，不用压太重。现在最值得做的是：自己先试一个完整创作流程，截图记录，整理成"Miora 中文上手 + 哪类内容最出效果"的体验包，发到设计师群和内容副业群里探探反应。

- 参考来源：[腾讯 Miora 全量上线](https://t.me/aigc1024/22411)
- 适合谁：接小设计单的兼职设计师、做内容创作副业的人、想降低外包成本的小品牌主
- 先怎么试：用 Miora 跑一个完整品牌物料场景（比如一个奶茶店的全套视觉），截图 + 记录踩坑点，整理成"Miora 中文上手清单 + 3 个适合/不适合场景对比"，先发群里看有没有人问
- 最低成本验证：一张"brief 输入 → 整套输出"的对比截图，配一句"这是我用了两小时帮朋友出的品牌物料"，今晚发朋友圈，看有没有人私信
- 为什么先别冲太猛：工具刚开放，稳定性和输出质量还没被大量真实用户验证；现在重投入制作课程或套餐，万一后续有大更新，内容就得重做
- 配图建议：直接截 Miora 画布界面，一屏能看到多个素材同时生成的状态，视觉冲击最强
