今天最值得先试的一单：把 Claude Code 的角色配置模板包做成中文交付包，买家今天就遇得到这个麻烦，你今晚就能挂上去。

## 今日主推

### [帮你把 Claude Code 配成"AI团队"——中文跑通包今天就能卖](https://github.com/garrytan/gstack)

你有没有遇到过这种情况：看到一个工具说能让 AI 分别扮演 CEO、工程师、QA、设计师，帮你拆解任务、互相 review——听起来很爽，但打开 GitHub 全是英文，配置文件一堆，不知道从哪下手，关掉了。

这就是今天的买家画像。gstack 和 claude-code-templates 这两个项目正好撞在一起：一个是 Garry Tan 亲自用的 Claude Code 配置（23个角色分工），一个是专门用来配置和监控 Claude Code 的 CLI 工具，两个都在今天的 GitHub 热门榜上。你现在要做的不是跟买家讲这两个项目有多厉害，而是做一个"我帮你配好了，直接能用"的中文交付包，先挂一版低价试试水温。

- 参考来源：[gstack](https://github.com/garrytan/gstack) / [claude-code-templates](https://github.com/davila7/claude-code-templates)
- 目标鱼塘：Claude Code 用户、想提升 AI 编程效率的独立开发者、一人公司老板、内容副业新手
- 适合谁：自己有 Claude 账号或 Claude Code 入口，但不知道怎么配角色、怎么让 AI"分工干活"的人
- 这钱从哪来：买家拿到账号后卡在"不会配"这一步——连个中文说明都找不到，GitHub 全是英文，自己试一下配错了更乱，花小钱买个配好的模板包直接省掉这段折腾
- 可交付物：中文版角色配置模板包（CEO / 工程师 / QA / 文档 5个角色，每个角色带一套系统提示词和使用说明）+ 跑通截图 + 基础答疑
- 最简单卖法：闲鱼或朋友圈挂一版低价模板包（参考 9.9–29.9 区间），标题写结果不写项目名，比如"Claude 会自动分角色帮你 review 代码，配置包已汉化，买了直接用"
- 最低成本验证：今晚用 gstack 的配置自己跑一遍，截 3 张图（配置界面 + Claude 角色对话 + 输出结果），做成一张对比图，发一条朋友圈或群消息，看有没有人问"怎么弄的"
- 今天先做哪一步：先把 gstack 的角色配置汉化成一份文档，整理成 5 个角色的提示词模板，不需要做完整课程，一份清晰的 PDF 或飞书文档就够了
- 今天就能发的文案：「Claude Code 有个玩法：配好之后，AI 会自动分成 CEO、工程师、QA 几个角色，互相检查你的项目，比你自己问一遍强多了。配置文件是英文的，我帮你汉化整理好了，买了直接套用，不用自己踩坑。感兴趣私我。」
- 复购/升级路径：低价模板包 → 跑通包（含安装+配置+答疑，代跑一遍）→ 月费陪跑（持续答疑+新模板更新）→ 团队定制配置服务
- 售后边界：只交付模板包和配置说明；Claude Code 账号本身的稳定性不在交付范围内；不承诺长期维护，但可以告知买家项目更新时同步
- 配图建议：截一张 gstack 的 README 角色分工示意图（英文原版），旁边配一张你汉化后的中文配置截图，做成左右对比，左边"看不懂"，右边"直接用"

## 本周可试

### [AI 会记住你上次干到哪了——帮买家配一套跨会话记忆，悄悄比别人多卖一个点](https://github.com/thedotmack/claude-mem)

claude-mem 这个项目最近安静地冒出来，做的事情其实很有感知度：Agent 跨会话自动记忆，支持 Claude Code、Gemini、Cursor 一堆工具——换句话说，就是让 AI 不再"每次开聊都失忆"。这个痛点小白也能感受到，但现在主要是开发者在用，中文说明极少，真正做成买家能拿到结果的搭售包，还没人抢先。

先别急着主推，但这周可以悄悄跑通一遍，积累一版中文说明。等你手里有截图和跑通记录，再作为"Claude 搭售加量版"的一个差异化卖点，比单纯卖账号多一个理由让买家选你。

- 参考来源：[claude-mem](https://github.com/thedotmack/claude-mem)
- 适合谁：已经在卖 Claude 账号或 Claude Code 相关服务的卖家，想做出差异化的人
- 先怎么试：本周先自己把 claude-mem 跑通一遍，截图记录"AI记住了什么、下次怎么用"，整理成一份 1 页纸的中文上手说明
- 最低成本验证：做完之后发一条朋友圈或群消息，标题写"我帮 Claude 装了个记忆，它终于不失忆了"，看有没有人问怎么配，不用先挂商品
- 为什么先别冲太猛：项目更新时间偏早，中文使用案例还很少，买家认知还没到，现在主推需要花太多时间解释"这是什么"；先作为搭售加分项比单独成商品更容易成交
- 配图建议：截两张对比图——一张是普通 Claude 对话（不记得上次说了什么），一张是 claude-mem 接入后 AI 主动提到"上次你说…"，对比一目了然
