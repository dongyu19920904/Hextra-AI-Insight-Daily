## 今日のメイン

### Orca で「マルチエージェント統合設定パック」に課金意欲があるか検証する

**Orca を使えば自分のサブスクリプションで Claude Code と Codex を同時に動かせるけど、「誰かが実際に金を払うか」はまだ未検証の仮説だ。**

- **根拠と信頼度：** 中。[Orca リポジトリ：プロジェクトの存在とマルチエージェント統合実行機能の説明](https://github.com/stablyai/orca)。課金ユーザーの記録や中文での実測スクショはまだない。
- **ターゲットと地道な方法：** **未検証の仮説**——Claude Code と Codex を同時に使う個人開発者が、設定の繰り返しや実行環境の切り替えに疲れている可能性がある。
- **最小デリバリー：** 「マルチエージェント統合起動設定パック」：① Orca の動作スクショ（2つのエージェントが同時にレスポンス）；② 失敗ポイント込みの中国語設定手順；③ アカウント代行購入や長期メンテは含まない。検収基準：ドキュメント通りに動かせること。
- **48時間検証：** まずローカルで Orca を動かして実際の所要時間と失敗ポイントを記録。次に Claude Code か Codex を使っている開発者3〜5人に個別でスクショを見せて、自発的に値段を聞いてくる人がいるか観察する。
- **初回受注と再購入：** 声かけ文句：「Orca で2つのエージェントを同時起動するのを動かしたんで、設定パックにまとめたんだけど見てみる？🤔」初回は文書とスクショのみの納品で、代理デプロイは含まない。**再購入は弱め**、どちらかというと一度きりの単発案件になりそう。
- **リスクと撤退：** **コンプライアンスリスクは低め**。Orca のライセンスを確認して商業目的での配布条件を確かめる必要あり。撤退条件：5人が見て誰も値段を聞かなかった場合、またはローカルで2インスタンスを安定して動かせない場合。

- **根拠：** [agent-browser リポジトリ：プロジェクトの存在とブラウザ自動化 CLI 機能の説明](https://github.com/vercel-labs/agent-browser)
- **ターゲット：** **未検証の仮説**——agent-browser を見つけたけどインストール・デプロイができない中国語圏の初心者が、誰かに動かしてもらいたいと思っている可能性がある。

- **48時間検証：** まず動かして失敗ポイントを記録し、スクショを初心者開発者3人に送って「自分でインストールできそうか、誰かに頼みたいか」を観察する。
