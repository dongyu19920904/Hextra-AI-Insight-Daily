## 今日のメイン

### Postman 移行比較パックに需要があるか検証する

**Postman が Codex と Claude Code プラグインを自動インストールし、セルフアプルーブの起動フックまで試みたとユーザーが GitHub issues に報告した——これが今日再現できる具体的な事件だ🚨** 検証したい仮説：独立開発者や小チームが自分で issues を掘り返して代替ツールを一個一個試している可能性があり、「踏み抜いた穴ぜんぶ済みの移行比較結果」に金を払う気があるなら、それが一件の受注になる。

- **根拠と確度：** 中。[GitHub issues 原文：Postman 12.33.4 が Codex/Claude Code プラグインを自動インストールし MCP 認証警告が出るというユーザーレポートの存在を証明](https://github.com/postmanlabs/postman-app-support/issues/14370)。根拠のギャップ：今回の候補入力からは Postman 公式の正式回答と影響ユーザー規模データが取れていない；代替ツールの移行コストも自前テスト待ち。

- **釣り堀と地道なやり方：** 検証したい仮説：Postman で API デバッグしてる開発者が、自分で issues を漁ったり Slack でニュースを回したりしている可能性があり、対処は「プラグインを手動でオフにする」か「アップグレードを保留する」止まりで、わかりやすい代替案の比較がない状態かもしれない。

- **最小デリバリー：** 商品名：**Postman 移行比較パック**。① 自動インストールプラグインの完全ログスクショ；② 代替ツール2〜3個（Bruno・Insomnia・Hoppscotch）を同一 API タスクで操作比較；③ 移行チェックリスト（Collection エクスポート形式・環境変数・チームコラボ制限）。含まない：有料アカウントの提供なし、代替ツールの長期互換保証なし。買い手の検収基準：代替ツールのどれか1つで自分の既存 API テストフローを通せること。

- **48時間検証：** まずリアルな Collection を Postman から Bruno にインポートして失敗ポイントとフォーマット差異をスクショ付きで記録；次にそのスクショを開発者3〜5人に送って「これ遭遇した？踏み抜き済みの比較結果に少額払う気ある？」と聞き、価格を聞いてくるか興味を示すか観察する。

- **初回受注と復注：** 誘い文句：「Postman が勝手に AI プラグイン入れてフックまで承認しやがったんで、移行比較パック作りました。サンプル見てから決めてください。」初回受注：ツール1本分の移行比較、Collection は1セット固定・代替ツールは2つ固定、カスタマイズなし。復注は弱め、基本的に一発受注型；チーム全体の移行を聞いてきたら、時給制の移行代行サービスにアップグレード可。

- **リスクと停止条件：** コンプライアンスリスク **中**🟡 Postman Collection エクスポートフォーマットの二次配布の範囲を確認必須、代替ツールのライセンスも一個ずつ確認が要る。停止条件：自前テストでフォーマット損失が深刻で再現不能になった場合・ターゲットユーザー5人全員が興味なしの場合・Postman が当該行為を撤回する公式声明を出した場合。

## 今週の小テスト

### RTX Spark Linux 降クロック デバッグレポートのサンプル検証

- **根拠の出所：** [MindStudio 実測記事：MSI Prestige RTX Spark が Linux で電源接続時に GPU が約780MHzにクロックロックされ、Windows の約2.2GHz を大きく下回る再現可能な現象を証明](https://www.mindstudio.ai/blog/linux-nvidia-rtx-spark-laptop)

- **ターゲット釣り堀：** 検証したい仮説：RTX Spark シリーズのノートPCを買って Linux でローカル推論を回そうとしている開発者が、Windows の3分の1以下の速度しか出ないのに原因がわからずハマっている可能性がある🤔

- **最小デリバリー：** 見せられるサンプル1点：降クロック再現スクショ＋既知ドライバ設定の調整手順＋何が効かなくて何が少し改善したかの正直な記録。買い手の検収基準：それを見て自分が同じ問題に当たってるか、緩和の限界がどこかを判断できること。

- **48時間検証：** まず再現可能な結果サマリーをスクショ付きでまとめ、Linux ローカル推論関連のコミュニティに投稿して、同じ問題で詰まってて値段を聞いてくる人がいるか観察する。

- **なぜ小テストどまりか：** RTX Spark＋Linux＋ローカル推論の3条件が揃う読者層が極端に狭い；根拠が単一の実測記事だけで、今回の候補入力には Nvidia の暗号化ファームウェア降クロックに関する公式説明が含まれておらず、製品の事実確認が待ち状態。

- **停止条件：** 48時間以内に同じ問題で詰まってる人がゼロ；または Nvidia がすでに公開の修正パスを出していてレポートの価値がなくなった場合。
