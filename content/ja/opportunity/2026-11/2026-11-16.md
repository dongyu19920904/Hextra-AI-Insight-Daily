## 今日のメイン

### AI Agent 評価レポートサンプルが個人開発者に刺さるか検証する

**SkillEvaluator は NVIDIA がメンテしている Agent スキル評価フレームワークで今も更新中；今日確かめたいのは「中国語圏の個人開発者が自分の Agent 向け評価レポートにお金を払うか」だ🔍**

- **根拠と信頼度：** 中。[公式リポジトリ：プロジェクトの実在・Apache-2.0ライセンス・更新日2026-11-16の確認](https://github.com/NVIDIA/SkillEvaluator)。穴：今回の候補インプットに有償ニーズのインタビューや問い合わせ記録なし、市場需要は未検証の仮説。
- **想定ターゲットとローテク検証法：** 未検証仮説：AI Agent を運用している個人開発者や小チームは体系的な評価手法を持っていない可能性があり、今は手書きのテストケースやカンで回しているせいで品質が比較しにくい状態かも。
- **最小デリバラブル：** 商品名「AI Agent スキル評価レポートパック」。①公開または買い手提供の Agent でフル評価を実行；②中文レポートを出力、各次元スコア・品質ゲート結論・主要問題の特定を含む；③「このレポートの読み方」説明ページ付き；④Agent の修正・コードリファクタ・長期保守は含まない。買い手が確かめられること：レポート内の問題特定から自分のコードの改善箇所を直接探せる。
- **48時間検証：** まずリポジトリ付属のサンプルか最小 Demo でフル評価を1回回し、実際にかかった時間と失敗ポイントを記録、スクショを中文サンプルにまとめて人に送れる状態にする。次にそのサンプルを Agent 開発中の個人開発者3〜5人に送り、「今どうやって Agent の品質テストしてる？このレポート見て誰かに代わりに回してもらうならいくら払う？」と聞く。値段を聞いてきたりレポートテンプレートを欲しがる人が出るかを観察する。
- **初回受注とリピート：** テスト用の一言：「あなたの AI Agent のスキル評価レポートを作ります。リポジトリのアドレスをください、48時間で中文の結論を納品します。」初回は固定スコープ：単一 Agent・単回評価、レポートと説明ページの納品のみ、修正対応なし。リピート方向：Agent のイテレーションごとに再評価；今のところ低頻度単発案件に近いが、評価フローをテンプレ化すれば次回の納品コストを下げられる。
- **リスクとやめる基準：** リスク低め。Apache-2.0 は商用利用 OK、著作権表示の保持が必要；二次配布の範囲は要確認。やめる条件：テスト環境でフル評価が安定再現しない；開発者5人がサンプルを見て誰も値段を聞いてこない；または Agent 開発経験のない買い手にレポート内容がまったく読めない。

## 今週の小テスト

### ECC マルチツール設定パック：開発者がデュアルツール解説に金を払うか検証する

- **根拠：** [ECC リポジトリ：プロジェクトの実在と Claude Code・Cursor・Codex 等マルチツール対応の機能説明の確認](https://github.com/affaan-m/ECC)
- **想定ターゲット：** 未検証仮説：Claude Code と Cursor を同時に使っている開発者は、初期設定で同じ作業を何度も繰り返している可能性がある。
- **最小デリバラブル：** 「Claude Code + Cursor デュアルツール」シナリオ向けの中文設定説明パック、インストール手順のスクショと主なつまずきポイント付き。買い手が確かめられること：説明通りに操作して両ツールが ECC スキルを正常に呼び出せる。
- **48時間検証：** まず自分でデュアルツール設定を一通りやりきり、実際の所要時間とハマりポイントを記録してスクショでサンプル化。次にこの2ツールを併用している開発者3〜5人に送り、初回設定に何分かかったか・その時間を省けるなら払う気があるかを聞いて、値段を聞いてくる人がいるか観察する。
- **なぜ小テスト止まりか：** 総合スコア47でメイン推奨を下回る；リポジトリに有償ニーズの根拠なし；ツールのカバー範囲が広くターゲットが絞りにくいため、まず単一シナリオで検証する必要あり。
- **やめる条件：** 設定作業で再現不能な失敗が出る；ターゲット5人全員が「ググれば分かる」と言う；または中国語圏の初心者が操作不能と判明。
