# 今日AI商机

## 先说结论
今天最值得先试的一单：把 AI 工具的"用法包"卖给已经有账号、但根本不知道怎么用的人——这钱最好赚，因为买家已经花过钱了，他只差一个能直接抄的模板。

## 今日主推
### [你买了 AI 工具，但从来没真正用起来过](https://x.com/vista8/status/2059260610345660694)

很多人手里有 Claude、有 Cursor、有各种 AI 账号，但打开之后不知道输什么，用了两次就扔在那里吃灰。他们不缺工具，缺的是一个"这个场景直接这么用"的现成模板。

今天有个数据点很有意思：有人分析了 3 年的内容数据，发现 Prompt 类、工具清单类、资源入口类内容爆款率最高，收藏传播最强。这说明买家对"能直接用的东西"需求是真实的，不是你臆想出来的。

你今天能卖的，就是这个：一个针对某个具体场景（比如写周报、做客服回复、整理会议记录）的 AI 提示词模板包，配上三步上手说明，打包成一个小商品挂出去。买家拿到就能用，不用自己摸索。

- 参考来源：[vista8 内容数据分析](https://x.com/vista8/status/2059269911592194377) / [即刻 Skill 新比例讨论](https://m.okjike.com/originalPosts/6a1599ffaf7695b4cfb29dd2)
- 适合谁：手里有 AI 工具账号、但一直没真正用起来的人；或者想用 AI 提效但不知道从哪里开始的职场新手
- 这钱从哪来：买家已经为工具付过钱了，现在他只是不知道怎么用——你卖的是"省去自己摸索两周"的时间，这个钱他愿意出。今天这个数据点再次证明，Prompt 类内容是最容易被收藏和转发的，说明需求是真实存在的。
- 最简单卖法：做一个"3 个场景 × 5 条 Prompt"的小模板包，配一页截图说明，定价低一点先跑量，后续可以搭售给有账号的买家
- 今天先做哪一步：先选一个你最熟的场景（比如"用 Claude 写日报"或"用 AI 整理会议记录"），整理 5 条能直接复制粘贴的 Prompt，截图做成一页说明，今晚就能挂
- 今天就能发的文案：「买了 AI 工具但不知道输什么？我整理了 XX 场景的现成提示词，复制进去就能用，不用自己摸索。」
- 配图建议：用一张"空白对话框 vs 填好 Prompt 后的输出对比"截图，最能说明"有模板和没模板的差距"

## 本周可试
### [一个工具管五个 Agent，帮人省掉反复配置的麻烦](https://github.com/farion1231/cc-switch)

cc-switch 这个项目最近出来了，能在一个桌面工具里切换 Claude Code、Codex、Gemini CLI 等多个 Agent 环境。对小白来说，这件事本身不重要，重要的是：很多人现在同时在试好几个 AI 编程工具，每次换一个都要重新配一遍环境，烦死了。

这个方向有苗头，但项目还比较新，文档不完整，中文资料几乎没有。现在冲进去卖"全套配置服务"风险有点高，更适合先做一个"中文上手说明 + 我帮你装好"的小包，低价挂出去试试有没有人问。

- 参考来源：[cc-switch GitHub](https://github.com/farion1231/cc-switch) / [claude-mem GitHub](https://github.com/thedotmack/claude-mem)
- 适合谁：已经在用 Claude Code 或 Cursor 的人，或者想同时试几个 AI 编程工具但不想每次重新配环境的开发者和学生
- 先怎么试：先自己把 cc-switch 装一遍，截图记录每一步，整理成中文安装说明，做成一个"装好即用"的小包，低价挂出去，先看有没有人问
- 为什么先别冲太猛：项目刚出来，稳定性未知，中文用户基数还小，现在做大套餐容易售后翻车；先用低价引流款探一探水深，有人成交再加深
- 配图建议：用 cc-switch 官网或 GitHub 的界面截图，配上"一个界面切换多个 AI 工具"的示意，比纯文字说明更直观
