## 今日主推
### [不会配 Claude Code？我替你把 CEO、设计师、QA 全配好](https://github.com/garrytan/gstack)

很多人听说 Claude Code 能扮演不同角色帮你干活，但打开 GitHub 一看全是英文配置，直接关掉。gstack 这个项目把 23 个角色配置打包好了——CEO 拍板、工程师写代码、QA 测试、文档工程师整理——但对新手来说，"会用"和"能跑通"之间还差一个配置步骤。这个步骤，就是你今天能卖的东西。

你卖的不是教程，是"我帮你配好，你直接用"的结果。买家付钱买的是省掉那两小时踩坑时间，不是买一份说明书。

- 参考来源：[gstack](https://github.com/garrytan/gstack) / [cc-switch 多工具切换](https://github.com/farion1231/cc-switch)
- 适合谁：想用 Claude Code 提效、但看到配置文件就头疼的非技术用户；自由职业者、小团队、想试 AI 工作流的人
- 这钱从哪来：gstack 今天刚在 GitHub 冒头，中文圈还没人把它翻译成"可以直接买的服务"——信息差窗口就在这两天。买家心动的理由很简单：听说能让 AI 帮自己扮演整个小团队，但自己搞不定配置
- 最简单卖法：发一条"Claude Code 角色配置跑通包，我帮你装好、测好、截图给你看"的轻服务，定价 19-39 元，限前 5 单
- 今天先做哪一步：自己先把 gstack 跑通一遍，截 2-3 张不同角色对话的截图，这就是你的成交证明
- 今天就能发的文案：

> 最近有个 GitHub 项目火了，能让 Claude Code 同时扮演 CEO、工程师、QA 帮你干活。
> 但配置这块很多人卡住了。
> 我帮你配好，截图给你看跑通了，你直接用。
> 19 元，今天限 5 单。

- 配图建议：用 gstack 跑通后不同角色回复的对话截图，最好并排放 CEO 和 QA 两个角色的输出，一眼看出"这不是一个 AI，是一组 AI"

## 本周可试
### [写论文、做研究，这个 Skill 包帮你省掉最烦的那一步](https://x.com/vista8/status/2057309148493336751)

academic-research-skills 这个插件几天内涨到 1.6 万 Star，说明"写论文"这个需求真实存在、而且很急。但现在大多数人还停在"知道有这东西"的阶段，还没人把它包装成"你装好就能用"的中文服务包。

这单值得盯，但今天先别重投入——因为这类 Skill 插件更新快，你先做一个最小版本（安装说明 + 3 个使用场景示例），试发看有没有人问，再决定要不要深做。

- 参考来源：[向阳乔木推文](https://x.com/vista8/status/2057309148493336751)
- 适合谁：在读研究生、需要写报告的职场人、想用 AI 辅助写作但不知道从哪装起的人
- 先怎么试：整理一份中文安装说明 + 3 个具体使用场景（比如"帮我找文献"、"帮我写摘要"、"帮我改论文结构"），做成一页 PDF 或截图，先在社群里免费发，看有没有人追问"怎么买"
- 为什么先别冲太猛：Skill 插件依赖平台生态，更新节奏快，今天能用的配置下周可能要改；先用低成本验证需求，确认有人愿意付钱再做完整版
- 配图建议：用插件实际跑出来的论文摘要或文献整理截图，配上安装命令那一行，让人一眼看出"这是能直接装的东西"
