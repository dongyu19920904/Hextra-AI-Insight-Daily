# 今日AI商机

## 先说结论
AI写代码工具集体涨价、限额，今天最值得先试的一单：把 Codex 的中文跑通包卖给那些"听说能免费用、但不知道怎么开始"的人。

---

## 今日主推
### 别人在抢着用 Codex，你可以卖"帮他们跑通第一步"

Copilot 宣布涨价、Claude Code 限速的消息昨天刷屏了。很多人第一反应是：那我去试试 Codex？但打开一看，全英文界面、不知道从哪里开始、不确定免费额度够不够用——就这样关掉了。

这个"想试但没跑起来"的空档，就是今天最容易成交的地方。你不需要教他们写代码，你只需要帮他们跑通第一步：账号开好、界面认识清楚、第一个任务跑出来截图给他看。

买家今天心动的理由很直接：替代品涨价了，Codex 免费账户还能用，但没人帮他们上手。你卖的就是这个"省折腾"。

- **适合谁：** 听说 AI 写代码很香、但从没跑通过一次的中文新手；或者原来用 Copilot、现在想找平替的人
- **这钱从哪来：** Copilot 涨价消息刚出，一批人正在找"免费能用的替代"，Codex 免费额度是今天最强的引流钩子；买家付钱买的是"帮我跑通，别让我自己摸索"
- **最简单卖法：** Codex 跑通包——账号注册说明 + 中文界面导览 + 第一个任务示例截图/录屏，打包成一份文档或视频，9-29 元起试挂
- **今天先做哪一步：** 自己先跑一遍 Codex 免费账户，截 3 张图：注册成功页、第一个任务输入、跑出结果。这三张图就是你今天的商品封面
- **今天就能发的文案：** "Copilot 要涨价了，Codex 免费账户现在还能用——但很多人打开就不知道从哪里开始。我整理了一份中文跑通包，注册到跑出第一个结果，全程不用懂代码。需要的来。"
- **配图建议：** 用 Codex 跑出第一个任务的结果截图，旁边放一句"免费账户可用"，比任何介绍都有说服力

## 本周可试
### 把"提示词优化"这件事，卖成一个能搭给任何人的小包

有一个叫"提示词优化大师"的 Skill 项目最近在技术圈传开了，它的特别之处在于：不是一套万能提示词，而是针对不同场景（写代码用 Claude Code 还是 Cursor、生图用 MJ 还是其他）给出不同的优化建议。

这件事本身不难商品化，但今天还不用重投入——因为大多数买家还没意识到"提示词要分场景"这件事，需要先有人帮他们建立这个认知，再成交。可以先做一个轻量版：挑 2-3 个最常见场景（比如写小红书文案、生成产品图、写周报），整理成中文对照包，先试发看有没有人问。

- **适合谁：** 已经在用 ChatGPT 或 Claude 但总觉得"效果不稳定、不知道怎么写提示词"的人；或者想给自己的账号搭售一个增值包的卖家
- **先怎么试：** 挑 3 个场景，每个场景做一个"普通提示词 vs 优化后提示词"的对比截图，打包成 PDF 或图文，9 元引流款先挂着
- **为什么先别冲太猛：** 这类包的买家需要先被教育"提示词是有差异的"，转化链路比跑通包稍长；先用低价引流款测反馈，有人问了再做深
- **配图建议：** 同一个任务，普通提示词的输出 vs 优化后的输出，左右对比图，一眼看出差距

## 今天别碰
### Cursor 官方 TypeScript SDK 公测

看着很热，但买家是开发者，不是新手。SDK 要装 npm、要懂 TypeScript、要自己写调用逻辑——这条路对小白来说门槛太高，今天做了大概率白忙。等有人把它包成傻瓜版再说。

## 地图感
### AI 写代码工具正在从"免费畅用"变成"按量收费"

Copilot、Claude Code 相继调整计费方式，这不是某一家的事，是整个 AI 编程工具在找商业模式。对普通用户来说，意味着以后用多少、付多少，免费额度会越来越稀缺。知道这个趋势就够了，不用现在做什么。

- **先发什么：** 发一条对比图文——"Copilot 涨价了，Codex 免费账户还能用，但你知道怎么开始吗？"配上自己跑通的截图，结尾挂跑通包链接
- **先录什么：** 录一段 2 分钟屏幕录屏：从打开 Codex 官网到跑出第一个任务，全程不说废话，只演示操作，这段视频就是你最好的商品说明
- **先卖哪一款：** 先挂 9 元引流款（Codex 中文跑通包），测试有没有人问；有人买了、有人问了，再做 29 元版（加场景示例 + 答疑）
