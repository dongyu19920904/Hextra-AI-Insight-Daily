# 今日AI商机

## 先说结论
飞书开放了 CLI 工具,现在可以把 Claude 接进飞书干活,卖配置包正好赶上这波。

## 今日主推
### 飞书接 Claude 配置包,让 AI 直接帮你管日历和文档

飞书刚开源了 CLI 工具,Claude Code 现在能直接调飞书的所有功能。以前想让 AI 帮你建文档、约会议、发群消息,得自己折腾半天接口,现在飞书把这些都开放了,但大部分人不知道怎么接。你卖的就是这个"接通"的动作,买家付钱是为了省掉自己研究文档、调试接口的时间,直接拿到能用的配置。

- 适合谁: 已经在用 Claude 或 Claude Code,想让 AI 帮自己管飞书日常工作的人
- 这钱从哪来: 飞书今天刚开放 CLI,想试的人不知道怎么接,你帮他跑通第一步,省掉他自己摸索的时间
- 最简单卖法: 卖一个配置包,包含安装说明、飞书 CLI 接入教程、3-5 个常用场景示例(建文档、约会议、发群消息),再搭一个 15 分钟答疑
- 今天先做哪一步: 先自己跑通飞书 CLI + Claude 的接入流程,录一个 3 分钟演示视频,展示 AI 帮你建文档或约会议的完整过程
- 今天就能发的文案: "飞书刚开放 CLI,现在 Claude 能直接帮你管日历、建文档、发群消息。我帮你配好了,拿到就能用,省得自己折腾接口。包含安装说明 + 5 个常用场景 + 15 分钟答疑,XX 元。"
- 配图建议: 用飞书 CLI 官方 GitHub 页面截图,或者录屏展示 Claude 在飞书里自动建文档的过程

## 本周可试
### Prompt 模板包,搭给已经有账号的人

yetone 开源了语音输入法的 Prompt,宝玉也在推自己的 skills 思路。这类 Prompt 模板包适合搭给已经有 Claude、GPT 账号的人,但现在市面上类似的免费资源也不少,先小范围试发,看看愿意为"整理好的模板包"付费的人有多少。

- 适合谁: 已经有 AI 账号,但不知道怎么写 Prompt 让 AI 干活更精准的人
- 先怎么试: 先整理 3-5 个高频场景的 Prompt 模板(比如写文案、整理会议纪要、生成代码注释),打包成一个文档,搭配 1-2 个使用截图,先在社群或朋友圈试发
- 为什么先别冲太猛: 免费的 Prompt 资源很多,买家可能更愿意为"配置好的工具"付费,而不是单独买 Prompt。先测反馈,看看有没有人愿意为"整理好的模板"付钱
- 配图建议: 用 yetone 开源项目的截图,或者展示 Prompt 模板的使用前后对比

## 地图感
### Pretext 文本测量库

Cheng Lou 发布了一个纯 TypeScript 写的文本测量库,能在不依赖 DOM 的情况下精确计算文本排版尺寸。这是前端开发工具,不是面向小白的商品,知道有这么个东西就行,不用展开。
