# 今日AI商机

## 先说结论
今天最值得先试的一单：把 gstack 的 23 个 AI 角色配置，打包成中文跑通包挂出去——买家不是要学技术，是要今晚就能用。

## 今日主推

### [你的 AI 不会扮演 CEO 和设计师？这包直接帮你配好](https://github.com/garrytan/gstack)

有个问题很多人遇到过：Claude Code 或者 Codex 用起来感觉差不多，都是问一句答一句，跟普通聊天没太大区别。问题不是工具不行，是没配对——光有账号，没有角色。

gstack 这个项目做的事情说白了就一件：把 Garry Tan（Y Combinator 总裁）自己在用的 23 个专业角色提示词配置整理出来了，CEO、设计师、工程经理、QA、文档工程师，每个角色各司其职。这种东西英文社区摸索了好几个月，中文版基本没人整理过。

今天的机会不是卖账号，是卖"帮你把这套配置装进去、跑起来"。买家不想看英文 README，更不想自己折腾 JSON 配置，他们想的是：我买完，今晚能不能就用起来。

- 参考来源：[gstack](https://github.com/garrytan/gstack) / [taste-skill](https://github.com/Leonxlnx/taste-skill)
- 适合谁：有 Claude Code、Codex 或类似工具账号，但每次用完感觉"没出活"的中文用户；也适合想用 AI 辅助产品设计、写文案、做规划的小团队
- 这钱从哪来：很多人已经有账号了，但不知道角色配置是什么，今天看到这个项目会心动——但打开一看全英文、全 JSON，直接放弃。你卖的是"帮他省掉这段折腾"，结果是今晚就能用上 CEO 模式和设计师模式
- 最简单卖法：把 gstack 的核心配置翻成中文说明 + 整理成可直接导入的模板包，加一个"代配置到你的工具里"的轻服务，定两档——自己装版（低价）和帮你装版（中价）
- 今天先做哪一步：先把 gstack 项目 clone 下来，挑 3-5 个最好理解的角色（比如 CEO、设计师、QA），截图跑通效果，写一段 100 字以内的中文说明，今晚就能挂商品页
- 今天就能发的文案：「你用 Claude 或 Codex，但每次出来的东西都很一般？不是模型问题，是没给它分配角色。有人整理了 23 个专业角色配置：CEO 模式、设计师模式、QA 模式……我帮你翻成中文、配好装进去，今晚能用。感兴趣私我。」
- 配图建议：用 gstack README 里的角色列表截图，旁边放一张中文对照说明；或者录一段 30 秒的屏幕录像，展示切换角色后输出质量的对比

## 本周可试

### [用 ChatGPT 学运镜、做 PPT——"超级应用"转型刚开始，现在是卡位窗口](https://x.com/dotey/status/2063686036895478162)

OpenAI 内部高管直接说了"Chat is dead"，ChatGPT 要从聊天工具变成能自主跑任务的超级应用。这件事本周刚开始发酵，媒体还在写分析，用户还没反应过来该怎么用——这段空白期，正好是你做"场景包"的窗口。

先别冲太猛，因为 Agent 模式还在灰度，很多功能不稳定，你今天做的场景包下周可能就要更新。先小范围试发，找到哪类买家反馈最热再加深。

- 参考来源：[ChatGPT 要变 AgentGPT 了](https://x.com/dotey/status/2063686036895478162) / [运镜 + PPT 实战案例](https://x.com/vista8/status/2063472269985517778)
- 适合谁：已经买了 ChatGPT 账号但"感觉没用起来"的人；或者用 ChatGPT 做过一两件具体事（学习、写材料、做演示）、想要现成用法的人
- 先怎么试：参考 vista8 那条推文的思路，做一个"ChatGPT 5.5 + Codex 搭配用法"的小场景包，聚焦在一个具体任务上，比如"用 ChatGPT 调研 + 生成 PPT 学一个陌生技能"，今晚先发一条朋友圈或社群试探反馈
- 为什么先别冲太猛：Agent 功能还在铺开，功能点变化快，做太精细的教程包容易过时；另外"超级应用"这个说法目前更多是媒体预判，真正的用户痛点还需要两周左右才会集中出现，现在更适合试探方向而不是重仓生产
- 配图建议：用 vista8 那条推文里的 PPT 截图，或者自己做一个"ChatGPT 学技能流程图"，3 个步骤以内，干净、有画面感

## 地图感

### [AI Agent 有了"长期记忆"——claude-mem 在做什么](https://github.com/thedotmack/claude-mem)

Agent 现在最大的毛病是每次对话都要重新介绍自己，claude-mem 想解决的就是这个：让 AI 记住上次做了什么，下次接着来。这是 Agent 从"试用玩具"变成"真正能用的工具"的关键一步，现在还在开发者早期，了解一下就够，不用现在押注。
