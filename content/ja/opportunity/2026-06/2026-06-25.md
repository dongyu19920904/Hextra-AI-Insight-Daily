## 今日主推

### [帮你把 Agent 的记忆真正配好，下次打开还记得你](https://github.com/thedotmack/claude-mem)

很多人装了 OpenClaw 或 Claude Code，用两下就卡住了——每次新对话，Agent 全忘了，又要重新解释背景。这个痛点不是新手才有，很多用了一段时间的人也在问"怎么让它记住我"。今天有个叫 claude-mem 的开源工具专门解这道题：跨会话持久上下文，Agent 的每次操作都能被压缩、存下来，下次自动注入。问题是，自己配这个对新手来说还是有点门槛——克隆仓库、配路径、测试跑通，没个把小时搞不定。你帮他搞定，今晚就能有人问价。

- 参考来源：[claude-mem](https://github.com/thedotmack/claude-mem) / [open-design](https://github.com/nexu-io/open-design) / [cc-switch](https://github.com/farion1231/cc-switch)
- 目标鱼塘：已经在用 OpenClaw / Claude Code / Cursor，但每次对话都从零开始、越用越烦的人
- 适合谁：OpenClaw 用户、折腾过 Agent 但卡在配置上的小白、想提效但不想自己排错的内容副业选手
- 这钱从哪来：Agent 没记忆是用过都知道的毛病，今天有现成方案，愿意花一点省折腾时间——不是买概念，是买"帮我跑通"这个动作
- 可交付物：claude-mem 安装跑通截图或录屏、中文配置说明（含常见报错对照）、基础答疑 1-2 次
- 最简单卖法：闲鱼或私聊发一条"帮你把 OpenClaw 记忆配好，30 分钟内交付截图"，定价 19-39 元，先试 5 单
- 最低成本验证：今天先自己跑通 claude-mem，截 2 张图（配置前 vs 配置后），配一张中文步骤截图，今晚就能挂
- 今天先做哪一步：克隆 claude-mem，本地跑通，截"配置完成后 Agent 跨会话还记得上次内容"的对比图
- 今天就能发的文案：「用 OpenClaw 每次都要重新介绍自己？有个工具能帮 Agent 记住你，我帮你配好，30 分钟内截图交付，19 元」
- 复购/升级路径：基础记忆配置 → 多工具接入（Codex / Gemini CLI 同步配）→ 全套 Agent 工作流代搭建 → 私域月费答疑
- 售后边界：只交付配置说明和跑通截图，不承诺开源工具长期维护，不做系统级代码定制
- 配图建议：两栏对比截图——左边"新对话、Agent 什么都不记得"，右边"配完 claude-mem 后 Agent 自动带上上次上下文"；不用 P 图，真实终端截图最有说服力

## 本周可试

### [用一份"AI设计工具筛选包"，帮设计师省掉两周踩坑时间](https://github.com/nexu-io/open-design)

open-design 是一个本地部署的设计工具，内置 259+ 技能、142+ 设计系统，能出原型、幻灯片、视频，支持 Claude / Cursor / Qwen 接入。对设计师来说这东西听起来很诱人，但"本地部署 + 配模型 + 跑起来"这条路不短，大部分人会卡死在第一步。这单现在还不用重投入，因为大多数潜在买家还没开始找解决方案——但已经有苗头了，可以先做一个"设计师专用 AI 工具筛选对比包"试发，等反馈。

- 参考来源：[open-design](https://github.com/nexu-io/open-design)
- 适合谁：自由设计师、UI 设计兼职、会用 Figma 但想接入 AI 的人；不是程序员，不想看英文文档
- 先怎么试：做一份"3 个设计类 AI 工具横向对比 + 各自上手难度评分"的中文小包（1 页 PDF 或截图卡），价格 9-19 元，先试发朋友圈或设计师群
- 最低成本验证：不用部署 open-design，先整理对比清单，今晚 2 小时内能出图，试发一条看有没有人问
- 为什么先别冲太猛：工具本身是开源早期项目，部署链路对中文新手不算友好；买家基数还没到"今天就急着买"的程度；先测信息差翻译包，有人问了再上代配置服务
- 配图建议：一张三列对比表截图（工具名 / 上手难度 / 适合什么场景），干净、清晰，不需要 banner
