## 先说结论
今天最值得先试的一单：把 gstack 这套 Claude Code 角色配置，打包成"帮你跑通、交付截图"的轻服务挂出去——不用写代码，不用讲技术，卖的就是"我替你折腾好了"。

## 今日主推

### [你不用懂代码，我帮你把 Claude 配成一个能干活的"AI团队"](https://github.com/garrytan/gstack)

有人把 Claude Code 配置成 23 个角色分工的工作团队——CEO、设计师、工程师、QA 全齐了，发任务给它，它自己分配、自己执行。这套配置已经在 GitHub 上开源，但普通人看到就直接懵：英文、命令行、配置文件，光搞明白怎么跑就能劝退 90% 的人。

你卖的不是这个项目，你卖的是"我已经跑通了，截图给你看，直接交付给你用"。买家今天遇到的问题很具体：看到别人分享这套玩意儿，心痒，但完全不知道从哪开始。你接的就是这个口。

- 参考来源：[gstack](https://github.com/garrytan/gstack) / [claude-mem 跨会话记忆组件](https://github.com/thedotmack/claude-mem)
- 适合谁：想用 AI 帮自己做项目、副业或日常任务，但不会配置、不会命令行的中文新手
- 这钱从哪来：看到别人秀"AI帮我搞定了整个项目流程"就心动，但自己动手必然折腾半天、大概率放弃——买的是省两天踩坑，直接拿到能用的配置包
- 最简单卖法：先自己跑通一次，截几张"角色分工运行中"的截图，配一页中文说明，打包成轻服务挂出去；定价可以从低价引流款起，后续加 claude-mem 跨会话记忆做升级版搭售
- 今天先做哪一步：今天先跑通 gstack 默认配置，截三张截图（启动成功、分配任务、输出结果），写两行中文说明，这就是你明天能发的商品内容
- 今天就能发的文案：「有人把 Claude 配成了23个岗位的AI公司，CEO分任务、工程师写代码、QA检查、文档工程师整理，全自动跑。我已经跑通了，配置文件+中文说明直接给你，不需要你自己折腾。需要的来。」
- 配图建议：用 gstack 终端运行截图，或者画一张"角色分工示意图"（CEO→工程师→QA→文档），中文标注，看起来比代码截图更直觉

## 本周可试

### [世界杯开踢，帮人"选 AI 预测哪家强"的筛选包能试发](https://www.36kr.com/p/3849637857377157)

豆包、千问、DeepSeek、Kimi，几家国内AI都在蹭世界杯预测，媒体已经在做横评了。买家真正的困惑不是谁预测准，而是"这么多AI工具，我到底该用哪个、怎么用"。这个场景有点反常识——世界杯是体育热点，但卖的其实是"帮你选 AI 工具"的筛选服务，买家是那种看到热闹想跟进、但不知从哪下手的人。

现在先别重投入，因为世界杯刚开始，热度还会涨，但预测准不准要等结果出来，现在发筛选包是占位，等比赛打出几轮再加热。

- 参考来源：[AI预测世界杯大横评](https://www.36kr.com/p/3849637857377157) / [Kimi-K2.7-Code 开源](https://x.com/Gorden_Sun/status/2065380954936610856)
- 适合谁：平时有在卖 Kimi、千问或 DeepSeek 账号的人，或者有体育/娱乐向社群的内容创作者
- 先怎么试：先发一条"我替你试完了这几家AI预测世界杯，直接告诉你用哪个"的朋友圈或社群内容，看有没有人问；有人问再做场景包，没人问就换角度
- 为什么先别冲太猛：预测类内容有很强的时效性，世界杯结束热度清零；而且"哪家AI更准"现在还说不清楚，先小范围试发，别花大力气做完整课程
- 配图建议：找一张几家 AI 工具 logo 并排的对比图，加一行文字"我替你试完了"，不用精修，截图风更有真实感
