很多人下载了 Agent 工具，打开之后不知道怎么让它真的"跑起来"。配 Skill 已经够折腾了，现在又冒出来 Loops 这套东西——触发器、反馈门、退出条件，光是看说明就想关掉。

今天有个 Loops 集合站上线了，收录了 40 套现成的 coding agent 闭环工作流，可以直接复制用。问题在于，大多数人看到这个依然不知道从哪里开始。你能做的事，就是替他们把第一套跑通，截图或录屏告诉他们"装完是这个样子的"——这就是今天能成交的东西。

卖的不是教程，是"你不用自己踩那些坑，我已经替你试过了"。

- 参考来源：[loops.elorm.xyz 集合站上线](https://t.me/aigc1024/21385)
- 适合谁：想用 coding agent 提效、但一看配置就头大的中文新手；也适合已经在用 Claude Code 或 Cursor 但觉得"没发挥出来"的人
- 这钱从哪来：这套工作流是今天新冒出来的东西，大多数人连听都没听过，信息差刚刚打开。买家付的是"别让我再折腾半天还跑不通"
- 最简单卖法：轻服务——"帮你把第一个 Loops 工作流跑通，附截图/录屏说明，基础答疑三天"。引流款可以低价，成交款可以加一套场景配置
- 今天先做哪一步：去 loops.elorm.xyz 挑一个最简单的工作流，自己先跑一遍，截两张图——一张配置界面、一张跑通结果。有了这两张图，今晚就能发

## 本周可试
### [Claude Skill 帮人做出第一份 AI 生成 PPT，你收代劳费](https://x.com/dotey/status/2068042001895809420)

宝玉在测 baoyu-design skill，已经能在生成 PPT 时自动插图、连图带内容一起导出。功能在迭代，bug 还在修，但"AI 帮我做 PPT"这个需求本来就不缺买家。

现在的机会在于，Skill 还没稳定，大多数人自己配起来还会踩坑。你不需要等它完美，先做一个"我替你试过，导出基本能用"的最小服务——比一上来就卖完整定制包风险低多了。先试发一条，看有没有人问，再决定要不要往深做。

- 参考来源：[宝玉 Skill 更新说明](https://x.com/dotey/status/2068042001895809420) / [配图 Skill 更新](https://x.com/dotey/status/2067876611873964284)
- 适合谁：有 Claude 账号或 Codex CLI 环境、想帮人做 PPT 或简报的新手卖家
- 先怎么试：先跑一遍 baoyu-design skill，生成一份带图的 PPT，截图留存。今晚发一条"帮做 AI 生成 PPT 小样，有需要私聊"，只接 1-2 单，先看反馈
- 为什么先别冲太猛：Skill 还在迭代，导出格式有时候会出问题（宝玉自己也说"惨不忍睹"）。先做小单验证，别一开始就承诺大批量交付
- 配图建议：用 Skill 生成的 PPT 成品截图，最好带封面和一张内页配图——有图有文字，买家一眼能判断质量
