### 2. NVIDIA がマルチモーダルモデル Nemotron をオープンソース化、同類より高速

**Nemotron 3.5 Super VL** は、視覚推論モデルで計算最適化が売り。NVIDIA がオープンソース化した本モデルは **総パラメータ120B**、アクティブパラメータ12B。Gorden Sun が Twitter で紹介した [NVIDIA 公式のモデル特性](https://x.com/Gorden_Sun/status/2111823065789460900)によれば、推論、ツール呼び出し、テキスト・画像・ドキュメント・動画理解を統合 📹。長時間稼働エージェント向けに計算を最適化し、**同類モデルよりはるかに高速**。能力は中堅レベルで、Hugging Face でウェイト公開済み。

### 3. DeepSeek が検索・ウェブ抽出 API を提供開始

**DeepSeek** は、エージェント呼び出し用の独立インターフェースを公開した。[API ドキュメントで公表された2つの JSON インターフェース](https://api-docs.deepseek.com/guides/search/)は、Search が自社検索エンジンでウェブ結果を返し、Fetch が指定ウェブページを Markdown に抽出する 🔍。成功したリクエスト1000回あたり **0.75ドル**で、成功して結果を生成した場合のみ課金。どちらも DeepSeek API キー認証を継続し、モデル生成内にラップする必要はない。北京時間 **11月1日から**、Harness、Claude Code、Codex 経由の呼び出しはリクエスト単位で課金される。

![DeepSeek が検索・ウェブ抽出 API を提供開始 · 原文カバー](https://api-docs.deepseek.com/img/deepseek-social-card.jpeg "DeepSeek が検索・ウェブ抽出 API を提供開始 · 原文カバー")

### 5. Sphinx がプッシュ前に開発者の AI コード理解度をテスト

**Sphinx プロジェクト**は、問答で理解を確認してからマージする Git フック。[Sphinx プロジェクト](https://sphinx-six-theta.vercel.app/)は、保護ブランチへのプッシュ時に一時停止する。独立したレビューモデルが変更を読み取り、開発者に**挙動、失敗ケース、不変条件の予測**を求める 🔒。回答が不正確なら問題を説明して別シナリオで再挑戦、通過すればプッシュ継続。公式サイトの例は決済リトライとイベント ID 保存順序を議論。README はこれが練習であってセキュリティゲートではないと強調し、ローカルフックは回避可能。Node.js **22.19** 以上が必要。

![Sphinx がプッシュ前に開発者の AI コード理解度をテスト · 原文配図](https://sphinx-six-theta.vercel.app/demo.gif "Sphinx がプッシュ前に開発者の AI コード理解度をテスト · 原文配図")

### 6. AI エージェントスキルパックでプロダクト UI を映画的短編に

**AI エージェントスキルパック**は、具体的なパラメータを提供して自由発揮させない。AI探索ガイドチャンネルが紹介した [AI エージェントスキルパックでプロダクト UI を映画的短編に](https://t.me/aigc1024/26005)では、`npx skills add` でインストール後、エージェントに直接公開用短編を生成させる 🎬。手法は映像を一連の hero shot に分解：実際の UI がボードのようにステージに浮かび、カメラを **30～50°** に下げて斜め見。焦点面は2、3行の厚みだけで、残りはボケに。暗色プロダクトは純黒虚空、淡色プロダクトはハイキー撮影スタジオ。

### 7. AI ベンチマーク自体を誰が較正するのか

**評価は短命、根拠あり、具体的であるべき。** TypeSafe AI が Twitter で議論した [AI ベンチマークの信頼性パラドックス](https://www.bestblogs.dev/en/status/2111875713737380347?utm_source=rss&utm_medium=feed&utm_campaign=resources&entry=rss_article_item)。著者は優れた評価手法は **ephemeral**(ある時点の能力スナップショットのみ)、**grounded**(ビジネス関連タスクのパフォーマンスを直接測定)、**specific**(代理指標でなく目標成果を評価)であるべきと主張 📊。超伝導量子ビット較正図に例え、精度検証に使うシステム自体が自身の精度を保証する必要があると指摘。
