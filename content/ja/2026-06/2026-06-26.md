### 2. [阿里 Qwen-AgentWorld：397B 参数，跑分压过 GPT 5.4](https://x.com/Gorden_Sun/status/2070005187264360835)

过去训 Agent，大家都在教它"怎么行动"。Qwen-AgentWorld 换了个方向——它的目标是预测"你行动之后，世界会变成什么样"。

给模型一个动作加历史交互记录，它直接预测终端下一行会输出什么。这是首个用单一语言模型覆盖七个 Agent 交互领域的世界模型，包括 MCP、Search、Terminal、SWE、Android、Web、OS，一个模型全包了。397B 参数版本评分超过 GPT 5.4，35B 参数版本已经开源，可以直接从 HuggingFace 拉下来跑。Agent 从"执行者"变成"能预测结果的执行者"，这个方向变化比参数本身更值得关注。

### 3. [腾讯推出专门给 Agent 用的邮箱，注册后直接喂给 Codex 配置](https://x.com/vista8/status/2070144005589831745)

### 8. [谷歌推出 Open Knowledge Format：用 Markdown + YAML 让 Agent 直接消费知识](https://x.com/vista8/status/2069983469715755404)

以前给 Agent 喂知识，要么用 RAG 检索，要么直接塞进 prompt，格式全靠自己设计。谷歌六月推出 Open Knowledge Format（OKF），核心思路简单：一组 Markdown 文件加 YAML frontmatter，把知识变成可读、可版本控制、Agent 可直接消费的标准文件包。

有人已经用 Codex 读取这套规范，把自己做过的项目整理成了 OKF 格式，加进系统记忆索引。效果是：Agent 可以跨项目"记住"你做过什么，而不是每次都从零开始。这个规范如果被广泛采用，Agent 的上下文管理方式会有根本性的改变——从"临时喂料"变成"持久知识库"。
