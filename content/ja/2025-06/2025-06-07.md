# AI洞察日報 2025/6/7

### **AI製品と機能アップデート**

1.  最近、ドイツのテック大手**ボッシュ**と**アリババクラウド**が協力し、**Tongyi大規模言語モデル**を**スマートキャビン**に応用しました。クラウドコンピューティングとエッジコンピューティングのハイブリッド計算を通じて、**3D デジタルヒューマン**とのインタラクションを実現し、キャビンのインテリジェント認識とマルチモーダル制御能力を向上させています。このソリューションは知識Q&Aと同時通訳をサポートし、スマートキャビンをユーザーのニーズを理解し満たすインテリジェントアシスタントに変えました。これは自動車業界が個性化・インテリジェント化されたモビリティスペースへ向かっていることを示しています。

2.  **Perplexity AI**は最近**SEC**ファイルアクセス機能をリリースしました。これは様々な投資家が**Perplexityプラットフォーム**で複雑な**財務文書**を簡単に照会・理解できるよう支援するもので、すべての回答に引用が付いています。さらに、**Perplexity**は「**ラボ**」機能もリリースしました。この機能はユーザーのプロンプトをレポート、ダッシュボードなどの完全なプロジェクトに変換でき、ワークフロー効率を大幅に向上させています。

3.  **Trae プラットフォーム**は最近アップデートされ、**Google**の**Gemini 2.5 Pro Preview**モデルを正式に統合しました。このモデルは**WebDev Arena**と**LMArena コーディングランキング**の両方で第1位にランクされており、フロントエンド開発と**UI デザイン**能力を大幅に向上させています。 <br/> [![画像](https://raw.githubusercontent.com/justlovemaki/imagehub/refs/heads/main/images/2025/07/news_01k024y0p1e10rrk4waye86r7n.avif)](https://raw.githubusercontent.com/justlovemaki/imagehub/refs/heads/main/images/2025/07/news_01k024y0p1e10rrk4waye86r7n.avif) <br/> 今回のアップグレードはコード変換、編集、複雑なエージェントワークフローを最適化し、ユーザーに無料で開放されています。**AI**が**ブロックチェーン**と**分散型アプリケーション**分野でのイノベーションを推進することが期待されています。

4.  海外の有名な**AI ビデオ生成プラットフォーム PixVerse**は、国内版「**撮影Me AI**」を正式にリリースしました。モバイルアプリとウェブ版を同時にローンチし、国内のコンテンツクリエイターと企業に効率的で便利な**AI ビデオ生成ツール**を提供することを目指しています。 <br/> [![画像](https://raw.githubusercontent.com/justlovemaki/imagehub/refs/heads/main/images/2025/07/news_01k024y3tcf09s854ks0323534.avif)](https://raw.githubusercontent.com/justlovemaki/imagehub/refs/heads/main/images/2025/07/news_01k024y3tcf09s854ks0323534.avif) <br/> 「**撮影Me AI**」はテキストまたは画像から1クリックで高品質・多スタイルのビデオを生成でき、PixVerse V4.5アルゴリズムに基づいてローカライズ最適化されています。中国市場での**AI ビデオ技術**の普及と応用を推進することが期待されています。

5.  **ElevenLabs**は2025年6月5日に「地表最強」と称される**テキスト音声変換（TTS）モデル**、**Eleven v3（アルファ版）**をリリースしました。このモデルはテキストを自然で流暢な音声に変換するだけでなく、**オーディオタグ**を通じて感情、速度、さらには音響効果を正確に制御し、「演技合成」を実現できます。 <br/> [![画像](https://raw.githubusercontent.com/justlovemaki/imagehub/refs/heads/main/images/2025/07/news_01k024y7epf2v9w78szt0c4fa0.avif)](https://raw.githubusercontent.com/justlovemaki/imagehub/refs/heads/main/images/2025/07/news_01k024y7epf2v9w78szt0c4fa0.avif) <br/> [![画像](https://raw.githubusercontent.com/justlovemaki/imagehub/refs/heads/main/images/2025/07/news_01k024ybs3fjrvewa63q074tra.avif)](https://raw.githubusercontent.com/justlovemaki/imagehub/refs/heads/main/images/2025/07/news_01k024ybs3fjrvewa63q074tra.avif) <br/> **70以上の言語**と**マルチキャラクター自然対話**をサポートし、自動タグ機能により創作を簡素化しています。**映画・テレビ配音**、**バーチャルアシスタント**などの分野での広範な応用が期待され、**AI 音声**の未来を再定義する可能性があります。

### **AI最先端研究**

1.  この研究論文は**動的メモリスパース化（DMS）**という新しい手法を紹介しています。これは**Transformer LLM**の**KV キャッシュ**を圧縮することで、推論時に**超拡張**を実現し、同じ計算リソースでより多くのトークンを生成し、モデルの精度を向上させます。この手法は少量の訓練ステップで高い圧縮率を達成でき、**Qwen-R1 32B**などの複数の**LLM**が**AIME 24**、**GPQA**、**LiveCodeBench**などのベンチマークテストで精度を大幅に向上させています。論文アドレス：[https://arxiv.org/abs/2506.05345](https://arxiv.org/abs/2506.05345)。
