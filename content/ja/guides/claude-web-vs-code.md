## まず自分のケースに当てはめてみよう

| 今日やりたいこと | まず見るべきもの | 最初に確認すること |
| --- | --- | --- |
| 資料の整理・方案の修正 | Claude 会話インターフェース | ファイルや機能が現在のタスクに合っているか |
| 既存サイトのバグ修正・コード変更 | Claude Code | 正しいプロジェクトとアカウントに接続されているか |
| 自分のアプリにモデルを組み込む | Claude API | Consoleの請求・予算・APIキー管理 |

たとえばエラーの説明をさせたいだけなら、必要なエラー情報を貼り付けるだけでOK。プロジェクトを確認させてファイルを変更してテストを実行させたい場合に、初めてコードツールが本領を発揮する場面だよ。**「いつか使うかも」のために先にクレジットを大量購入するのはやめよう。🙅**

## Pro を買っていたら、Claude Code はもう一本別途買う必要があるの？

Anthropic の[Pro / Max と Claude Code の接続説明](https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-or-max-plan)では、Claude アプリと Claude Code が同じサブスクリプションに統合されており、使用量は共有されると説明されている。同じ Claude アカウントでログインしても、それぞれに独立した追加枠が生まれるわけじゃない。

見落とされがちなポイント：PCに `ANTHROPIC_API_KEY` が設定されていると、API認証・課金ルートを通ってしまう可能性がある。**サブスクリプションがあるからといって、ターミナルでの呼び出しが必ずしもサブスクの枠から引かれるわけじゃない。** トラブルシュートの際は、環境変数の有無とログイン方式だけを確認して、APIキーのスクリーンショットを他人に送るのは絶対にNGだよ。🔐

## API の請求とサブスクの請求を混同しないで

[Claude API 公式課金説明](https://support.claude.com/en/articles/8977456-how-do-i-pay-for-my-claude-api-usage)では、Console の残高と課金方式が解説されている。対象となる Max / Team プランには現在月次 API クレジットが含まれているけど、適用範囲があって、Claude Code の使い放題パスとして使えるわけじゃない。具体的な資格と用途は[Max・Team プランの月次 API クレジットに関する公式ガイドライン](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-and-team-plans)を確認してね。

初めて使う人にとってスムーズな順番は：**まずインターフェースを選んで、次にログインを確認して、最後に課金を見る。** 「Claude」という文字を見ただけで、名前が似た商品を買うのはやめよう。😅

## 購入前に確認すべきたった3つのこと

1. 必要なのは自分のアカウントの更新なのか、それとも API アクセスなのか？
2. 購入する商品が提供するサービスは、自分が使おうとしているインターフェースに対応しているか？
3. 利用地域・支払い資格・納品・アフターサービスの条件は満たしているか？これらはモデルのニュース一本で代わりに確認できるものじゃない。

自分の Claude アカウントがあって更新が必要な場合は、[爱窝啦·AI账号店の Claude Pro 更新説明](https://www.aivora.cn/products/chong-zhi-xu-fei-yue-ka-2)を確認して、納品対象とアフターサービスの範囲を重点的にチェックしよう。API残高商品と混同しないようにね。
