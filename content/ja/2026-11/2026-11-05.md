### 8. RTX Spark ノートPC が Linux 給電後の推論速度は Windows の 21% に低下

**RTX Spark** は給電すると逆に速度が崩れる。**充電器を挿したら、逆に速度が崩壊した。** MindStudio の実測によると、MSI Prestige RTX Spark の[ネイティブ Linux での推論パフォーマンス](https://www.mindstudio.ai/blog/linux-nvidia-rtx-spark-laptop)：給電時 GPU クロック約 780MHz に対し Windows では約 2.2GHz。GPT-OSS-120B のスループットは Windows 65.4 tokens/s、ネイティブ Linux 給電時はわずか **13.9 tokens/s**。電源を抜くと Linux でも約 61〜67 tokens/s まで回復。原因は Windows 独自の暗号化電力テーブルとされており、現状は WSL で Windows 側の電源管理を残すのが推奨路线。RTX Spark で**ローカル推論**を走らせたい Linux ユーザーは、今のところ WSL が一番安定。
