- **做不做：** Postman 迁移对比包先做；RTX Spark 调试报告作小试；claude-code 工作流近 7 天同类出现过，跳过。

## 今日主推

### 验证 Postman 迁移对比包有没有人要

**Postman 被用户在 GitHub issues 报告自动安装 Codex 和 Claude Code 插件、并尝试自批启动钩子，这是今天可复现的具体事件。** 待验证假设：可能有独立开发者或小团队正在手动翻 issues、逐一试替代工具，若有人愿意为踩完坑的迁移对比结果付费，这就是一单。

- **证据与可信度：** 中。[GitHub issues 原帖：证明 Postman 12.33.4 自动安装 Codex/Claude Code 插件及 MCP 认证警告的用户报告存在](https://github.com/postmanlabs/postman-app-support/issues/14370)。证据缺口：本次候选输入未提取到 Postman 官方正式回应及受影响用户规模数据；替代工具迁移成本尚待自测。

- **鱼塘与笨办法：** 待验证假设：正在用 Postman 做 API 调试的开发者，可能正在自己翻 issues 或群里转发新闻，处理方式可能是手动关插件或暂不升级，但没有清晰的替代方案对比。

- **最小交付：** 商品名：**Postman 替代迁移对比包**。① 复现自动安装插件的完整日志截图；② 2-3 个替代工具（Bruno、Insomnia、Hoppscotch）在同一 API 任务下的操作对比；③ 迁移检查清单（Collection 导出格式、环境变量、团队协作限制）。不包含：不提供付费账号，不承诺替代工具长期兼容。买家可验收：能用其中一个替代工具跑通自己原有的一个 API 测试流程。

- **48小时验证：** 先把一个真实 Collection 从 Postman 导入 Bruno，记录失败点和格式差异并截图；再把截图发给 3-5 位开发者，问「遇到了吗，愿不愿花小钱买份踩完坑的对比结果」，观察是否有人追问价格或表示意向。

- **第一单与复购：** 邀约句：「Postman 自己装了 AI 插件还批准了钩子，我整理了迁移对比包，先看样品再决定要不要。」第一单：1 个工具迁移对比，固定 1 套 Collection、固定 2 个替代工具，不含个性化定制。复购偏弱，更像一次性单；若有人追问团队整体迁移，可升级为按小时计的代迁移服务。

- **风险与停止：** 合规风险**中**。需确认 Postman Collection 导出格式的二次分发边界，替代工具许可需逐一核对。停止条件：自测时格式损失严重无法复现、5 位目标用户均无意向、或 Postman 发出官方声明撤销该行为。

## 本周小试

### RTX Spark Linux 降频调试报告样品验证

- **证据来源：** [MindStudio 实测文章：证明 MSI Prestige RTX Spark 在 Linux 插电后 GPU 锁频约 780MHz、低于 Windows 约 2.2GHz 的可复现现象](https://www.mindstudio.ai/blog/linux-nvidia-rtx-spark-laptop)

- **目标鱼塘：** 待验证假设：买了 RTX Spark 系列笔记本、打算在 Linux 上跑本地推理的开发者，可能正面对速度不到 Windows 三分之一却不知原因的困境。

- **最小交付：** 一份可展示样品：降频复现截图 + 已知驱动配置调整步骤 + 哪些方法无效、哪些有部分改善的诚实记录。买家可验收：能对照判断自己是否遇到同一问题及缓解边界。

- **48小时验证：** 先整理可复现的结果摘要并截图，再发到 Linux 本地推理相关社群，观察有无人表示正在踩坑并询价。

- **为什么只是小试：** 受众需同时具备 RTX Spark + Linux + 本地推理三个条件，极度垂直；证据来自单一实测，本次候选输入未提取到 Nvidia 对加密固件降频的官方说明，产品事实待核验。

- **停止条件：** 48 小时内无人表示遇到同一问题；或 Nvidia 已有公开修复路径导致报告失去价值。
