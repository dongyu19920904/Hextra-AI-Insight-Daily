## 直接结论

- **直接答案：** 今天有两个代码可视化工具同时出现，值得先用其中一个跑出针对具体职业的可验收样品，再问目标用户愿不愿意为省掉自己折腾的时间付钱。
- **做不做：** 先做 Understand-Anything 的职业场景样品，48 小时内看 3-5 位目标用户的真实反应再决定。
- **先验证：** 选一个具体职业（如独立开发者接手遗留项目），跑出一份可截图展示的知识图谱，问他们这份结果能省掉多少手工整理时间。
- **何时停：** 5 位目标用户看过样品后无一询价、无一愿意表达意向，或跑通成本超出目标用户的可接受范围，立刻停。

## 今日主推

### 验证「接手陌生代码库时能否直接买到一张可探索的全局地图」

**代码仓库转知识图谱这件事今天有了可直接部署的开源实现，值得先跑出一个职业场景样品再问价。** Understand-Anything 把代码库转成可搜索、可提问的交互式图谱，兼容 Claude Code、Cursor、Codex 等主流工具。接手遗留项目、为陌生仓库做文档、或给客户交付「你这套代码到底在干什么」的说明——这类任务目前依赖手工读代码加注释，耗时且不可复验。

- **证据与可信度：** 中。[Understand-Anything 仓库：证明项目存在及代码转交互图谱功能说明](https://github.com/Egonex-AI/Understand-Anything) 可直接核验。**缺口**：本次候选输入未提供许可证类型、是否有付费意向的用户记录、实际部署耗时，这些需要自行跑通后记录。

- **鱼塘与笨办法：** 待验证假设：独立开发者或小团队接手遗留项目时，可能正在逐文件手读、手写 README 或反复问 AI 单个函数的用途，整体拼不出全局视图。

- **最小交付：** 商品雏形名称「陌生代码库全局地图·一次性交付包」。交付内容：① 对买家指定仓库跑出一份可截图、可在浏览器探索的交互图谱；② 一页说明：图谱覆盖哪些模块、能问哪类问题、不包含什么；③ 交付截图与可访问链接；④ 明确边界：只针对买家提供的单一仓库，不含后续维护或二次修改。买家验收标准：能在图谱里点开任意模块、看到调用关系，并自行提问得到回答。

- **48小时验证：** 先选一个中等规模的开源仓库（500-2000 行），本地跑通 Understand-Anything，记录实际耗时与失败点，截图保存可探索状态。再把截图发给 3-5 位接过遗留项目的开发者或外包接单者，问一个问题：「如果有人替你提前跑出这张图，你愿意为这个结果单独付多少钱？」观察是否出现具体金额回应或追问交付细节。

- **第一单与复购：** 测试邀约句：「你下次接到陌生代码库，要不要我先帮你跑出一张可以直接问答的全局图？固定范围，交付截图和可访问链接。」第一单固定为单仓库、单次交付，不含持续维护、不含多分支对比。**价格**由自己根据跑通耗时决定，这里不预设数字。复购潜力偏弱，更像一次性单；若买家有多个项目轮换接手，可沉淀成「每次新项目启动包」，降低重复部署的边际时间。

- **风险与停止：** 售后/合规风险**低**，本次候选输入未提供许可证信息，需在仓库 README 或 LICENSE 文件中核查商业使用条件，商标和依赖许可也需逐一确认，确认前不对外承诺合规。**停止条件：** 本地无法跑通、图谱输出乱码或空白；实际耗时超出买家可接受成本；5 位目标用户看过样品后无一给出具体询价反应；许可证不允许基于输出结果收费。

## 本周小试

### 验证「代码库或想法转交互图表」对非开发职业是否有人要

- **证据来源：** [archify 仓库：证明项目存在及代码/想法转交互图表功能说明](https://github.com/tt-a1i/archify)
- **目标鱼塘：** 待验证假设：产品经理、技术写作者或小团队 leader 可能需要把已有代码或模糊计划快速转成可分享的视觉图表，目前用手画或反复导出 Markdown 完成。
- **最小交付：** 把一份不超过 20 页的产品 PRD 或小型代码库用 archify 跑出一张可截图的交互图表，标注哪些节点可点击、哪些关系可追踪。
- **48小时验证：** 先本地跑通一次并截图，再把截图私发给 3 位产品经理或技术写作者，问他们目前用什么方式整理这类全局关系、这份截图能不能替代其中一步。观察是否有人主动问「怎么生成的」或「多少钱帮我跑一次」。
- **为什么只是小试：** archify 的综合评分低于 Understand-Anything，且两者都指向代码可视化方向，本次候选输入未提供许可证信息，职业场景是否有付费意向尚未验证。先用较低资源探一下非开发职业的反应，再决定是否升级为主推。
- **停止条件：** 本地跑通失败；截图发出后无人追问或询价；发现许可证不允许基于输出结果收费；目标用户反馈已有更顺手的替代工具。
