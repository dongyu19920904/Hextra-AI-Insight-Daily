## 直接结论

- **直接答案：** 今天值得验证的是：把多工具 AI 编程环境切换做成可展示跑通包，拿给正在用 Claude Code 或 Codex 的开发者询价。
- **做不做：** 值得用 48 小时验证，付费意愿未确认，先做样品再问价。
- **先验证：** 先跑通 cc-switch 接入两个工具，做成截图样品，再找 3-5 位开发者确认痛点是否真实。
- **何时停：** 5 位目标用户看完样品均无具体场景反应，或工具跑通失败率超出可处理范围。

## 今日主推

### 验证多工具 AI 编程环境一键切换跑通包有没有人要

**cc-switch 已作为开源工具存在，把 Claude Code、Codex、DeepSeek Harness 整合进同一桌面客户端，但工具可用不等于有人愿意为「帮跑通」付钱，今天先拿到这个答案。**

- **证据与可信度：** 中。[cc-switch 仓库：证明项目存在及支持多 AI 工具的功能说明](https://github.com/farion1231/cc-switch)，官网 ccswitch.io 可进一步核验产品状态。缺口：本次候选输入未提供中文用户付费记录或痛点讨论，市场需求仍为待验证假设。
- **鱼塘与笨办法：** 待验证假设：同时使用 2 个以上 AI 编程工具的独立开发者，可能在换机或新开项目时手动重复配置步骤；这个频率和付费意愿尚未确认。
- **最小交付：** 「多工具编程环境跑通包」——①干净机器上完整安装 cc-switch 并接入 Claude Code + Codex；②截图或录屏记录步骤与实际耗时；③整理 1 份踩坑说明；④提供一次远程确认能跑通的机会。验收标准：买家能在自己机器上启动并切换两个工具，无需自翻文档。不含账号注册、版本升级和非 cc-switch 支持的工具。
- **48小时验证：** 先自己跑通一次，记录实际耗时和失败点，做成截图或 2 分钟录屏样品。再发给 3-5 位正在用 Claude Code 或 Codex 的开发者，直接问：「换机或配多工具环境时有没有重复折腾过，这个结果愿不愿意付钱省事？」观察是否立刻想起具体场景，而不是礼貌性回应。
- **第一单与复购：** 测试邀约句：「帮你在新机器上一次跑通 Claude Code + Codex 双工具环境，截图确认，价格商量。」第一单：一台机器、两个工具、一次跑通确认。复购偏弱，更像一次性单；若能沉淀为迁移模板可重复出售，或演变为小团队批量配置服务。
- **风险与停止：** 售后风险低。须核对 cc-switch 仓库 LICENSE 文件及 ccswitch.io 商业使用条款，确认服务收费是否合规。停止条件：工具跑通失败无法排错；5 位开发者均无此痛点；或许可边界确认后不允许商业服务形式。

## 本周小试

### 验证代码库转知识图谱交付对小团队有无实际需求

- **证据来源：** [graphify 仓库：证明项目存在及将代码库转为可查询知识图谱的功能说明](https://github.com/Graphify-Labs/graphify)
- **目标鱼塘：** 待验证假设：文档残缺、新人接手或外包交付时需要快速理解代码结构的小团队或独立开发者，可能愿意为这个结果付费。
- **最小交付：** 选一个公开代码库，用 graphify 跑出可查询知识图谱，展示 3 个典型查询结果截图。买家可检查的结果：给出具体问题（如「这个函数被哪里调用」），能在图谱里找到答案。
- **48小时验证：** 先跑通一次并记录实际耗时，做成样品截图。再拿给 3 位有存量代码库的开发者，问上次需要快速理解陌生代码库是什么时候，这个样品结果有没有帮到他们。
- **为什么只是小试：** 证据仅有仓库，本次候选输入未提供中文用户实测或付费记录；developer-tool-setup 交付家族近 7 天已出现多次，先降级验证中文小团队场景是否真实存在。
- **停止条件：** 工具本地跑通失败；5 位开发者看完样品均无具体使用场景；或许可条款不允许商业化服务形式。
