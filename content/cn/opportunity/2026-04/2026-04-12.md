## 今日主推
### 你的 AI 工具会写字，但不会画图？这个包装好了能直接卖

很多人买了 Claude 账号或者装了 Cursor，用了一段时间发现一个问题：让它写文档可以，让它画流程图、架构图，要么输出一堆看不懂的代码，要么干脆不会。这个痛点今天有了一个很具体的解法——一个叫 markdown-viewer/skills 的 Skill 包，装上之后 Agent 一句话就能根据你的内容自动生成架构图、流程图、状态图，还能导出 SVG 或 HTML 直接用。

这件事本身不难，但对大多数买了账号的人来说，"装上去、跑起来、出图"这三步就够他们卡一下午。你今天能卖的，就是这三步打包好的结果。

- 适合谁：已经有 Claude 账号或 Cursor 的人，想让 AI 帮自己画图但不知道怎么配置的
- 这钱从哪来：买家今天的痛点是"有工具没结果"，他们不缺账号，缺的是"装好能用"这一步；这个 Skill 刚出来，中文上手资料几乎没有，信息差就是你的利润
- 最简单卖法：做一个"AI 自动画图跑通包"——包含安装步骤截图、3 个场景示例（流程图/架构图/信息图）、常见报错处理，打包成 PDF 或图文，搭着账号一起卖，或者单独卖跑通包
- 今天先做哪一步：自己先跑一遍 `npx skills add markdown-viewer/skills`，截 3 张出图效果图，今晚就能发
- 今天就能发的文案：「你的 AI 会写字，但不会画图？装一个 Skill 就够了。流程图、架构图、状态图，一句话自动生成，还能导出 SVG 直接用。我整理了中文安装步骤 + 3 个场景示例，装好就能出图，不用自己踩坑。」
- 配图建议：用 `https://pbs.twimg.com/media/HFn7ydtakAEERro?format=jpg&name=orig` 这张源图，直接展示 Agent 出图效果，比任何文字都有说服力

## 本周可试
### [Claude 最近悄悄变好了，但这件事现在还不是主卖点](https://x.com/dotey/status/2043125192545689697)

Claude Code 代码质量这两天有人反馈明显提升，Anthropic 还推出了让小模型调用大模型介入指导的机制。这说明 Claude 账号的实际体验在往上走，是个好苗头。但现在还没有一个"今天就能让买家心动"的具体触发点，更适合先低调测一测反馈，而不是马上重推。

- 适合谁：已经在卖 Claude 账号或者有 Claude 账号货源的人，想找一个新的搭售角度
- 先怎么试：把"Claude Code 代码质量提升"这个变化做成一个小对比截图包——用同一个任务，对比一下最近和之前的输出质量，打包成"Claude 最近变了什么"的体验包，低价挂着试试反馈
- 为什么先别冲太猛：Anthropic 这次改动没有官方公告，只是用户反馈，不确定是否稳定；而且 Claude 账号昨天已经是主推方向，今天重复推同一个角度容易让读者审美疲劳，先小范围试发观察
- 配图建议：用 `https://cdnv2.ruguoapp.com/FkE0_6Mc9fGyviCbRPrQ-hxTtysRv3.png` 这张即刻截图，展示 Anthropic 降成本 + 小模型调大模型的机制说明，比直接截 Claude 对话更有信息量

## 地图感
### [Agent 不需要复杂编排，一个共享文件夹就能让 16 个 AI 协作两周](https://x.com/dotey/status/2043125192545689697)

Anthropic 有个案例：16 个 Agent 并行工作两周，靠的不是复杂的编排框架，而是一个共享任务文件夹加文件锁。这说明 AI 协作的门槛比大家想的低，但这件事现在还是技术圈的认知，还没有变成能卖的商品。先知道有这个方向就够了。
