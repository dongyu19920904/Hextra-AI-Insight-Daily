## 今日主推
### 你不用自己折腾 Claude Code，我帮你配好直接用

很多人已经有 Claude 账号了，但打开 Claude Code 之后就卡住了——不知道怎么配置项目、不知道模板怎么用、不知道第一步该干嘛。GitHub 上今天正好有一个专门做 Claude Code 配置模板的热门项目冒出来，但全是英文，新手看了还是不知道从哪下手。

这就是今天的机会：你先把它跑通，截几张图，写一份中文配置说明，打包成"Claude Code 中文跑通包"，卖给那些有账号但用不起来的人。买家付的不是教程钱，是"省掉自己折腾两小时"的钱。

- **适合谁：** 已经在卖 Claude 账号、或者手边有 Claude 账号的人；能跑通一次就能卖的新手卖家
- **这钱从哪来：** 买家今天最大的痛点不是没账号，是有了账号不会用——Claude Code 刚出来没多久，中文配置教程几乎没有，信息差就是利润
- **最简单卖法：** 跑通包，定价 9.9–29.9 元；内容：中文配置说明 PDF + 常见报错解决清单 + 一个可直接复用的项目模板文件；可以搭给已买账号的老客户做复购，也可以单独挂商品页引流
- **今天先做哪一步：** 打开 github.com/davila7/claude-code-templates，跑通一个最简单的配置，截图，写 3–5 步中文说明，今晚就能发
- **今天就能发的文案：**

- **配图建议：** 用 Claude Code 跑通后的终端截图，或者配置文件填好的界面截图，真实感比任何宣传图都管用

## 本周可试
### AI 帮你写代码，但你连"让它帮谁写"都没想清楚——这个包可以卖

最近有一篇文章在技术圈传得很广：说西方人忘了怎么造东西，现在也快忘了怎么写代码。听起来是在聊大趋势，但背后有一个很实在的需求——很多人想用 AI 写代码，但不知道自己的场景该怎么描述、该给 AI 什么指令、该用哪个工具。

这个需求今天还没到爆发点，但苗头很明显。可以先做一个"AI 写代码场景选择包"：帮买家搞清楚自己是哪种人、该用哪个工具、第一个任务该怎么描述。先低价试发，看有没有人问。

- **适合谁：** 想卖 AI 编程工具（Cursor、Claude Code）但不知道怎么切入小白市场的人
- **先怎么试：** 做一张"你适合用哪个 AI 写代码工具"的对比清单，3 种人群 × 3 个工具，写成一页 PDF 或一张图，挂 9.9 元试发
- **为什么先别冲太猛：** 这个需求现在还在发酵，买家还没形成"我要买这个"的明确意识；先用低价引流款测反馈，确认有人问再加深内容
- **配图建议：** 做一张简单的"三种人 × 三个工具"对比表截图，清晰胜过精美
