# 今日AI商机

## 先说结论
把 Claude Code 接进微信群这件事，今天已经有人跑通了——你现在能卖的，就是帮别人省掉那两小时折腾。

---

## 今日主推
### 帮你把 Claude 接进微信，装完就能用，不用自己踩坑

你有没有试过想让 AI 直接在微信里帮你干活，结果光配环境就搞了一晚上？Claude-to-IM-skill 这个开源项目已经把这条路跑通了，但对大多数人来说，"开源"两个字等于"我不会装"。这就是今天的机会——你来帮他们装好、跑通、截图交付，他们付钱买的是省事，不是教程。

- 适合谁：有一点点折腾能力、能跑通安装流程的人；卖给完全不想碰命令行的小白用户
- 这钱从哪来：很多人看到"Claude 接微信"这个画面就心动了，但一看到 GitHub 页面就放弃了。你卖的是那个放弃的瞬间之后的解决方案。今天这个项目刚被大量转发，正是心动人最多的时候。
- 最简单卖法：收费代配置，交付跑通截图 + 简单说明文档，可以加一档"装完答疑一周"
- 今天先做哪一步：自己先把 Claude-to-IM-skill 装一遍，截一张"Claude 在微信里回复"的图，这张图就是你今天最好的商品封面
- 今天就能发的文案：「Claude 现在可以直接在微信里帮你干活了，但装起来有点麻烦。我帮你配好，截图给你看跑通的样子，有问题随时问我。感兴趣私信我。」
- 配图建议：用 Claude 在微信对话框里回复消息的截图，真实感最强，比任何说明都有说服力

## 本周可试
### 笔记乱成一锅粥？有个工具能帮你整理成知识图谱，但先别急着卖服务

Codepilot 整理 Obsidian 笔记这件事，karpathy 也跟进推荐了，说明这个方向有真实需求。但现在买家还在"哇好厉害"阶段，还没到"我要付钱让人帮我整理"的阶段。先试发，先看有没有人问，别一上来就做重服务。

- 适合谁：自己用 Obsidian 或有大量笔记的人，或者服务这类用户的卖家
- 先怎么试：先发一张"整理前 vs 整理后"的笔记图谱对比图，配一句"你的笔记也能变成这样"，看有没有人主动问怎么弄
- 为什么先别冲太猛：这个工具刚出来，中文用户还没大规模踩过坑，你自己也需要先跑通一遍才能交付，现在重投入做服务包风险偏高，先测反馈再决定要不要做成标准商品
- 配图建议：直接用歸藏发的那张整理后的 Obsidian 图谱截图，视觉冲击力够，一眼就能说明问题

## 今天别碰
### MemPalace 的"AI记忆宫殿"，听起来很酷，但现在卖不动

完全本地运行、无 API 调用、30 倍压缩……这些卖点对小白来说等于没有卖点。买家听不懂，也感受不到痛点在哪。技术圈在讨论，但讨论不等于有人付钱。现在碰这个，大概率花时间写了内容，没人问。
