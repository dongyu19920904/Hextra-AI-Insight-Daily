## 今日主推

### 你发给我一份文档，我帮你变成能发出去的好看页面

很多人用 AI 写完东西，最后还是截图发朋友圈，或者发个 Word 附件没人点开。问题不是内容不好，是输出格式太难看、太难传。

今天 Claude Code 的作者亲自说了：他自己对外分享，主要就是用 HTML 输出。Markdown 存内容，HTML 对外展示。这不是技术圈自嗨，这是一个现成的交付结果——你帮人把文档、方案、报告，用 Claude 跑成一份排版好看、能直接截图或发链接的 HTML 页面。

买家不需要懂 Claude，不需要懂代码。他只需要知道：发给你一份内容，你还他一个好看的东西。

- **适合谁：** 有内容要对外发但不会排版的人——自媒体、销售、做方案的职场人、小团队运营
- **这钱从哪来：** 买家今天就有这个需求，只是不知道 Claude 能帮他做；你帮他省的是"找设计、学工具、自己折腾"的时间
- **最简单卖法：** 先做一个"文档转好看 HTML 页面"的轻服务，收一单试试；或者打包成模板包，附上 Claude 提示词和操作步骤，让买家自己跑
- **今天先做哪一步：** 自己先用 Claude 把一份普通文档跑成 HTML，截图对比"发之前 vs 发之后"，这张图就是你今天的发圈素材
- **今天就能发的文案：**

> 你有没有遇到过——写了半天方案，最后只能发个 Word 或截图，对方根本没心情看？
> 我最近在帮人把文档直接变成好看的 HTML 页面，排版干净，能截图能发链接。
> 有需要的可以先发给我试一份，看看效果再说。

- **配图建议：** 左边放一份普通 Markdown 或 Word 截图，右边放 Claude 跑出来的 HTML 页面截图，视觉反差越大越好

## 本周可试

### 换脸直播跑通包：有人想玩，但没人帮他装好

Deep-Live-Cam 这个项目最近又在传，一张照片实时换脸，短视频圈和直播圈的人看到都会心动。但心动归心动，自己装起来要配环境、装依赖、踩一堆坑，大多数人装到一半就放弃了。

这单不是卖概念，是卖"帮你装好、跑通、截图给你看"的结果。现在试卖的话，先做低价跑通包验证有没有人问，别一上来就做大课。

- **适合谁：** 想玩换脸直播或短视频特效、但不会自己配环境的人；也适合想做差异化内容的小主播
- **先怎么试：** 自己先在本地跑通一次，录一段 30 秒的效果演示视频，挂一个低价"代装+跑通"服务，先看有没有人问
- **为什么先别冲太猛：** 这类项目对硬件有要求，买家设备参差不齐，售后问题会比较多；先小范围试，摸清楚常见坑再扩量
- **配图建议：** 用项目官方的换脸演示截图，或者自己录的跑通效果片段，不要用网上随便找的换脸图

## 今天别碰

### 从零训练大模型的教程包

LLMs-from-scratch 这类"从零实现 GPT"的项目今天又在传。看着很硬核，但买这个的人要么是真正的开发者（不需要你教），要么是被标题吸引的小白（买了也跑不动）。交付难、售后重、转化率低，今天先别碰。

## 地图感

### Markdown + HTML 正在变成 AI 内容的标准输出格式

AI 圈现在有个共识慢慢成型：用 Markdown 存内容、用 HTML 对外展示。不是新技术，是一个正在被主流工具默默采纳的工作方式。你不需要现在深入研究，但知道这个方向，下次帮人做内容交付时，心里有个底。
