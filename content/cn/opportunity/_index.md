## 本周可试
### Agent SDK 代配置，先接几单试试水温
有人把 Claude Code 源码拆出来做了个开源 Agent SDK，开发者在讨论。但小白不关心 SDK 名字，他们要的是"帮我把微信 Agent 接上"。这单可以试，但别急着做标准化，先接 2-3 个私单，看看用户真实需求在哪，再决定怎么包装。

- 适合谁：想把 Agent 接到微信或其他工具，但不想自己配环境的人
- 先怎么试：先在群里或朋友圈发一条"代配置微信 Agent，包跑通"，收 1-2 单，看反馈
- 为什么先别冲太猛：SDK 还在早期，文档不全，你现在做标准化可能白做，先验证需求
- 配图建议：用微信 Agent 跑通后的对话截图，别用代码界面
