# 今日AI商机

## 先说结论
今天最值得试的是代接入企业微信 MCP，国内厂商刚开始做 CLI 接口,小白还没反应过来,你先帮人跑通就能收钱。

## 今日主推
### 帮人把企业微信接进 AI 工具里,收个跑通费

企业微信刚做了 MCP,飞书钉钉也在跟。很多人想让 AI 直接调企业微信发消息、查日程,但不知道怎么接。你帮他装好、跑通、截个图证明能用,这单就成了。买家今天会心动,是因为他昨天还在手动复制粘贴,今天看到别人已经让 AI 自动发了。

- 适合谁: 用 Claude Desktop 或 Cursor 的人,想让 AI 直接操作企业微信
- 这钱从哪来: 接口刚出来,教程还没铺开,愿意花小钱省折腾时间
- 最简单卖法: 代接入 + 跑通截图 + 基础答疑,收 50-150
- 今天先做哪一步: 先自己跑通企业微信 MCP,录个 3 分钟演示视频
- 今天就能发的文案: "企业微信刚出 AI 接口,我帮你接进 Claude/Cursor 里,让 AI 直接帮你发消息查日程,不用再复制粘贴。包跑通 + 录屏教程,xx 元"
- 配图建议: 用企业微信官方 MCP 文档截图 + 你自己跑通后的终端或聊天界面截图

## 本周可试
### 把代码审查 Skill 打包卖给小团队

OpenAI Codex 刚出了个多 Agent 并行审查的 Skill,能自动查代码里的安全、性能、测试覆盖问题。技术圈在传,但小团队还不知道怎么用。你可以先试着把它配好,打包成"代码审查包",卖给 5-10 人的小团队。但别急着压货,先发 1-2 单测反馈,看他们到底愿意为省多少时间付钱。

- 适合谁: 5-10 人小团队,没专职测试,想让 AI 帮忙查代码问题
- 先怎么试: 先自己跑通 Review Swarm,录个演示,发到技术群或朋友圈,看有没有人问价
- 为什么先别冲太猛: Skill 刚出来,稳定性和实际效果还没经过大规模验证,先小单试水
- 配图建议: 用 Review Swarm 跑出来的审查报告截图,标注出它发现的具体问题

## 今天别碰
### 把同事蒸馏成 Skill 这个梗

看着好玩,但不知道卖给谁。买家不会为了"把同事变成 AI"这个概念付钱,他们只会为"省掉某个具体麻烦"付钱。现在碰了大概率只是帮项目方传播,你自己赚不到。

## 地图感
### CLI 和 MCP 是一回事吗

不是。CLI 是命令行工具,MCP 是让 AI 调用外部服务的协议。最近大家都在做 CLI,是因为 AI 需要一个标准入口去操作各种系统。你不用懂技术细节,只要知道:谁先做了 CLI 或 MCP,谁的服务就更容易被 AI 调用,你就能先帮人接进去收钱。
