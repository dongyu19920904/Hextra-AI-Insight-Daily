## 今日主推
### [你不用自己摸索，这包里有你直接能用的 AI 技能模板](https://x.com/dotey/status/2063107627744145812)

很多人买了 Claude、用上了 Cursor，结果发现不知道怎么让它真正干活——写出来的东西太泛、没有自己的节奏、每次都要重新描述一遍需求。宝玉今天把《图解Skill》的 GitHub Repo 公开了，里面有他自己用的 Skills，比如"把播客文字稿改写成访谈稿"——这种东西，小白光看 README 也看不懂怎么配进去用。

你今天要卖的不是教程，是"配好了、写清楚了、直接复制进去能出结果"的场景包。买家付钱买的是省掉"自己摸索怎么写 Skill"的两小时。

- 参考来源：[宝玉 @dotey](https://x.com/dotey/status/2063107627744145812) / [图解Skill GitHub Repo](https://github.com/JimLiu/Illustrated-Agent-Skills)
- 适合谁：已经有 Claude 或 Cursor 账号、但不知道怎么让它真正提效的人；内容创作者、做播客的、写公众号的
- 这钱从哪来：买家今天刷到"Skill"这个词，心里犯懵——"这跟提示词有什么区别？我要怎么用？"你卖的是替他把答案配好、装进去能跑的那一步，省的是困惑和时间
- 最简单卖法：把 3-5 个最实用的 Skill（比如播客转访谈稿、长文提炼要点、写作风格复刻）整理成中文说明包，配上"复制进 Claude 就能用"的步骤图，定个低价引流款试水
- 今天先做哪一步：打开 [GitHub Repo](https://github.com/JimLiu/Illustrated-Agent-Skills)，挑 3 个你自己能跑通的 Skill，截一张"输入 vs 输出"的对比图，今晚发一条试探帖
- 今天就能发的文案：「花了两小时研究宝玉这个 Skill 包，挑了 3 个普通人最用得上的：播客转访谈稿、长文提炼要点、写作风格复刻。都配了中文说明，复制进 Claude 直接能跑。不想自己折腾的，戳我。」
- 配图建议：用两列对比截图——左边是你在 Claude 里粘贴 Skill 的样子，右边是跑出来的结果；比任何文字说明都直接

## 本周可试
### [一套工具管所有 AI 命令行——cc-switch 跑通包](https://github.com/farion1231/cc-switch)

现在很多人手里同时装着 Claude Code、Cursor、OpenClaw，但每次切换都要重新配环境——这个痛点是真实的，但愿意主动搜这个解法的人现在还是小圈子。cc-switch 这类"一键切换多个 AI 工具"的工具刚冒头，热度在积累，还没到普通用户会主动来问的时候。

这单先别重仓，但值得今晚低成本挂一条——帮人把 cc-switch 配好跑通，换个工具、切换不迷路，卖"装好交付"而不是卖教程。先发一条观察有没有人问，有人问再录屏补细节。

- 参考来源：[cc-switch GitHub](https://github.com/farion1231/cc-switch) / [open-design GitHub](https://github.com/nexu-io/open-design)
- 适合谁：同时用两个以上 AI 工具、每次切换都头疼的人；想试 OpenClaw 但不知道怎么装的新手
- 先怎么试：先发一条"你现在用几个 AI 工具？切换的时候烦不烦"的问题帖，收集反馈；同时低价挂一个"帮你装好 cc-switch，三个工具一键切"的轻服务单，5-10 个字内说清楚你能交付什么
- 为什么先别冲太猛：用多个 AI 命令行工具的用户基数现在还不大，愿意为"切换更顺"付钱的比例不明；先试探，等有人主动问了再加深内容和交付，别先花大力气录课
- 配图建议：截一张 cc-switch 界面里列出多个工具名的截图，配文"这几个都能切"比任何介绍都省事
