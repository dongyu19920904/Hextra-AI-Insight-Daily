## 今日主推
### [用完就忘的 AI 编程助手，今天可以治了](https://github.com/thedotmack/claude-mem)

很多人用 Claude Code 写代码，最烦的一件事是：昨天跟它说好的项目背景，今天开新对话全忘了，又要重新交代一遍。claude-mem 就是专门解决这个问题的——它把每次对话里 AI 做过的事压缩存下来，下次自动带进去，不用你再重复说。

这个需求不是技术圈专属，只要用过 Claude Code 超过三天的人，基本都踩过这个坑。你今天能卖的，就是"帮他装好、跑通、截图给他看"这一步。

- 参考来源：[claude-mem](https://github.com/thedotmack/claude-mem) / [cc-switch](https://github.com/farion1231/cc-switch)
- 适合谁：用 Claude Code 写代码但嫌它"健忘"的人；想试 Agent 工具但不会配环境的中文新手
- 这钱从哪来：买家今天的痛点很具体——每次开新对话都要重新介绍项目背景，烦死了。你帮他装好 claude-mem，他省的是每天重复交代的时间，这个结果他愿意付一笔小钱买断
- 最简单卖法：收代配置费，交付"装好+跑通截图+一页使用说明"；想加一档可以搭 cc-switch（多工具切换桌面助手）一起卖，稍微贵一点
- 今天先做哪一步：自己先把 claude-mem 装一遍，截一张"新对话自动带入上次记忆"的对比截图，这张图就是你今天最好的成交素材
- 今天就能发的文案：「用 Claude Code 写代码，最烦的就是每次开新对话都要重新介绍项目——昨天说好的背景，今天全忘。现在有个工具可以让它记住，我帮你装好跑通，截图验收，有需要私我」
- 配图建议：两张对比截图最好用——左边是没装时新对话一片空白，右边是装了之后自动带入上次记忆的样子；或者直接用 claude-mem 的 README 里的流程图截图

## 本周可试
### [短剧剧本一键生成，GPT 5.5 Pro 已经有人在跑了](https://x.com/vista8/status/2059560634384343324)

有人已经用 GPT 5.5 Pro 做了一个短剧剧本生成 Skill，还在测试阶段，但方向很清晰：短剧编剧这个需求真实存在，愿意付钱的人也不少。现在还没人把它包成一个"小白直接能用的模板包"，这个窗口今天还开着，但等别人先跑出来就晚了。

先别急着做大而全的课程，今天可以先试发一个"短剧剧本生成模板包"的预告，看看有没有人问——有人问再做，没人问换方向，成本几乎是零。

- 参考来源：[vista8 推文](https://x.com/vista8/status/2059560634384343324)
- 适合谁：做短视频、写短剧脚本、或者帮甲方做内容的人；有 GPT 账号但不知道怎么用在具体场景上的人
- 先怎么试：先发一条"短剧剧本生成模板包，有需要的扣1"，看看反应；有人问就整理一个 3-5 个场景的提示词模板包，配一页使用说明，定个低价先跑
- 为什么先别冲太猛：这个 Skill 还在测试阶段，效果没有公开验证；短剧赛道竞争也快，先小范围试发验证需求，确认有人愿意付钱再加深投入，别一上来就做大课
- 配图建议：用 GPT 生成一段短剧剧本的截图，配上"输入：题材+人物，输出：完整剧本框架"的对比展示，比任何文字说明都直接
