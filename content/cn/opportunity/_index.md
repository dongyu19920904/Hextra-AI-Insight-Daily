# 今日AI商机

## 先说结论
今天先卖 **Claude 入口 + 场景搭售包**，因为第三方路子刚变，很多人会立刻想找“能直接用、有人带着跑通”的替代方案。

## 今日主推
### 别让买家自己踩坑：把 Claude 直接用起来，再顺手交付一套现成场景

这单今天最顺。不是因为工具多新，而是因为很多人刚发现：原来靠第三方接着用的路子，突然没那么省心了。买家这时候不会想听技术解释，只会想找一个**今天就能上手、最好有人告诉我第一步点哪**的入口。

你卖的也别复杂。不是卖“AI概念”，而是卖**Claude 入口 + 登录说明 + 3 个常用场景教程/模板 + 一段录屏**。买家拿到就能开始用，成交会比纯教程顺很多。

- 适合谁：
  - 已经知道 Claude，但一直没正式用起来的人
  - 之前靠第三方工具蹭着用，现在想找更直接入口的人
  - 想拿 Claude 做写作、翻译、总结、代码辅助，但不会配置的人

- 这钱从哪来：
  - 买家今天会心动，不是因为他突然想研究模型，而是因为原来的使用路径一变，他马上会担心“以后怎么继续用”“我现在到底该怎么开始”。
  - 这时候有人把入口、说明、常用场景一次性整理好，他愿意为**省时间、少踩坑、有人答一句**付钱。

- 最简单卖法：
  - 先做成 **Claude 入口 + 基础上手包**
  - 再加一个轻搭售：**写作/翻译/代码辅助三选一场景包**
  - 如果你手上能交付录屏，就顺手做成 **账号/入口说明 + 场景教程 + 基础答疑** 的标准成交款

- 今天先做哪一步：
  - 先把交付物压缩到 4 样：**入口说明、登录流程截图、3 个场景提示词、1 段 3 分钟录屏**
  - 不要一上来做大全。先把“新手第一次用 Claude 怎么不迷路”这件事跑通

- 今天就能发的文案：
  - **今天很多人不是不会用 AI，是突然发现原来的路子没以前顺了。**
  - **我这边整理了一套 Claude 直接上手包：入口说明 + 登录步骤 + 3 个常用场景模板 + 录屏，新手拿到就能开始用。**
  - **适合想先把写作/翻译/代码辅助跑起来的人，不想自己翻半天资料的来。**

- 配图建议：
  - 最好用 **Claude 界面实拍 + 你的交付目录截图** 这一张图说清楚
  - 第二张可以放 **“3 个场景模板封面图”**，比如：写作润色、长文总结、代码解释
  - 不要只放新闻截图。买家更想看“你交付什么”

## 本周可试
### 把原来卡住的 Agent 先迁到能继续跑的路子，OpenClaw 迁移跑通包

这单有需求，但今天不适合重压。真正愿意付钱的，不是围观看热闹的人，而是**已经在用、现在突然卡住、又懒得自己排错**的那一小批用户。先做小范围试发，别铺太大。

你可以卖的不是“OpenClaw 新装热单”，而是**迁移、替代、跑通**。比如：帮用户把原来的 Agent 使用方式换成还能继续用的方案，再补一份录屏说明。

- 适合谁：
  - 之前已经玩过 Agent、现在遇到使用路径变化的人
  - 想继续做自动化，但不想自己查文档、改配置的人
  - 社群里已经有人来问“那现在怎么办”的卖家

- 先怎么试：
  - 先发一个 **“我可帮你把原来 Agent 使用方式迁到能继续跑的方案”** 的试单帖
  - 先接 1 对 1 小单，交付内容控制在：**代配置 + 跑通截图 + 录屏说明**
  - 先挑最容易标准化的 1 个场景，比如“本地跑通”“基础问答可用”“一个固定流程可执行”

- 为什么先别冲太猛：
  - 现在变化还在发酵，用户需求是真的，但方案还在变
  - 太早做成大套餐，容易交付边界不清，售后会变重
  - 这类单更适合先当 **高意向私聊成交款**，不是先做成广撒网爆款

- 配图建议：
  - 用 **跑通前后对比图** 最好：左边是报错/卡住，右边是已跑通界面
  - 再加一张 **你的交付清单图**：代配置、截图、录屏、基础答疑
  - 少放技术流程图，多放“结果图”

## 今天别碰
### 别把 OpenClaw 新装当爆款去冲

看着热，实际上对小白不友好。规则刚变，用户最关心的是“还能不能继续用、值不值得折腾”，不是再听你讲一遍新项目名。现在贸然做大范围新装推广，很容易变成你自己先吃一轮售后。

## 地图感
### 本地模型接入会越来越常见，但今天先别把它当主货卖

像 Codepilot 接本地模型这类变化，说明一个方向：以后会有更多人想要“云上模型 + 本地模型”一起用。但对今天的小白买家来说，他先要的是**能开始用**，不是先搭一整套复杂环境。

## 今日动作
- 先发什么：
  - 发一条 **“原来靠第三方用 Claude 的，今天先别乱找教程，我这边整理了直接上手包”** 的短帖，重点写清交付物，不讲太多背景

- 先录什么：
  - 录一个 **3 分钟上手视频**：进入界面、完成一次提问、套用一个场景模板、得到结果  
  - 让买家看到“拿到后今天就能用”

- 先卖哪一款：
  - 先卖 **Claude 入口 + 基础教程 + 3 个场景模板** 这一款  
  - 这是今天最容易成交的标准小单，也是后面加答疑、加配置、加场景包的起点
