# 今日AI商机

## 先说结论
飞书开源 CLI 让 Claude 能直接操作飞书全家桶，今天最值得试的是帮小白跑通"让 AI 自动建文档、排日历"。

## 今日主推
### 让 Claude 自动操作飞书,代跑通包今天能卖

很多人想让 AI 帮自己建文档、排日历、发群消息,但一看到"CLI""配置""权限"就头大。飞书刚开源了 CLI 工具,现在 Claude 能直接调飞书的所有能力,但大部分人装不明白。你今天能卖的就是帮他们跑通这件事,交付一个"告诉 AI 一句话,它就能帮你操作飞书"的环境。

- 适合谁: 用飞书办公,想让 AI 帮自己干活,但不会装 CLI 的小白
- 这钱从哪来: 飞书今天开源了 CLI,Claude 现在能操作飞书文档、日历、群消息、多维表格,但装起来要处理权限、认证、配置,小白自己搞不定
- 最简单卖法: 代跑通服务,收 50-150,帮用户装好 CLI、配好权限、测试能用,交付一份"怎么让 Claude 帮你干活"的说明
- 今天先做哪一步: 先自己跑通一遍飞书 CLI + Claude 的组合,录一个"AI 帮我建了份文档"的演示视频
- 今天就能发的文案: "飞书开源了 CLI,现在 Claude 能帮你自动建文档、排日历、发消息。不会装?我帮你跑通,50 块,半小时交付,包测试能用。"
- 配图建议: 用飞书 CLI 官方 GitHub 页面截图 + 你自己录的 Claude 操作飞书的演示画面

## 本周可试
### Gemini 安卓版升级,低价体验号可以试发

Gemini 这周在安卓上更新了 Live 模式,能边聊边记住上下文,反应也快了。想试 Gemini 的人多了,但官方订阅对小白来说还是贵。你可以试着发低价体验号,搭个基础上手包,先看看有没有人愿意为"试一下 Gemini Live"付个小钱。

- 适合谁: 想试 Gemini 新能力,但只想先低成本体验的安卓用户
- 先怎么试: 先发朋友圈或群里,挂个 19.9 的 Gemini 体验号 + 登录说明,看看有没有人问
- 为什么先别冲太猛: Gemini 的更新主要在安卓端,用户群还不够明确,先小单测反馈,别一上来就囤号
- 配图建议: 用 Gemini 官方推特发的 Live 模式演示视频截图

## 今天别碰
### 字节开源的沙箱环境,现在碰大概率白忙

字节开源了 AIO Sandbox,看着热闹,但这是给开发者用的底层环境,不是给小白用的工具。你现在去卖"沙箱配置服务",买家听不懂,也不知道要拿它干嘛,等过段时间有人把它包装成具体应用再说。

## 地图感
### CodePilot 的 CLI 管理系统是什么

就是让 AI 能自动装工具、配权限、生成说明的系统。以前你要手动装 CLI、改配置,现在告诉 AI 一句话,它自己搞定。藏师傅把网易云、飞书、即梦的 CLI 都接进去了,还给每个工具打了"对 AI 友好度"的分。
