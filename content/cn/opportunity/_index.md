## 今日主推
### [帮你把 Claude Code 跑起来，你不用碰终端](https://x.com/dotey/status/2044145889707774000)

很多人听说 Claude Code 重新设计了，心动了，打开一看——全是英文，全是命令行，直接关掉。这个"打开又关掉"的瞬间，就是你的生意入口。

你不需要教他们懂原理。你只需要帮他们跑通一次：装好、配好、跑一个真实任务、截图给他看。他付钱买的是"我终于用上了"这个结果，不是教程本身。

今天 Claude Code 桌面端刚完成底层重构，支持同时跑多个任务、可视化差异审查、应用预览——功能变强了，但门槛也更高了。小白更需要有人帮他迈过第一步。

- **适合谁：** 听说过 Claude Code、想用但没跑通过的中文新手；有点技术好奇心但不想自己排错的人
- **这钱从哪来：** Claude Code 刚重构完，功能变多了，想试的人多了，但能自己装好的人没变多——这个落差就是付费动机。买家今天心动的理由是"刚更新，现在上手正好"
- **最简单卖法：** 轻服务，代配置跑通包。你帮他装好、跑通一个任务、交付截图+简单说明，收一个小单费用。可以先发低价引流款（只跑通基础环境），再搭一个进阶款（跑通+答疑+模板）
- **今天先做哪一步：** 自己先把新版 Claude Code 桌面端装好跑一遍，截一张"任务跑完"的截图，这就是你今天最值钱的素材
- **今天就能发的文案：** "Claude Code 刚重构了，很多人打开就懵。我帮你装好、跑通第一个任务，你直接用结果。有需要私我。"
- **配图建议：** 用 Claude Code 桌面端跑任务完成的截图，或者官方发布的演示视频截帧——有"任务完成"状态的画面最有说服力

## 本周可试
### [一份"我替你试过这几个 AI 编程工具"的对比筛选包](https://x.com/dotey/status/2043911437697888290)

现在市面上 AI 编程工具一堆：Claude Code、Cursor、GitHub Copilot、各种开源 Agent……小白根本不知道从哪个开始。他们不缺工具，缺的是"有人替我先试过，直接告诉我选哪个"。

这个方向不用你今天就冲，但值得这周开始攒素材。先做一个 2-3 个工具的中文对比清单，不是测评文章，是"你的情况适合用哪个"的筛选服务。

- **适合谁：** 想用 AI 写代码但不知道从哪个工具入手的中文新手；预算有限、不想每个都买来试的人
- **先怎么试：** 先做一个轻量对比卡片（Claude Code vs Cursor vs 免费方案，各自适合谁、门槛多高、能跑通什么），发到群里或朋友圈，看有没有人问"我适合哪个"——有人问就是成交信号
- **为什么先别冲太猛：** Claude Code 刚重构，功能还在变，这周先攒素材、测反馈，下周再做成正式商品更稳。现在重投入做完整课程，内容可能很快就过时
- **配图建议：** 做一张简单的三列对比表截图，工具名 + 适合谁 + 门槛高低，视觉清晰，容易被转发
