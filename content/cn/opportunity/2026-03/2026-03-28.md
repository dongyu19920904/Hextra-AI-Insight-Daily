# 今日AI商机

## 先说结论
OpenAI 砍产品线的同时，Anthropic 泄露了比 Opus 更强的新模型，今天最值得试的是帮小白跑通 Claude API 接入。

## 今日主推
### 帮人把 Claude API 接进自己的工具里

OpenAI 这周砍了三条产品线，Sora、内置结账、成人聊天全停了。很多人开始担心自己用的 GPT 接口会不会也突然没了。正好 Anthropic 泄露出来一个比 Opus 还强的新模型 Mythos，技术圈都在讨论要不要多备一条 Claude 线路。

问题是大部分人不会自己接 API，看着文档头疼，试两次报错就放弃了。你今天能卖的就是帮他们把 Claude 接进他们正在用的工具里，跑通、测试、交付截图，让他们直接能用。

- 适合谁：已经在用 GPT API 的人，想多备一条 Claude 线路但不想自己折腾
- 这钱从哪来：OpenAI 砍产品线让人没安全感，Anthropic 新模型泄露让人想试，但自己接不通就会找人代劳
- 最简单卖法：代接入 Claude API + 跑通测试 + 交付说明，按次收费或按工具收费
- 今天先做哪一步：先在社群或朋友圈发一条"帮接 Claude API，今天能交付"，配上一张你自己跑通的截图
- 今天就能发的文案：OpenAI 这周砍了三条线，很多人开始找备用方案。我这两天帮几个朋友把 Claude 接进他们的工具里了,跑通、测试、交付说明都给你。不想自己折腾的可以找我,今天能交付。
- 配图建议：用一张 Claude API 调用成功的终端截图或返回结果截图,证明你真的跑通了

## 本周可试
### Stripe CLI 插件代配置

Stripe 推出了一个新插件 Stripe Projects,可以让 AI 帮你处理服务商付费,不用每次都手动输卡号。听起来很方便,但实际上大部分人连 Stripe CLI 都没装过,更别说配置插件了。

这单有苗头,因为确实能省事,但现在还不用重投入。先试着在社群里问一句"有人想试 Stripe 新插件吗",看看有没有人回应。如果有人问,就帮他配一次,收个小钱,顺便看看这个需求到底有多大。

- 适合谁：正在用 Stripe 收款的人,想让 AI 帮忙处理付费但不想自己研究 CLI
- 先怎么试：先在社群或私聊里问一句,看有没有人想试,有人回应再帮他配一次
- 为什么先别冲太猛：Stripe CLI 本身就有门槛,用的人不多,这个插件刚出来,需求还不明确,先小范围试试水
- 配图建议：用 Stripe 官方博客或文档的截图,证明这是真实功能

## 今天别碰
### Codex 插件创建功能

Codex 刚支持插件,还内置了插件创建功能,技术圈很热闹。但这东西现在不适合小白做,因为创建插件需要懂开发,而且 Codex 本身的用户基数还不够大,你做出来也不知道卖给谁。等它用户多了,插件市场起来了,再考虑做插件模板包或代创建服务。

## 地图感
### iOS 27 的 Siri 要变成 AI 中枢了

苹果在憋大招,iOS 27 里 Siri 会变成一个 AI 中枢,可以把请求转发给第三方大模型。这意味着以后你在 iPhone 上用 AI 会更方便,但现在还没发布,只是个消息。知道就行,不用现在做什么,等正式发布了再看有没有机会。
