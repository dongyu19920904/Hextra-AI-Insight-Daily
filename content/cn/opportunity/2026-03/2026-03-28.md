# 今日AI商机

## 先说结论
OpenAI 一周砍三个产品，老用户手里的 Pro 账号反而成了稀缺货，今天先试卖"Pro 账号+稳定使用说明"。

## 今日主推
### Pro 账号现在能卖出溢价，因为 OpenAI 在收缩产品线

OpenAI 这周关了 Sora、砍了内置支付、停了成人聊天功能。产品线收缩的时候，老用户手里稳定能用的 Pro 账号反而变成了硬通货。很多人担心自己新注册会踩坑，或者担心功能随时变，这时候你手里有个跑了几个月的老号，配上一份"哪些功能还能用、怎么用最稳"的说明，就是今天能成交的理由。

- **适合谁**：想用 GPT-4 或 Pro 功能，但不想自己踩 OpenAI 产品变动的坑
- **这钱从哪来**：OpenAI 砍产品让用户没安全感，稳定老号+使用说明能让人少担心
- **最简单卖法**：Pro 老号 + 一份"当前可用功能清单+稳定使用建议"，先卖 1-2 单测反馈
- **今天先做哪一步**：整理一份你手里 Pro 账号的功能截图，标注哪些还能用、怎么用最省心
- **今天就能发的文案**：OpenAI 这周砍了三个功能，手里的 Pro 老号反而成了稀缺货。我这有跑了几个月的稳定号+使用说明，需要的私聊
- **配图建议**：用 Pro 账号后台截图，圈出当前可用的核心功能，配上"稳定使用 X 个月"的标注

## 本周可试
### Claude 新模型泄露，但先别急着囤号

Anthropic 不小心泄露了比 Opus 更大的新模型 Mythos，技术圈在讨论定价会有多贵。但这事儿现在只适合盯着，不适合重投入。因为模型还没正式发，定价、使用门槛、稳定性都是未知数，现在囤号或者提前卖"新模型体验"很容易踩空。

- **适合谁**：手里有 Claude 账号资源，想提前布局但不想压太多成本的人
- **先怎么试**：先在社群或朋友圈发一条"Claude 新模型快出了，到时候可以帮跑通"，测测有没有人问
- **为什么先别冲太猛**：模型没发布，定价和使用规则都不确定，现在大量囤号或承诺交付容易被动
- **配图建议**：用 Anthropic 官网或泄露新闻的截图，标注"新模型 Mythos 即将发布"

## 今天别碰
### Stripe CLI 插件和 Siri AI 中枢，技术圈热闹但离小白赚钱太远

Stripe 推了个 CLI 插件，Siri 要变 AI 中枢，听着很酷，但这两个都不是今天能包装成商品的东西。Stripe 的事儿是给开发者用的支付工具，Siri 的事儿要等到 iOS 27 才落地，现在写了也没人买单。

## 地图感
### Agent 工具都在往 CLI 方向走，但暂时不用追

Stripe、Codex 这些工具都在推 CLI 插件，说明 Agent 生态在往命令行方向靠。但这个趋势对小白来说暂时用不上，知道有这个方向就行，不用现在就去学或者卖相关服务。
