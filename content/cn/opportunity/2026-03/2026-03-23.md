## 今日可卖

### Claude 账号 + baoyu 技能包上手教程
- **可直接发布的商品标题**：Claude Pro 账号 + 宝玉技能包安装教程，10 分钟上手 YouTube 字幕提取
- **今天适合卖什么**：Claude 账号搭配 baoyu-skills 安装和使用教程
- **适合卖给谁**：想用 Claude 但不会装技能包的新手、需要 YouTube 字幕提取的内容创作者
- **为什么今天能卖**：baoyu-skills 刚破 10K stars，193.7K 安装量，YouTube 字幕提取技能刚发布，正是热度期
- **建议卖法**：账号 + 技能包安装教程 + 常用技能使用说明
- **更适合单卖还是搭售**：搭售
- **如果搭售，最适合搭什么**：Claude 账号 + 3-5 个实用技能安装教程（YouTube 字幕、文件处理、代码辅助）+ 7 天答疑
- **低价引流款**：Claude 基础账号 + 1 个技能安装视频教程（29-39 元）
- **标准成交款**：Claude Pro 账号 + 5 个常用技能包教程 + 安装答疑（79-99 元）
- **搭售利润款**：Claude Pro 账号 + 技能包全套教程 + 代安装配置 + 14 天陪跑（159-199 元）
- **今天值不值得发**：值得，技能包热度正好，搭配账号卖教程是标准打法
- **注意事项**：教程要写清楚技能包安装步骤，别只给链接；YouTube 字幕提取功能要演示一遍；不要承诺所有技能都能用

### 微信 Agent 接入代配置服务
- **可直接发布的商品标题**：微信龙虾插件代配置，把你的 AI Agent 接入微信私聊
- **今天适合卖什么**：帮用户把现有 Agent（Claude/GPT/自建 bot）接入微信的代配置服务
- **适合卖给谁**：有 Agent 但不会接微信的开发者、想在微信里用 AI 的小团队
- **为什么今天能卖**：微信官方刚上线 Openclaw 插件，SDK 封装刚出来，正是接入窗口期
- **建议卖法**：按次收费的代配置服务 + 标准交付文档
- **更适合单卖还是搭售**：单卖为主，可选搭售后续调试
- **如果搭售，最适合搭什么**：代配置 + 7 天调试答疑 + 常见问题处理
- **低价引流款**：基础接入配置（仅跑通 echo bot）（49-69 元）
- **标准成交款**：完整接入 + 测试 + 交付文档（129-159 元）
- **搭售利润款**：接入 + 定制功能调试 + 14 天技术支持（299-399 元）
- **今天值不值得发**：先小范围试发，微信插件还在灰度，不是所有人都能用
- **注意事项**：明确说明目前只支持私聊；灰度期间可能有用户接不上，要提前说清楚；不要承诺商业化稳定性

## 本周可试

### Agent 技能包定制服务
- **可直接发布的商品标题**：定制你的 Agent 技能包，针对你的业务场景写专属 skill
- **为什么值得试**：baoyu-skills 热度起来了，但通用技能包不一定适合所有场景
- **更适合谁来做**：会写代码、懂 Agent 开发的技术卖家
- **先怎么小成本试**：先在技术群里问有没有人需要定制技能包，收 1-2 单试试交付流程
- **为什么现在先别放大**：定制开发交付周期长，标准化程度低，不适合批量卖
