### baoyu-skills 技能包现在能卖

- 适合卖给谁：已经在用 Claude 或 Cursor 但不知道怎么装技能的中文用户
- 为什么今天能卖：baoyu-skills 刚破 10K stars，193.7K 安装量，还发布了新的 YouTube 字幕提取技能，热度正好
- 建议卖法：技能包安装教程 + 常用技能清单 + 答疑群
- 更适合单卖还是搭售：更适合搭售，单独卖教程太薄
- 如果搭售，最适合搭什么：Claude 账号 + baoyu-skills 安装教程 + 10 个常用技能配置
- 今天值不值得发：值得，现在装的人多但不会装的更多
- 注意事项：不要承诺所有技能都能用，只写你测过能跑通的；不要把开源项目说成你开发的

### OpenClaw 微信接入代配置服务
- 今天适合卖什么：OpenClaw 代配置、微信 Clawbot 插件跑通服务、个人微信 AI 助手搭建
- 适合卖给谁：想在微信里用 Claude 但不会配置的人、想给团队搭私有 AI 助手的小老板
- 为什么今天能卖：微信官方刚上线 Clawbot 插件，还有人开源了微信 agent SDK，正是配置需求爆发期
- 建议卖法：代配置服务（一次性收费）+ 7 天答疑 + 可选的后续维护包月
- 更适合单卖还是搭售：可以单卖服务，也可以搭售 Claude 中转或账号
- 如果搭售，最适合搭什么：OpenClaw 代配置 + Claude API 中转 + 微信接入 + 基础使用教程
- 今天值不值得发：值得，微信插件刚出，现在是第一波吃螃蟹的窗口期
- 注意事项：不要承诺永久稳定，微信插件是灰度测试；不要说能突破微信限制做营销；明确告知这是个人使用场景

## 本周可试

### 微信 Agent SDK 接入服务
- 为什么值得试：wong2 开源了微信 agent SDK，可以把任意 agent 接入微信，技术门槛降低了
- 更适合谁来做：会写点 Python 或 Node.js 的开发者，或者愿意学着跑通的技术卖家
- 先怎么小成本试：先自己跑通一个 echo bot，录个视频证明能用，然后挂个"代接入服务"测试需求
- 为什么现在先别放大：SDK 刚出，稳定性未知；微信官方态度不明确；大部分人还在观望 Clawbot 插件够不够用
