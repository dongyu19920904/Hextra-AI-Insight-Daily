# 今日AI商机

## 先说结论
今天最值得试的，不是卖概念，而是把`Claude账号入口 + 中文写作整理模板包`打成一套，先卖“拿来就能出内容”的小套餐。

## 今日主推
### 写作整理直接交付，Claude 账号 + 中文模板包
这是一单更容易成交的“结果型商品”：买家不是想研究模型，而是想今天就把写作、翻译、长文整理跑起来。

- 适合谁：想用 AI 写文案、做翻译、整理资料，但不想自己折腾入口和提示词的中文新手。
- 为什么今天能卖：买家愿意下单的原因很简单——他们想立刻用上、立刻出结果。今天 Claude 相关讨论还在发酵，配合最近围绕 Claude 工作流、远程连接和场景使用的更新，正适合把“账号+模板+答疑”一起卖。
- 最简单卖法：`Claude账号入口 + 登录说明 + 5个常用中文模板`，模板只放最容易见结果的场景：长文整理、口语翻译、爆款文案、会议纪要、资料总结。
- 参考卖法：`低价引流款：账号入口 + 登录说明`；`标准成交款：账号入口 + 10个中文模板 + 1次答疑`；`搭售利润款：账号入口 + 模板包 + 环境配置检查 + 7天陪跑`
- 今天先做哪一步：先做 3 张结果截图，分别是“原文很乱→整理版”“普通文案→优化版”“长链接内容→摘要版”，再把模板整理成一页图。
- 今天就能发的文案：`想用 Claude 写文案、翻译、整理资料，但不想自己折腾入口和提示词的，可以直接拿现成版。今天我这边做了一个能直接上手的小包：账号入口 + 常用模板 + 基础说明，适合先低门槛试用。需要我发你看演示图。`
- 配图建议：用`原始信息源里 Claude-to-IM-Skills 更新的截图`，说明今天 Claude 工作流热度在；再用`你自己做的前后对比图`，直接证明买家能拿到什么结果。

## 本周可试
### 微信里直接收发 AI 结果，OpenClaw 跑通包
这类机会离成交很近，但版本变化快，更适合先做小单试卖，不适合一上来做重交付。

- 适合谁：想把 Agent 接到微信里用起来，但不会配环境、不会排错、只想先跑通一次的人。
- 先怎么试：先卖`跑通版小服务`，只承诺基础接入、基础测试、截图或录屏交付；先在私聊和社群里收 3 个以内试单。
- 为什么别一下冲太猛：这类工具最近更新频繁，前面已经出现过版本 bug 和插件连接波动，售后容易变重，先小范围验证比直接铺大单更稳。
- 配图建议：用`原始信息源里“支持微信桥接/扫码配置”的截图`，帮助买家理解“能跑通到哪一步”；再用`你自己的微信收发测试图`，证明你不是只会转热点。

## 今天别碰
### 只卖新版插件系统教学课
热是热，但现在版本还在变，插件连接和打包问题都出现过；小白最容易买完不会配，你也最容易陷入高售后，不适合当今天主卖款。

## 地图感
### 以后更值钱的不是单个工具，是跨工具通用配置包
今天能看到一个很明显的方向：Claude、Codex、Cursor 这类工具越来越像“同一套场景，不同入口”，以后更好卖的是标准模板、配置包、跑通包，不是单点教程。

## 今日动作

- 先录什么：先录一个`1分钟演示视频`，从原始长文到整理结果，展示模板怎么直接套。
- 先卖哪一款：先卖`标准成交款`，也就是`账号入口 + 10个模板 + 1次答疑`。
