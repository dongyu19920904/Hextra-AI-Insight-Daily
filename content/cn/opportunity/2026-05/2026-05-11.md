## 本周可试
### 把 Codex CLI 包成"帮你装好、帮你用起来"的小服务

Codex CLI 这周安装量数据很夸张，说明有大量人在尝试，但安装量高不等于用起来了。很多人装了跑不通，或者装好了不知道怎么用在自己的工作上。

这单不用今天就冲，因为需求还在发酵，现在先做一个"帮你装好 Codex CLI + 教你用一个场景"的小包，低价挂着，等问的人多了再加深服务。

- **适合谁：** 想用 AI 写代码但不会配环境的人，或者已经听说 Codex 但卡在安装步骤的小白
- **先怎么试：** 先自己把 Codex CLI 跑通，整理一份中文安装说明 + 一个最简单的使用场景截图，做成一个 29-49 的小包先挂着，看有没有人问

- **配图建议：** 用 Codex CLI 跑通后的终端截图，加一行中文说明"这是帮你配好之后的样子"，对比感强
