## 今日主推
### [你的 AI 团队配置包，帮你省掉两小时折腾](https://github.com/garrytan/gstack)

有个叫 gstack 的配置在 GitHub 上冒出来，里面是 Y Combinator 合伙人 Garry Tan 自己用的 Claude Code 设置——23 个角色分工，CEO、设计师、工程经理、QA 各司其职，让 AI 真的像个小团队在帮你干活。问题是，大多数人看到这种项目的第一反应是：好像很厉害，但我不知道怎么装。

这就是你今天能卖的东西。不是卖项目本身，是卖"我替你装好、配好、跑通给你看"的结果。买家付的是省掉自己踩坑的时间，不是买一个 GitHub 链接。

- 参考来源：[gstack](https://github.com/garrytan/gstack) / [taste-skill](https://github.com/Leonxlnx/taste-skill)
- 适合谁：看见热门 AI 项目很心动，但不会装、不会配、不知道从哪开始的中文新手
- 这钱从哪来：买家今天刷到这个项目，觉得"这个我要用"，但打开 GitHub 就懵了——你卖的是帮他跳过这一步，直接拿到跑通的结果
- 最简单卖法：先自己跑通一遍，截几张配置成功的图，写一份中文安装说明，打包成"Claude Code 多角色跑通包"，定价 19-39 元，闲鱼或私域都能挂
- 今天先做哪一步：今晚先把 gstack 本地跑通，截图留存，写一份 300 字以内的中文上手说明，这就是你的交付物
- 今天就能发的文案：「Claude Code 有个配置，能让 AI 同时扮演 CEO、设计师、QA 帮你干活——但装起来要折腾。我整理了中文跑通包，买了直接用，不用自己踩坑。」
- 配图建议：用 gstack 项目页截图 + 本地跑通后的终端截图，两张并排，左边"看起来很复杂"，右边"跑通了"

## 本周可试
### [AI 写出来的内容太平？这个品味包可能值得试卖](https://x.com/op7418/status/2060192275301642532)

taste-skill 和 PPT Skills 这类"给 AI 加品味"的配置包，已经有人拿去做小红书内容拿到千赞了。说明买家不只是想要 AI 工具，他们想要的是"AI 帮我出的东西不丢人"。这个需求是真实的，但现在还在早期验证阶段，先小范围试发，看有没有人主动来问。

- 参考来源：[歸藏推文](https://x.com/op7418/status/2060192275301642532)
- 适合谁：已经在用 Claude 或 ChatGPT 做内容，但总觉得生成结果太普通、太像 AI 腔的人
- 先怎么试：整理一份"让 AI 写出有品味内容"的中文 Prompt 模板包，配 2-3 个前后对比截图，先发朋友圈或社群，看有没有人主动问价
- 为什么先别冲太猛：这类模板包的成交依赖买家自己先感受到"AI 写的东西太烂"的痛点，需要用对比内容来触发，冷启动期转化慢；先测反馈，有人问再上架
- 配图建议：同一个主题，左边是普通 AI 输出，右边是加了 taste-skill 配置后的输出，对比要明显，让人一眼看出差距
