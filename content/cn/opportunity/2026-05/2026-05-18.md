## 本周可试
### [帮人把 AI Agent 跑通，比教人学 Agent 更好卖](https://github.com/thedotmack/claude-mem)

Agent 工具这周密度很高——claude-mem 跨会话记忆、cc-switch 多工具切换、gstack 23个角色配置，每一个单独看都挺复杂。但买家不想学，他们只想知道"这东西能不能帮我省事，帮我装好"。

现在还不用重投入，因为这些工具刚出来，中文教程和踩坑记录还很少，你先跑通一个、做出截图，就已经比大多数人快了。先发一版"帮你跑通 claude-mem / gstack，附配置说明"的轻服务，测一下有没有人问，再决定要不要深做。

- 参考来源：[claude-mem](https://github.com/thedotmack/claude-mem) / [gstack](https://github.com/garrytan/gstack) / [cc-switch](https://github.com/farion1231/cc-switch)
- 适合谁：对 Agent 工具感兴趣、但自己装不上、跑不通、不知道从哪开始的中文新手
- 先怎么试：挑 claude-mem 或 gstack 其中一个，自己先跑通，截图记录过程，发一条"帮你配好，附说明"的轻服务帖子，定价 29-59 元，先看有没有人私信
- 为什么先别冲太猛：这几个工具都是近两天才热起来，中文用户真实需求量还没验证；先小范围试发，有人问再加深，不用一上来就做全套教程
- 配图建议：用 gstack 的 23个角色配置界面截图，或 claude-mem 跨会话记忆的对比截图，配一行"以前每次都要重新说，现在它记住了"
