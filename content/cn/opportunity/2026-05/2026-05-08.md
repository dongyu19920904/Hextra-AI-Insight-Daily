## 今日主推
### 不用开网页，在 Excel 里直接喊 Claude 干活——帮你配好这套

很多人买了 Claude 账号，但一直停在网页端用。今天 Anthropic 把 Excel、Word、PPT 三个插件正式转为 GA，Outlook 也进了公测——意味着你可以在表格里、PPT 里、邮件里直接调 Claude，不用来回切窗口。

问题是：大多数人看到这个消息，第一反应是"好像很厉害"，第二反应是"但我不知道怎么装"。这就是今天的成交缝隙——帮人把这套插件配好、跑通、交付一份"装完就能用"的说明包。

卖的不是账号，卖的是"你不用自己折腾，我替你装好、测好、告诉你第一步怎么用"。

- **适合谁：** 已经有 Claude 账号、用 Microsoft 365 办公、但不知道怎么接插件的职场人；或者想给同事/老板推荐 Claude 的人
- **这钱从哪来：** Claude 插件今天刚转正式版，很多人今天才看到消息，想试但不知道从哪下手——信息差窗口就在今天
- **最简单卖法：** 自己先跑通一遍（装插件 → 在 Excel 里测一个真实场景 → 截图），打包成"Claude × Office 跑通包"：含安装步骤、3 个场景示例（表格整理 / PPT 大纲 / 邮件回复）、答疑一次。低价引流款先挂 19-29 元试水，有人问再加深
- **今天先做哪一步：** 自己先把 Excel 插件装上，跑一个"整理一张乱表格"的截图，这就是今天的发圈素材和商品封面
- **今天就能发的文案：**
  > Claude 今天正式进 Excel 了。不用开网页，在表格里直接喊它整理数据、写公式、生成报告。
  > 但装插件这步很多人卡住——我整理了一份跑通说明，含安装步骤 + 3 个办公场景示例，直接拿去用。
  > 需要的扣 1，我发你。
- **配图建议：** 截一张 Excel 表格里调出 Claude 侧边栏、正在处理数据的实际界面图，比任何文字都有说服力

## 本周可试
### 把 AI 自动化技能包翻成中文，卖给"有工具但不会配"的人

Warp 这两天开源了一套 14 个预构建技能库，覆盖 CI 修复、文档更新、Issue 分类这类 DevOps 场景。技术圈在转，但真正的机会不在技术圈——在那些"听说 AI 能自动化，但不知道从哪抄作业"的人身上。

这件事今天还不用重投入，因为买家群体偏技术，成交链路比 Office 插件长一点。但值得先做一件事：把这 14 个技能翻成中文场景清单，加上"你能用在哪"的一句话说明，打包成一个"AI 自动化场景速查包"，先挂着试试有没有人问。

- **适合谁：** 有一点技术背景、用过 GitHub 或 CI 工具、但不知道 AI 能帮自己省哪些重复操作的开发者或运维
- **先怎么试：** 把 14 个技能翻成中文 + 每个加一句"适合什么场景用"，做成一页 PDF 或 Notion 页面，先在技术社群试发，看有没有人主动问"怎么用"
- **为什么先别冲太猛：** 买家需要先有 Warp 环境，上手门槛比 Office 插件高；现在适合做引流内容和低价包，不适合直接卖高价陪跑
- **配图建议：** 截一张 14 个技能的列表界面，旁边加中文场景标注，一眼看出"这是能直接抄的清单"

## 今天别碰
### Claude "做梦"功能 / Agent 记忆整理

Claude 开发者大会上推了一个"Dream"功能，让 Agent 异步整理记忆。听起来很酷，但这是给开发者调 API 用的，不是给普通用户点一下就能用的产品。小白现在碰这个，大概率只能转发热闹，转化不了一单。

## 地图感
### Markdown 成了 AI 时代的"通用语言"

Obsidian 作者说了一句话值得记住：Markdown 已经是 AI 文件交互的默认格式，大家都在默契地往这个方向走。不用深究技术原因，只需要知道：以后你做的模板包、交付文档、场景说明，用 Markdown 格式写，AI 工具读起来最顺，也最容易复用。
