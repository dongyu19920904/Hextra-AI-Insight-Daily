## 本周可试
### [花 20 分钟做一份"AI 工具选哪个"中文对比包，卖给纠结的新手](https://github.com/x1xhlol/system-prompts-and-models-of-ai-tools)

GitHub 上有人把 Cursor、Claude Code、Windsurf、Devin、Kiro 等二十多个 AI 编程工具的系统提示词和模型配置全扒出来了，技术圈在讨论"谁的 prompt 更聪明"，但普通用户根本看不懂，他们只想知道：**我该用哪个、有什么区别、新手从哪个开始**。

这个信息差现在还新鲜，但做成对比包需要一点整理时间，先小范围试发看反应，别一上来就做大而全的版本。

- 参考来源：[system-prompts-and-models-of-ai-tools](https://github.com/x1xhlol/system-prompts-and-models-of-ai-tools)
- 适合谁：有一点内容整理能力、能写中文说明的新手卖家；目标买家是在几个 AI 编程工具之间纠结、不知道从哪入手的人
- 先怎么试：先只做 3 个工具的对比（比如 Cursor vs Claude Code vs Windsurf），写成一页中文清单：各自适合谁、免费额度怎么样、新手上手难度；定价 9-19 元，先发朋友圈或社群问"有没有人需要"，有人问再正式挂
- 为什么先别冲太猛：这类信息差包保鲜期不长，工具更新快，做太细反而容易过时；先验证有没有人愿意付钱，再决定要不要做完整版
- 配图建议：截一张 GitHub 项目里工具列表的图（能看到 Cursor、Claude Code、Windsurf 这些熟悉名字），旁边配一张你整理的中文对比表格，对比感一眼就出来
