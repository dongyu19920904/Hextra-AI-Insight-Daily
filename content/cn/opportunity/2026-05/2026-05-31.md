## 今日主推
### [你的 Agent 一直在"想"，不是在"做"——帮你配好 Skill 直接用](https://x.com/dotey/status/2060538728011927954)

很多人买了 AI Agent 账号，折腾了半天，发现它每次都在重新"想"，根本不按你设定的流程走，消耗还贼大。问题不是工具不行，是 Memory 和 Skill 根本是两回事——Memory 只是背景，Skill 才是执行。这个坑，自己踩要花好几天，你帮他配好，今晚就能发单。

这两天 Skill 这个词在 AI 圈突然热起来，有人的社交卡片 Skill 直接冲到 GitHub 本周新建项目 Star 第一。热度在，但大多数人看不懂怎么用，更不知道怎么配进自己的 Agent 里。你卖的不是教程，是"配好能用的结果"。

- 参考来源：[宝玉 @dotey](https://x.com/dotey/status/2060538728011927954) / [歸藏 @op7418](https://x.com/op7418/status/2060667214077034978)
- 适合谁：已经有 Agent 工具（Kimi、ChatGPT、微信 Bot 等）但不会配 Skill、或者配了不生效的人；不想自己排错的小白
- 这钱从哪来：买家今天的痛点是"我配了但它不按流程走"——这个问题有现成答案，但他找不到、看不懂、懒得试。你帮他配好一个能跑的 Skill，他省的是几天折腾时间，付几十块很自然。今天 Skill 热度刚起来，信息差还在。
- 最简单卖法：选一个最常见场景（比如群聊总结、数据查询、社交卡片生成），配好一个能跑的 Skill 包，截图或录屏证明跑通，挂闲鱼或发朋友圈，标价 19-49 元，写清楚"配好直接用，不用自己折腾"
- 今天先做哪一步：先把宝玉那条推文里的 Skill 方案自己跑一遍，截一张"配置前 vs 配置后"的对比图，这张图就是你今天最好的成交素材
- 今天就能发的文案：「你的 Agent 一直在"想"，不是在"做"？大概率是 Memory 和 Skill 没分清。我帮你配好一个能跑的 Skill，直接交付，不用自己排错。19 元，今天能用。」
- 配图建议：用宝玉推文里的截图（配置前后对比）或歸藏那张 GitHub Star 排名截图，直接说明"这东西现在很热，但你不用自己研究"

## 本周可试
### [帮人把 Claude Code 的角色配置包跑起来，直接交付](https://github.com/garrytan/gstack)

gstack 这个项目把 Claude Code 配成了 23 个专业角色——CEO、设计师、工程经理、QA……听起来很酷，但大多数人看到英文 README 就关掉了。这个信息差现在还在，翻译成中文上手包、帮人配好跑通，是一个可以试的方向。

但今天先别重投入：Claude Code 本身门槛不低，买家需要先有账号、有环境，售后问题会比 Skill 包多。先做一个最小版本——中文说明 + 跑通截图——发出去看有没有人问，再决定要不要深做。

- 参考来源：[gstack](https://github.com/garrytan/gstack) / [橘鸦AI早报 2026-05-31](https://imjuya.github.io/juya-ai-daily/issue-107/)
- 适合谁：已经在用 Claude Code 或想试的人，但看不懂英文配置、不知道怎么把角色用起来
- 先怎么试：把 gstack 的 23 个角色整理成一份中文清单，挑 3-5 个最实用的（比如"帮你写需求文档的 PM 角色"、"帮你做代码审查的 QA 角色"），做成一页说明，先在群里或朋友圈发出去，看有没有人主动问
- 为什么先别冲太猛：Claude Code 用户基数比 Agent Skill 小，配置环境门槛高，售后问题多；现在先测反馈，有人问再做完整交付包，别一上来就做大而全的陪跑服务
- 配图建议：用 gstack GitHub 页面截图（展示 23 个角色列表），配一行中文说明"这些角色你能直接用，但要先配好"——反差感比纯文字更容易让人停下来看
