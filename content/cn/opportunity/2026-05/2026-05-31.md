## 今日主推
### [帮你把 Agent 配好，手机发消息就能查数据导文件](https://x.com/dotey/status/2060538728011927954)

有人把数据库接进了 AI Agent，结果每次查个数据就烧掉一大截费用，工作流写进 Memory 也没用，Agent 就是不按流程走。这个问题今天在中文技术圈被讨论得很热，说明已经有一批人卡在这一步了——他们有工具、有账号，就差一个"帮我配好"的人。

你能卖的不是教程，是"配完能用"这个结果。做一个最小版本：把 Skill + Script 的配置方式整理成一份中文说明，加一张跑通截图，今晚就能挂出去试。

- 参考来源：[宝玉 @dotey](https://x.com/dotey/status/2060538728011927954) / [歸藏 Skill 项目](https://x.com/op7418/status/2060667214077034978)
- 适合谁：已经在用 AI Agent 但卡在配置上的人；想让 Agent 帮自己处理日常数据查询的小白
- 这钱从哪来：他们已经在用了，就差配对——今天这个问题被公开讨论，说明需求正在集中冒出来，不是冷门
- 最简单卖法：一份"Agent Skill 配置包"，含中文说明 + 跑通截图 + 基础答疑，低价引流款先挂 9-19 元试水；有人问再出代配置服务版
- 今天先做哪一步：把宝玉那条推文里的解法整理成一页中文说明，截一张跑通图，今晚发朋友圈或群里问"有没有人卡在这里"
- 今天就能发的文案：「AI Agent 接了数据库，但每次查个东西就烧钱？工作流写进 Memory 也没用？根本原因是 Memory 不是执行指令。我整理了一份 Skill 配置方法，配完手机发消息就能按流程走，不用每次重新想。需要的扣1。」
- 配图建议：截一张 Agent 按 Skill 流程跑通的对话截图，左边是发消息，右边是直接出结果，不要截代码页面

## 本周可试
### [帮短视频剪辑师配一套"AI配音不踩坑"筛选包](https://github.com/OpenMOSS/MOSS-TTS)

MOSS-TTS 这个开源语音生成项目今天上了 GitHub 热榜，支持多说话人、长文本、实时流式输出。技术上确实不错，但对小白来说，"怎么选、哪个场景用哪个、踩过哪些坑"才是真正值钱的东西。

这单先别冲太猛，因为部署门槛还在，直接卖跑通包售后压力不小。但可以先做一个轻一点的方向：把 MOSS-TTS、现有几个中文 TTS 工具做一个"短视频配音场景对比清单"，卖的是筛选结果，不是部署服务。

- 参考来源：[MOSS-TTS GitHub](https://github.com/OpenMOSS/MOSS-TTS)
- 适合谁：做短视频、需要 AI 配音但不知道选哪个工具的人；不想自己踩坑的内容创作者
- 先怎么试：做一份"短视频配音工具对比清单"，覆盖 2-3 个中文 TTS 工具，写清楚各自适合什么场景、哪里容易出问题，先在社群里免费发一版测反馈，有人问再出付费版
- 为什么先别冲太猛：MOSS-TTS 本地部署对新手不友好，直接卖部署包售后会很重；先做筛选包、对比包，验证有人买再考虑加深
- 配图建议：用两段相同文本的不同 TTS 输出波形或音频截图做对比，直观展示音质差异，不要截 GitHub 页面
