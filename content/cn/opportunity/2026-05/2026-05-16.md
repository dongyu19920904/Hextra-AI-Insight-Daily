## 今日主推
### 你有 Claude Code 账号，但一直没真正用起来——这个包帮你配好

很多人买了 Claude Code 或 Codex 账号，打开之后不知道怎么让它"变聪明"。其实差的就是一套 Skill 配置，配上之后，翻译、写作、PPT 整理这些场景直接能用，不用自己摸索。

今天这个机会的证据很实在：PPT Skill 包在 GitHub 快破万 star，翻译 Skill 的玩法也在中文圈传开了。买家不缺账号，缺的是"配好能直接用"的那一步。你卖的不是教程，是省掉他自己折腾两小时的结果。

- **适合谁：** 已经有 Claude Code、Codex 或 Cursor 账号，但打开之后不知道怎么配 Skill、不知道从哪个场景下手的人
- **这钱从哪来：** 买家今天刷到 Skill 相关内容，心动但看不懂英文文档、不知道怎么装——你卖的是"装好能用"这个结果，不是教程本身。PPT Skill 包今天热度正高，是个好时机。
- **最简单卖法：** 整理 2-3 个场景的 Skill 配置包（翻译、PPT、写作各一套），配一页中文安装说明，打包成搭售包，定价 9-19 元引流，有人问再加答疑升档
- **今天先做哪一步：** 先把翻译场景的 Skill 配置跑通，截一张"配置前 vs 配置后"的对比图，今晚先挂一条闲鱼
- **今天就能发的文案：**
  > 买了 Claude Code / Codex 但一直没用起来？差的可能就是一套 Skill 配置。我整理了翻译、PPT、写作三个场景的配置包，中文安装说明，装完直接用。9 元，有问题可以问我。
- **配图建议：** 用 PPT Skill 的实际输出截图，左边是普通提问结果，右边是加了 Skill 之后的结果，一眼看出差距

## 本周可试
### 帮人把 Claude Code 的"记忆"配通——跨会话不失忆的代配置服务

很多人用 Claude Code 最烦的一件事：每次开新对话，它就"忘了"你上次说的。现在有工具能解决这个问题，但配置步骤对新手来说还是有点绕。

这个方向值得盯，但今天先别重投入。原因是：工具本身还比较新，买家对"跨会话记忆"这个痛点的认知还没完全打开，现在先小范围试发，看有没有人主动来问，比直接铺货更稳。

- **适合谁：** 已经在用 Claude Code 或 Codex 的人，觉得每次重新交代背景很烦、想让 AI 记住自己习惯的用户
- **先怎么试：** 先发一条朋友圈或社群消息，描述"每次开新对话都要重新介绍自己"这个场景，问有没有人有这个烦恼。有人回应再发服务说明，不要先做完整交付包
- **为什么先别冲太猛：** 工具（claude-mem 这类）还在快速迭代，配置方式可能近期有变；买家对这个痛点的感知还不够强，需要先用场景描述把需求激活，再卖服务
- **配图建议：** 截一张"新对话开头要重新介绍背景"的聊天截图，旁边对比"有记忆之后直接接着上次说"的效果，用真实对话画面说话
