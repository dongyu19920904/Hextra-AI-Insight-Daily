## 今日主推

### 验证多 Agent 桌面工具跑通包有没有人要

**cc-switch 今天刚更新，原仓库 MIT 许可、可直接复现，是当天最适合做「跑通代配置」验证的起点。** 它支持 Claude Code、OpenClaw、Grok Build 等多个 Agent 的桌面入口切换。有没有人愿意付费省去自己配的麻烦，是待验证假设。

- **证据与可信度：** 中。[cc-switch 仓库：证明项目存在、MIT 许可及多 Agent 桌面助手功能说明](https://github.com/farion1231/cc-switch)，今日 06:44 更新可核验。仍缺：本次候选输入未提供付费用户记录或实际安装反馈。
- **鱼塘与笨办法：** 待验证假设：想试 Agent 工具的小白可能在对着英文 README 逐行排错，若有人帮跑通可能愿意付小额费用——需要验证。
- **最小交付：** 「cc-switch 跑通包」：① 安装并连通至少一个 Agent；② 1-2 分钟录屏展示可用状态；③ 常见报错说明文档；④ 30 分钟基础答疑。验收：买家能打开界面切换 Agent 并调用。不含 API Key 和账号申请。
- **48小时验证：** 先在本机跑通一遍，记录实际耗时和失败点，做成录屏样品。把样品发给 3-5 个在用 Claude Code 或 OpenClaw 的人，问「你自己配过吗，如果有人帮跑通愿意付多少？」看是否有人主动问价。
- **第一单与复购：** 邀约句：「帮你在电脑上跑通 cc-switch，装好测好给你说明文档，包 30 分钟答疑。」第一单限一台设备一个系统跑通一个 Agent。复购可能偏低，更像一次性单；若用户换 Agent 或遇新报错可追加服务。
- **风险与停止：** 售后合规风险中。MIT 许可允许商业使用但需遵守条件，商标边界待核对。停止条件：无法稳定复现跑通流程，或样品发出后 48 小时内 5 位用户均无意向。
