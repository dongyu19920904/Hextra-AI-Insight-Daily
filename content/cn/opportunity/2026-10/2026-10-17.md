- **做不做：** 先做最小样品，付费意愿未验证，不跳过询价。
- **先验证：** 本地跑通一个角色并截图，找 3-5 位正在用 Claude Code 的开发者问意向。

## 今日主推

### 验证「帮独立开发者部署 Claude Code 多角色配置包」是否有人愿意付定金

**gstack 公开了 23 个角色工具的精确配置，能不能卖成「跑通服务」，今天才是真正要验证的问题。**

这套配置含 CEO、工程经理、QA、文档工程师等角色。待验证假设：独立开发者或小团队可能知道这个仓库存在，但不确定如何装进自己项目、哪个角色真正有用、出错了怎么修——如果这个猜测成立，「代跑通 + 交付可用配置」就是可收费的最小结果。

- **证据与可信度：** 中。[gstack 仓库：证明项目代码、23 工具角色配置及公开说明存在](https://github.com/garrytan/gstack)。仍缺：LICENSE 条款需自行打开仓库核查，本次候选输入未提供付费意向记录。
- **鱼塘与笨办法：** 待验证假设：若独立开发者正在手动逐条复制配置并自行踩坑调试，可能会为「省掉这段折腾」付费；需要访谈确认。
- **最小交付：** 商品名「Claude Code 多角色配置部署包」。交付内容：① 本地复现截图或短录屏；② 3-5 个角色的可用配置文件；③ 失败点记录与修复说明；④ 不含：自定义业务逻辑、长期维护、API 费用。买家可检查：在自己项目里跑通至少 1 个角色并收到可用输出。
- **48小时验证：** 第一步，今天本地跑通 QA 或文档工程师角色，记录实际耗时和失败点，制成截图样品；第二步，把样品发给 3-5 位正在使用 Claude Code 的开发者，直接问：「这套配置你折腾过吗？如果帮你配好，愿不愿意出个小定金？」观察是否有人追问价格或范围而不只是收藏。
- **第一单与复购：** 测试邀约句：「帮你把 gstack 多角色配置跑通，交付可用配置文件 + 失败点说明，固定范围，价格面议。」第一单不含定制角色、不含后续迭代。若对方有多项目需求，可沉淀为可复用的配置 + 文档包；否则更像一次性服务单。
- **风险与停止：** 售后合规风险**中**——需先确认 LICENSE 是否允许商业化交付，这是今天第一个必查项。停止条件：① 本地无法完整复现；② LICENSE 限制商业使用；③ 5 位目标用户均无付费意向；④ 买家期望超出固定范围。

## 本周小试

### 验证「AI 求职材料生成样品」对正在投简历的程序员有没有吸引力

- **证据来源：** [ai-job-search 仓库：证明项目代码及求职辅助功能说明存在](https://github.com/MadsLorentzen/ai-job-search)
- **目标鱼塘：** 待验证假设：正在投递简历的程序员或应届生，若正在反复手动改简历和求职信，可能会为「我替你跑一遍」付费。
- **最小交付：** 用该项目处理一条真实招聘信息，输出定制简历和求职信样品，买家可对比原版与输出版的实际差异。
- **48小时验证：** 先跑通一条完整流程并截图，再找 3 位正在投递的程序员展示样品，询问是否愿意为代跑服务付费并记录反应。
- **为什么只是小试：** 综合分 43 分偏低，developer-tool-setup 交付家族本周已多次出现，付费意愿完全未验证，先小范围试水。
- **停止条件：** 项目本地无法复现，或 5 位目标用户均表示会直接 fork 自用而不付钱。
