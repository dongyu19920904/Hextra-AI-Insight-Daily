## 今日主推
### [一个人顶一支团队？帮你把这套 AI 分工配置跑起来](https://github.com/garrytan/gstack)

很多人看到"CEO、设计师、工程师、QA 各干各的"会心动，但打开 GitHub 就不知道从哪下手。gstack 本质上是一份 Claude Code 的精确角色配置，23 个工具各司其职，跑起来之后真的像一支小团队在协作。

买家付钱不是为了学配置——是为了省掉那两三个小时的踩坑时间，直接拿到一个能跑的结果。你帮他把这套配置装好、截个图、录个跑通过程，这单就成立了。

- 参考来源：[gstack](https://github.com/garrytan/gstack) / [graphify](https://github.com/safishamsi/graphify)
- 适合谁：想用 Claude Code 但不会配环境的新手；做内容、做产品、做副业的独立创作者
- 这钱从哪来：看到"AI帮你扮演CEO和工程师"会心动，但自己装完跑不起来——你卖的是省下这段沮丧时间，今天刚好这个项目在圈内传开，信号还热
- 最简单卖法：发一张"跑通截图+角色分工说明"，挂 9.9 引流款，成交后交付配置说明+答疑；或者直接开代配置服务，定价 29-49，限接 5 单

- 今天就能发的文案：

> 一个人用 Claude Code 开一支团队——CEO、设计师、工程师、QA，23 个角色各干各的。
> 配置全现成，跑通之后真有点不一样。
> 自己装踩了坑没跑起来？我帮你配好，截图发你，直接用。限接 5 单，问我。

- 配图建议：用 gstack 跑通后的角色分工截图；最好带上一个角色的实际输出内容，让人看到"真的在干活"而不是只有角色名

## 本周可试
### [任何文件夹都能变成可查询的知识图谱——先做一个中文上手包](https://github.com/safishamsi/graphify)

graphify 能把代码、SQL、文档、论文、图片甚至视频全部转成一张可查询的知识图谱，支持 Cursor、Claude Code、Gemini CLI 这些已经有人在用的工具。这个方向的真实需求不小——做研究、整理资料、管项目文档都会遇到"东西散在四处找不到"的问题。

但它需要一点环境配置，中文教程几乎为零，这就是信息差。本周可以先做一个"中文上手说明+三个场景示例"的翻译包，低价发出去测反馈，不用一上来就做全套服务。

- 参考来源：[graphify](https://github.com/safishamsi/graphify)
- 适合谁：做研究、整理项目文档、管知识库的内容创作者和独行开发者
- 先怎么试：整理一份中文安装说明+三个具体使用场景（比如"把一个项目文件夹问清楚""把论文 PDF 变成可搜索图谱"），做成 PDF 或飞书文档，9.9 先挂着
- 为什么先别冲太猛：项目很新，中文用户实际跑通率还没验证，先卖信息包测反馈，有人问了再做跑通服务也不晚
- 配图建议：用 graphify 生成的知识图谱截图，最好是中文项目的那种，让人一眼看出"这跟自己的场景有关"
