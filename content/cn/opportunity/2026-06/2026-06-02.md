## 今日主推
### [今天 OpenAI 要直播，Codex 有大动作——帮你提前跑通](https://x.com/dotey/status/2061539606592360781)

今天北京时间晚上 11:30，OpenAI 官方直播预告 Codex 和平台更新。这种节点有个规律：官方一发，评论区就开始出现"我也想用，但不知道从哪开始"。你现在挂一单"帮你跑通 Codex Agent 配置"，正好接住这波问的人——不是蹭热点，是卡窗口。

买家今天的心理是：看见了，心动了，但配置文档全英文，跑起来要装环境，还不知道会不会出 bug。你卖的就是"你不用折腾，我帮你跑通，截图交付"这个结果。

- 参考来源：[宝玉推文](https://x.com/dotey/status/2061539606592360781) / [橘鸦AI早报 2026-06-01](https://imjuya.github.io/juya-ai-daily/issue-108/) / [微软 Skills 进化报道](https://www.36kr.com/p/3832748874934148)
- 适合谁：看见 Codex、OpenAI 更新就心动，但全程卡在"怎么装、怎么配"的中文新手
- 这钱从哪来：今晚 OpenAI 直播一出，搜"Codex 怎么用"的人会明显变多；他们不缺信息，缺的是一个"有人帮我搞好"的出口
- 最简单卖法：发一条轻服务说明——"帮你配好 Codex Agent 环境，跑通截图交付，出问题我来排"；定价可以先试一个低价引流款，成交后再看要不要加深服务
- 今天先做哪一步：现在就写一版服务说明，今晚直播开始前发出去；不用等直播结果，提前卡位比看完再发要有效得多
- 今天就能发的文案：

> 今晚 OpenAI 要直播，Codex 有更新 📢
> 已经有人问我"怎么用" 了
> 我先帮你跑通：配置好环境 + 跑通测试 + 截图交付
> 出问题包答疑，不用自己对着英文文档折腾
> 感兴趣的扣 1，我直接发你说明

- 配图建议：用 Codex 官方界面截图（有代码 + Agent 输出那种），右下角加一行小字"帮你配好，直接用"；画面有代码感但不要全是技术黑话

## 本周可试
### [把 Claude Code 的 23 个角色配置，打包成中文上手包](https://github.com/garrytan/gstack)

gstack 这个项目有意思的地方不是技术，是它把 Claude Code 拆成了 CEO、设计师、工程经理、QA 这些角色——这对中文新手来说，是一个"原来 AI 还能这么分工"的认知钩子。问题是，项目全英文，配置文件一堆，新手看了直接劝退。

这个方向今天不用主攻，但值得先做一版"中文场景翻译包"——把 23 个角色换成中文职场场景描述，加上每个角色适合干嘛的一句话说明，先发出去测测有没有人问。

- 参考来源：[gstack](https://github.com/garrytan/gstack) / [CodePilot 0.55.0 重构](https://m.okjike.com/originalPosts/6a1d7d251622f2d4e1fbd80f)
- 适合谁：用 Claude Code 或类似 AI 编码工具、想知道"除了写代码还能怎么用"的中文用户
- 先怎么试：把 gstack 的 23 个角色整理成一张中文对照表，加上"这个角色适合在哪个场景用"的说明，做成一个小 PDF 或截图组；先发朋友圈或社群，测有没有人主动问"在哪买"
- 为什么先别冲太猛：这个项目没有中文传播热度，买家认知还没起来；现在适合低成本试发，看反馈再决定要不要做成完整模板包或搭配 Claude Code 账号卖
- 配图建议：左边放 gstack 的英文角色列表截图，右边配一张中文版对照表（自己做一个简单的表格就够）；反差感自然出来，不需要多解释
