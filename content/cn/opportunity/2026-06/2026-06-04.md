## 今日主推
### [不用 Figma 也能出设计稿，但新手根本装不上这个工具](https://github.com/nexu-io/open-design)

很多人刷到 open-design 的演示视频，看得心动——网页、移动端、PPT、视频原型，一个工具全搞定，还免费本地跑。但点进 GitHub 一看，英文文档、依赖环境、Claude Code 接入，直接劝退。大部分人收藏完就关掉了，这个"收藏但不会用"的gap，今天就是你的生意。

你不用讲它有多厉害。你只需要发一条"我帮你装好、跑通、给你一份用法说明"，愿意付小钱省两小时折腾的人，今晚就会来私聊。

- 参考来源：[open-design](https://github.com/nexu-io/open-design) / [cc-switch 多工具切换](https://github.com/farion1231/cc-switch)
- 适合谁：想用 AI 做设计原型但没有技术背景的小白；自由职业者、短视频运营、想省 Figma 费用的人
- 这钱从哪来：买家今天看完演示就想用，但装不上，付一笔小钱让你帮他跑通，比自己搜半天文档划算；工具本身是免费的，钱花在你帮他省的时间上
- 最简单卖法：低价跑通包——你帮他装好、接好 Claude Code 或 OpenClaw、截一张跑通截图、附一份中文说明；9-29元起，验证有人买再加深服务
- 今天先做哪一步：自己先把 open-design 本地跑通，截一张实际出稿的截图，今晚发一条朋友圈或社群消息
- 今天就能发的文案：「那个可以本地跑、出网页稿/PPT/移动端原型的开源设计工具，我帮你装好配好，附中文用法说明，装失败全退。有需要私我。」
- 配图建议：用 open-design 官方仓库里的截图或演示图，选最直观那张"一键出稿"的结果图，不要截 GitHub 代码页

## 本周可试
### [一套 AI 角色配置，让 Claude Code 自动分工干活](https://github.com/garrytan/gstack)

gstack 这个项目有点反常识：它不是新模型，也不是新工具，就是一份 Claude Code 的配置文件，但配好了之后，AI 会自动扮演 CEO、设计师、工程经理、QA 几个角色，分工协作跑项目。听着像开发者玩具，但换个角度看——"帮你配一套 AI 团队，替你跑产品原型"，这个卖点对不懂代码的老板和创业小白很有吸引力。

今天先别冲太重，因为买家需要先有 Claude Code 环境，前置门槛不低。可以先做一份中文说明+配置模板包，放到社群里观察问的人多不多，再决定要不要上轻服务。

- 参考来源：[gstack](https://github.com/garrytan/gstack)
- 适合谁：已经在用 Claude Code 或者想用 AI 跑项目的人；对"AI替我管团队"这个概念感兴趣的创业者
- 先怎么试：做一份中文的 gstack 配置说明包，说清楚每个角色是干什么的、怎么改成自己的场景，定价 9-19 元试发，看有没有人主动问能不能帮他装
- 为什么先别冲太猛：买家得先有 Claude Code 能跑的环境，这个门槛在中文新手里不低；现在先测信息感兴趣的人有多少，再决定要不要上代配置服务
- 配图建议：找 gstack 仓库里的角色分工示意图，或者自己截一张"23个工具各自分工"的列表截图，配一句"AI替你管团队"的中文说明
