## 今日主推
### [谷歌放了鸽子，这份"下一步用哪个"对比包今天最好卖](https://www.36kr.com/p/3899401765422720)

昨天整个 AI 圈都在等 Gemini 3.5 Pro，200 万上下文、内测吊打 GPT，结果今天突然叫停。这批人现在处于一个很特别的状态：注意力已经被拉起来了，但没地方落。他们不是不想用，是不知道现在该用哪个。

这就是对比试错包最好卖的时机。你不是来卖单个工具的，你是来帮人省两天试错时间的。买家今天的问题很具体：Gemini 凉了先用什么？GPT 贵，Claude 限流，还有别的选吗？一份帮他们做完这个判断的小包，今天比任何时候都容易成交。

- 参考来源：[Gemini 3.5 Pro 叫停报道](https://www.36kr.com/p/3899401765422720) / [RT Gantrol 国产平替 Codex](https://x.com/dotey/status/2078154564272889992)
- 目标鱼塘：刚刚被 Gemini 消息吊起来、现在不知道用哪个的中文新手；有 ChatGPT 账号但总感觉"好像还有更好的没试过"的用户
- 适合谁：不想自己一个个去试工具、想直接看结论的人；预算不高、只想花小钱解决"用哪个"这个问题
- 这钱从哪来：Gemini 临时叫停的消息今天热度很高，有一批人正处于"准备换/准备试新工具"的窗口期，这个时候一份帮他们做完选择的对比包，门槛低、判断成本低、最容易拍
- 可交付物：3-4 个主流 AI 工具（GPT / Claude / Kimi / Gemini 现有版本）中文对比清单，附每个工具最适合的具体场景、当前实际可用状态、一句话推荐结论；PDF 或长图格式，今天就能做完
- 最简单卖法：低价资料包，9-19 元，标题走"Gemini 凉了我该用哪个"，主打省时间做判断
- 最低成本验证：今晚做一张"4 个工具对比表"截图，发朋友圈或闲鱼，看有没有人问；不用做完整包，先用截图测反馈
- 今天先做哪一步：做一张 4 栏对比表截图，每列一个工具，每行标一个场景（写作/编程/搜索/对话），填上今天实际可用状态，配"Gemini 又鸽了"做标题引流图
- 今天就能发的文案：谷歌昨天放话 48 小时上新，今天直接叫停。你攒了半天劲，现在不知道用哪个了吧——我替你比了 4 个，直接告诉你现在该选哪个，9 块钱省你两天。
- 复购/升级路径：低价包→社群答疑（每周更新工具状态）→月费小情报群→代配置服务；买家一旦信任你的判断，后续工具推荐转化率很高
- 售后边界：只交付判断清单和场景建议，不承诺账号稳定，不做代充，不保证任何工具长期不变
- 配图建议：截一张 Gemini 叫停的报道截图 + 手绘风 4 格对比表，放在一起，反差感强，比单纯工具截图更容易被转发

## 本周可试
### [代码仓库太大，AI 每次都在乱读——帮程序员把 Cursor/Claude Code 跑顺的接入包](https://github.com/tirth8205/code-review-graph)

code-review-graph 这个项目今天上了 GitHub Trending，解决的是一个程序员每天都在踩的坑：大仓库里让 AI 帮你看代码，它总是读了一堆没用的文件，上下文全浪费了。这个项目帮 AI 工具建一张持久化的"代码地图"，让它只读关键内容。

这个机会不是今天就能爆，但它是一个很稳的"小行业切片"——买家就是每天用 Cursor 或 Claude Code 写代码、苦于大项目跑不顺的程序员，痛点高频，门槛不高，值得先试挂一版。先做一个最小跑通截图，挂上去看有没有人问，不用一开始就做完整课。

- 参考来源：[code-review-graph GitHub](https://github.com/tirth8205/code-review-graph)
- 适合谁：每天用 Cursor / Claude Code 处理中大型项目、觉得 AI 读代码又慢又乱的程序员；想提效但不想自己配置 MCP 的独立开发者
- 先怎么试：把这个项目本地跑一遍，截几张"配置前 vs 配置后上下文使用量"的对比截图，做成一个轻量跑通说明，挂闲鱼或发朋友圈，标题写"让 Cursor 只读有用的代码，跑大项目快多了"
- 最低成本验证：一张跑通前后对比截图，今晚发一条朋友圈或闲鱼标题，看有没有程序员来问；有人问再做完整包
- 为什么先别冲太猛：受众是程序员，他们会先自己去 GitHub 看，成交比普通新手慢一步；而且项目今天刚上 Trending，中文资料还很少，现在做信息差翻译包比直接卖代配置更容易跑通第一单
- 配图建议：截项目 README 里的架构图或终端运行截图，配一行中文说明"这就是让 Cursor 变快的那张图"，比直接发代码更有画面感
