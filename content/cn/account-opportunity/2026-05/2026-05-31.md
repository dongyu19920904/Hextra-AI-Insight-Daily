## 今日主推

### [Claude Code 跑通包：帮你配好 23 个专业角色，直接用](https://github.com/garrytan/gstack)

gstack 这个项目今天在技术圈传开了。23 个 Claude Code Skill，分别扮演 CEO、设计师、工程经理、QA……听起来很厉害，但 99% 的人看完 README 就卡住了，不知道怎么装、怎么跑、跑完长什么样。

这个卡点就是你今天能卖的东西。不是卖账号，是卖"帮你装好、跑通、交付截图"的代配置服务。买家拿到的是一个已经能用的 Claude Code 工作流，不是一堆配置文件。

- 发生了什么：Claude Code 专业角色配置包 gstack 在 GitHub 爆热，技术门槛让普通用户望而却步
- 证据来源：[gstack - GitHub](https://github.com/garrytan/gstack)、[橘鸦AI早报 2026-05-31](https://imjuya.github.io/juya-ai-daily/issue-107/)
- 可信度：中
- 是否今天能挂闲鱼：观察
- 今天先挂什么：「Claude Code 跑通服务 / 帮你配好 23 个专业角色 Skill / 交付截图+说明」，定价低于 30 元先试水
- 今天先测什么：标题测两版——一版写"帮你装好"，一版写"Claude Code 直接用版"，看哪个问的人多
- 售后风险：中（需要买家有 Claude 账号或入口，否则要搭售账号，售后链条变长）
- 今天最小动作：先写一版代配置服务说明，明确交付内容：装好+截图+答疑一次，不包长期维护

## 平替机会

- **Claude 账号 + gstack 跑通包组合**：买家没有 Claude 入口是最大卡点。今天可以试挂"Claude 体验号 + 专业角色配置包"组合，一单解决入口和配置两个问题。售后边界要写清楚：账号体验期内有效，配置问题答疑一次。适合已经有 Claude 账号货源的卖家直接搭售。

- **社交媒体卡片 Skill 上手包**：[guizang-social-card-skill](https://m.okjike.com/originalPosts/6a1abb78c2dc8bf83f4777e7) 本周 GitHub Star 第一，说明有人在找"AI 帮我生成社交卡片"的现成方案。可以做成"账号 + 卡片 Skill 安装说明 + 示例截图"的搭售包。买家拿到的是能直接出图的工具，不是一个 GitHub 链接。售后风险中，先小范围试挂。

- **多模型对照体验包**：今天没有单一模型爆发信号，反而适合卖"Claude vs GPT 对照体验"组合包。买家花一单钱，试两个模型，自己决定留哪个。卖点是"先试后定，不踩坑"，不是死推某一个。

## 闲鱼新品

- **标题实验 A**：「不会装 Claude Code？帮你配好 23 个专业角色 直接用」——先写麻烦，再写结果，不写 gstack 这个项目名
- **标题实验 B**：「Claude 专业版配置包 / CEO+设计师+工程师角色全套 / 跑通交付」——写角色场景，让买家脑子里有画面
- **新组合试挂**：「AI 内容卡片生成入口 + 上手说明 / 发小红书/X 直接出图」——把社交卡片 Skill 的使用场景写进标题，比写工具名更容易被搜到
- **低价引流款**：9.9 元「Claude Code 入门跑通说明包」，交付一页 PDF，写清楚怎么装、怎么跑、常见报错怎么处理。用来测谁在问，再决定要不要做代配置服务

## 今天别碰

- **直接卖 gstack 配置文件**：这是开源项目，买家自己能下载，你卖文件本身没有价值。要卖的是跑通服务，不是文件。
- **Claude Code 长期稳定入口承诺**：今天没有官方稳定性信号，不要把代配置服务包装成"永久可用"或"长期维护"，售后会很重。
- **把 GitHub Star 数写进商品标题**：买家不关心 Star 数，关心的是"我能不能直接用"。Star 数写进标题是卖给技术圈的，不是卖给闲鱼买家的。
