**自己用 Codex 改代码，先看 ChatGPT 登录；要把任务接进脚本或 CI，再比较 API Key。** 两种入口都能做本地编程任务，但账单不通用。ChatGPT 会员不是 API 余额，给 API 充值也不会把你的 ChatGPT 套餐升级。

官方文档核验日期：2026-10-22。本文是文档对照指南，没有做同任务耗时或消耗实测，不承诺固定任务数。

## 按任务选入口，不按名字买服务

| 你要做什么 | 先看哪种入口 | 付费前确认什么 |
| --- | --- | --- |
| 自己在电脑上改代码、读仓库 | ChatGPT 登录 | 当前套餐是否适用、剩余用量是否够 |
| 已有 ChatGPT 订阅，第一次试 Codex | 先检查现有账号 | 不用一开始就另买 API 服务 |
| 用脚本或 CI 批量跑任务 | 比较 API Key | API 组织、模型权限、计费和预算 |
| 用 Codex 云端功能 | ChatGPT 登录 | 对应功能的套餐和工作区权限 |
| 使用第三方中转或镜像 | 单独核对交付 | 端点、支持的客户端、计费与数据边界 |

[OpenAI 官方认证说明](https://learn.chatgpt.com/docs/auth)区分订阅登录与按量 API 登录；本地客户端支持两者，Codex 云端需要 ChatGPT 登录。脚本任务也要结合工作区要求选择入口，不能只看商品名里有没有“Codex”。

## 先确认你现在从哪扇门进去

在 Codex 客户端的个人菜单查看当前账号或 API Key 状态。CLI 可运行只读命令：

```sh
codex login status
```

如果工具里还有自定义服务商配置，核对它指向官方 API 还是第三方端点。**不要为排查问题公开密钥、登录文件或完整环境变量。**

账单也分开看：[ChatGPT 和 API 的官方计费说明](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform)给出了各自的账单入口。ChatGPT 订阅在 ChatGPT 设置中管理；API 消耗到对应 API 组织查询。第三方服务的账单则向该服务商核对。

## 提示额度不足，先查这三件事

1. **哪一项用完？** 是订阅用量、API 预算，还是第三方服务额度？先把提示读完整。
2. **什么时候恢复？** 按当前界面的重置提示或计费状态判断，不拿别人的截图当自己的额度表。
3. **只是今天忙，还是天天不够？** 偶发长任务先缩小范围；持续需求再比较适用方案。不要一看到“限额”就给另一套账单充值。

[官方 Codex 定价与用量页](https://learn.chatgpt.com/docs/pricing)提供当前方案和用量查看方法，CLI 会话可用 `/status` 查看剩余限制。本文不推荐额外额度包，也不把“每天能做多少任务”写成保证。

## 两个常见误会

**买 ChatGPT Plus，会给 API 账户充钱吗？** 不会。两边分开计费，API Key 不是会员兑换码。

**API Key 能代替所有 ChatGPT 登录功能吗？** 不能。本地编程入口与云端功能不能混为一谈，按官方认证和功能说明确认。
