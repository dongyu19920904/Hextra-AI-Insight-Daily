## **🔥 重磅 TOP 10**

### 1. [Midjourney V8 正式发布](https://x.com/op7418/status/2034069787719176219)
以前跑一张图要等半天，现在 V8 直接快了 5 倍，还能直出 2K 高清图。复杂提示词理解更强，文字渲染终于不再是灾难现场，个性化风格参考也大幅增强。最关键的是，它能更懂你的审美偏好——以前你得反复调参数才能出满意的图，现在它自己就能猜到你想要什么感觉。目前在 Midjourney alpha 网站上测试，兼容 V7 的所有设置。AI 绘画的军备竞赛又升级了。

![image](https://pbs.twimg.com/media/HDp3caGbEAEIfK5?format=jpg&name=orig)

### 2. [OpenAI Codex 支持 Subagents](https://x.com/dotey/status/2033646439838912682)
写代码时最烦的就是主窗口被各种任务塞满，现在 Codex 终于支持创建子代理了。你可以把不同任务分给不同的 Subagent 并行处理，主窗口保持干净，还能随时切换窗口跟踪每个子任务的进度。就像给你的 AI 助手配了一个团队，前端、后端、测试各干各的活，效率直接起飞。开发者狂喜。

<video controls preload="metadata" playsinline style="max-width:100%; height:auto;" src="https://video.twimg.com/amplify_video/2033636632155533312/vid/avc1/1280x720/YS-bINcJSIt1Pq1Z.mp4?tag=14"></video>

### 3. [阿里开源 OpenSandbox](https://x.com/Gorden_Sun/status/2033941005368774953)
Agent 乱跑代码把系统搞崩？阿里开源了 OpenSandbox，专门给 AI Agent 提供沙箱环境。多语言 SDK、统一 API、Docker/Kubernetes 运行，还集成了 Chrome 无头浏览器和 Playwright 自动化。支持运行 Claude Code、Gemini CLI、Codex CLI 等主流 Agent，基本开箱即用。以前担心 Agent 把生产环境搞炸，现在可以放心让它折腾了。

![image](https://pbs.twimg.com/media/HDoCjpZaoAAPt7-?format=jpg&name=orig)

### 4. [Mistral 开源 Small 4 模型](https://x.com/Gorden_Sun/status/2033729603416756708)
Mistral 推出 Small 4，119B 总参数但只激活 6.5B，支持 256K 上下文和多模态输入。评分略低于 Qwen3-Next-80B，明显低于 Qwen3.5 122B。虽然不是最强，但胜在开源，对于需要本地部署的团队来说是个不错的选择。开源社区又多了一个可以玩的大模型。

![image](https://pbs.twimg.com/media/HDlCSUbaUAAMA7G?format=jpg&name=orig)

### 5. [Foundation-1 开源 AI 音乐生成](https://x.com/Gorden_Sun/status/2033943515080864234)
基于 Stable Audio 微调，专门生成无人声的背景音乐，效果非常好。能生成可循环的片段音乐，只需要 7G 显存就能本地运行。以前做视频配乐要么花钱买版权，要么用免费的烂大街素材，现在可以自己生成独一无二的配乐了。游戏开发者、视频创作者的福音。

<video controls preload="metadata" playsinline style="max-width:100%; height:auto;" src="https://video.twimg.com/amplify_video/2033943132870733824/vid/avc1/1920x1080/hl_FBQwwwHai2vMZ.mp4?tag=21"></video>

### 6. [MiroThinker-1.7 开源深度研究 Agent](https://x.com/Gorden_Sun/status/2033739806208102813)
MiroMind 发布 MiroThinker-1.7，专门强化长链条 Agent 任务和工具调用能力。支持 256K 上下文，单任务最多 300 次工具调用，还推出了长链条可验证推理机制——推理过程既可逐步验证也可全局验证。以前 Agent 做复杂任务容易跑偏，现在有了验证机制，准确性大幅提升。适合需要深度研究和复杂任务处理的场景。

![image](https://pbs.twimg.com/media/HDH31AWbcAAJ99w?format=jpg&name=orig)

### 7. [Kimi 发布 Attention Residuals 论文](https://x.com/op7418/status/2033708252681392213)
Kimi 团队发布新论文，重新思考深度聚合方式。传统残差连接是固定的、均匀的累加，Kimi 提出了 Attention Residuals——用注意力机制动态调整不同层的贡献权重。就像把 ResNet 旋转 90 度变成 LSTM，现在又把 Attention 旋转 90 度。这个思路很猛，可能会影响未来模型架构设计。用 K2.5 对论文进行可视化解释后，更容易理解了。

![image](https://pbs.twimg.com/media/HDkuy72bEAAqxMh?format=jpg&name=orig)

### 8. [迪士尼雪宝机器人](https://x.com/dotey/status/2033942205694353638)
迪士尼做了个雪宝 Olaf 机器人，技术栈很硬核：肚子里装了 NVIDIA Jetson 芯片，在 Omniverse 虚拟平台训练走路，用 Newton 物理引擎适应真实世界，语言大脑是 DeepMind 的 Gemini。整条链路：虚拟训练 → 物理仿真 → Sim-to-Real 迁移 → 边缘推理 → 真实机器人行走。以前机器人要在真实世界反复摔才能学会走路，现在先在虚拟世界练好再迁移，效率高多了。

### 9. [WebAssembly 解释器嵌入 Transformer](https://x.com/dotey/status/2033646220061618453)
有人把 WebAssembly 解释器无损地 hard-coded 到 Transformer 模型权重里，相当于在 LLM 内部运行着一台真正的计算机。这台计算机可以实际执行计算，而不是像现在大多数模型那样只能推理。思路类似 TI 的 DSP 芯片：ARM 负责逻辑思维，DSP 专门负责高速数据计算。这样 LLM 就能同时兼顾智能推理能力和确定性计算精度，终于不用再算错 3.11 和 3.8 哪个大了。

![image](https://pbs.twimg.com/media/HDjxtTlbEAAoFOB?format=jpg&name=orig)

### 10. [Lenny 开放全部 Newsletter 数据](https://x.com/dotey/status/2034055226559180835)
Newsletter 大神 Lenny Rachitsky 把全部家底开放了：350+ 篇文章 + 300+ 期播客转录，全部整理成 AI 友好的 Markdown 文件，还附赠 MCP server 和 GitHub 仓库。几个月前他只放了播客转录，就有人做出了 RPG 游戏、育儿网站、Twitter bot 等 50+ 个项目。现在数据量更大，免费用户拿子集，付费用户拿全量。他发起挑战：用这些数据做点东西，最喜欢的项目送一年免费订阅，截止 4 月 15 日。
