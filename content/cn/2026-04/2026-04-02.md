这个数字不是估值，是融资额。Sam Altman 这次直接把投资人的钱包掏空了，1250 亿美元的融资规模已经超过了很多国家的 GDP。虽然消息还没官宣，但如果属实，这将是 AI 行业史上最大规模的单轮融资。钱这么多，要么是在憋大招，要么是真的烧钱烧到停不下来。等等党可以继续观望，但这个体量的资金流入，意味着 OpenAI 接下来的动作会更激进。

### 2. [Google 发布 Veo 3.1 Lite 模型，价格降低 8 倍](https://x.com/op7418/status/2039167939635708176)

Google 这次直接把视频生成的价格打下来了。Veo 3.1 Lite 相比标准版便宜 8 倍，Veo 3.1 Fast 也跟着降价。这个节奏很明显，Google 在用价格优势抢市场份额。对开发者来说是好事，视频生成的成本门槛又降了一截。不过便宜归便宜，效果能不能打还得实测，毕竟 Lite 版本通常意味着某些能力被阉割了。

### 3. [前 OpenAI 员工加入 DeepSeek](https://x.com/Gorden_Sun/status/2039242198336901211)

这位小哥曾参与 Sora 1 和 2 的训练，以及 o3 和 o4 的后训练，现在直接搬到杭州加入 DeepSeek。人才流动本身不稀奇，但从 OpenAI 跳到中国 AI 公司，这个信号值得关注。DeepSeek 最近动作频繁，挖到这种核心技术人员，说明他们在视频生成和推理模型上有大计划。

### 4. [Claude Code 愚人节彩蛋：/buddy 抽宠物](https://x.com/Gorden_Sun/status/2039271518535131193)

Claude Code 更新后输入 /buddy 可以抽取你的专属宠物，有人抽到蜗牛，有人抽到其他奇怪生物。这个功能看起来像愚人节玩笑，但实际上是个可玩的小彩蛋。如果你用 API 登录，还能通过修改配置文件重新抽取属性值。虽然没啥实用价值，但开发者玩得挺开心，至少证明 Anthropic 的团队还挺有趣。
