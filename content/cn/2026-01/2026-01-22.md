### [向阳乔木的 Claude Skills 工作流分享：把日常琐事全扔给 AI](https://x.com/dotey/status/2014020135913177508)

以前写篇文章，光是找配图、整理素材就得折腾半天。现在呢？向阳乔木在直播里展示了他的 Claude Skills 玩法——写作、配图、素材整理，全部自动化。最绝的是配图那块，用Playwright MCP 让 AI 自己去浏览器里扒素材，然后生成对应的 Skill。宝玉也补了一刀：写作风格这东西每个人不一样，得自己调，但思路是相通的。想告别"素材整理到凌晨三点"的朋友，这套流程值得抄作业。

### [票据风格提示词终于来了！还能批量生成小红书配图](https://x.com/op7418/status/2013921013927420186)

你们催了多久的票据风格提示词，歸藏终于放出来了。不止是个提示词，他还做了个Skills——扔一份文档进去，能自动批量生成同一风格的小红书配图。以前做十张图得改十次提示词，现在一键出图，风格还能保持统一。做自媒体的、写公众号的，这个直接能省下配图的命。

### [Claude Code 多窗口并行：现在这才叫真正的多任务](https://x.com/op7418/status/2013896350648410441)

一个人干活顶三个人？开多个 Claude Code 窗口同时跑，这已经是歸藏的日常操作了。左边窗口写代码，右边窗口调试，中间还能让 AI 帮忙写文档。以前切来切去眼睛都花了，现在并行处理，效率直接起飞。这种工作流对付多个并发任务太香了，就是电脑性能得跟得上。

### [Tambo: React 生成式 UI 的瑞士军刀](https://github.com/tambo-ai/tambo)

前端开发者的新玩具来了。Tambo 是个 React 生成式 UI SDK，3200+ star不是白拿的。简单说就是让你的 React 应用能动态生成界面组件，不用写死每个 UI 元素。做AI 产品的团队应该重点关注——用户输入什么，界面就能生成什么，这才是 AI-native 产品该有的样子。

### [Claude Code 官方复合工程插件：Anthropic 亲儿子来了](https://github.com/EveryInc/compound-engineering-plugin)

Anthropic 官方出的 Claude Code 复合工程插件，5600+ star。这插件能让你把多个工程任务串起来执行，不用一个个手动触发。比如"先跑测试、再格式化代码、最后提交"，一条指令搞定。对于工程规范严格的团队，这东西能减少大量重复操作。Python 写的，想魔改也方便。
