## **🔥 重磅 TOP 10**

### 1. [ruflo：Claude 智能体编排平台，今日狂揽 2594 星](https://github.com/ruvnet/ruflo)

你有没有想过，把一堆 AI 智能体像乐高一样拼起来，让它们自己分工、自己协作、自己学习？ruflo 就是干这个的。它基于 Claude 构建，支持多智能体集群部署、自主工作流协调，还内置了 RAG 和原生 Claude Code 集成——换句话说，你不用再手动把每个 AI 工具串起来，ruflo 帮你搭好了整个"指挥中枢"。今天单日 2594 颗星，说明开发者早就在等这种东西了。企业级架构加上自学习集群，这不是玩具，是认真在做生产级 Agent 平台。

### 2. [TradingAgents：多智能体 LLM 金融交易框架，总星数破 6.6 万](https://github.com/TauricResearch/TradingAgents)

想象一下，一个 AI 团队里有人负责看盘、有人负责分析基本面、有人负责风控——TradingAgents 就是把这套分工搬进了代码里。多个 LLM 智能体各司其职，协同完成金融交易决策，今日新增 2181 星，总星数已经冲到 66359。金融 AI 一直是高门槛赛道，这个框架把复杂的多智能体协作做成了开箱即用的 Python 库。量化交易的朋友可以认真看一眼，这条路子正在被越来越多人踩出来。

### 3. [agency-agents：完整 AI 代理团队，总星数 9.2 万](https://github.com/msitarzewski/agency-agents)

以前组建一个创意团队，你得招前端、招文案、招社区运营。现在？这个项目直接给你一整支 AI 代理团队，从前端开发专家到 Reddit 社区运营达人，每个智能体都有自己的个性、工作流程和可交付成果。今日新增 828 星，总星数已经逼近 10 万。最有意思的地方不是"它能做什么"，而是"它把 AI 角色化"这个思路——每个 Agent 不再是一个通用工具，而是一个有专业背景的"虚拟员工"。

### 4. [DeepSeek-TUI：在终端里跑 DeepSeek 的编程智能体](https://github.com/Hmbown/DeepSeek-TUI)

不开浏览器，不开 IDE，直接在终端窗口里和 DeepSeek 对话写代码——这就是 DeepSeek-TUI 的核心卖点。用 Rust 写的，性能不用担心，今日新增 1277 星。对于那些整天泡在命令行里的开发者来说，这种"不离开终端"的体验有种说不出的顺滑感。更重要的是，它把 DeepSeek 的能力直接嵌进了开发者最熟悉的工作环境，少了一层切换，多了一份专注。

### 5. [Pixelle-Video：AI 全自动短视频引擎](https://github.com/AIDC-AI/Pixelle-Video)

给它一个主题，它自己写脚本、自己配素材、自己剪辑、自己输出——Pixelle-Video 把短视频生产流水线全部 AI 化了。今日新增 497 星，总星数已过万。短视频赛道一直是内容创作者的重体力活，这个项目的出现意味着"一个人运营十个账号"正在从段子变成现实。对于自媒体从业者来说，这不是锦上添花，是降维打击级别的效率工具。

### 6. [n8n-mcp：给 Claude Desktop / Cursor 用的 n8n 工作流 MCP](https://github.com/czlonkowski/n8n-mcp)

n8n 本来就是自动化工作流神器，现在有人把它和 MCP 打通了，让 Claude Desktop、Claude Code、Windsurf、Cursor 都能直接调用 n8n 工作流。今日新增 497 星，总星数近 2 万。这意味着什么？你在 Cursor 里写代码的时候，可以直接让 AI 触发一个 n8n 自动化流程——发邮件、更新数据库、推送通知，一气呵成。AI 编辑器和自动化平台的边界正在消失。

### 7. [jcode：编程智能体测试框架](https://github.com/1jehuang/jcode)

Agent 越来越多，但怎么测试一个编程智能体到底靠不靠谱？jcode 专门解决这个问题。用 Rust 构建，今日新增 545 星。随着 AI 编程工具爆炸式增长，"如何评估 Agent 质量"正在成为一个严肃的工程问题。这个框架的出现时机很准——当大家都在卷 Agent 功能的时候，有人开始认真做 Agent 的质量保障，这个方向值得盯紧。

### 8. [dexter：用于深度金融研究的自主智能体](https://github.com/virattt/dexter)

和 TradingAgents 侧重交易执行不同，dexter 更专注于"研究"这个环节——自主收集信息、分析财报、生成研究报告。TypeScript 写的，今日新增 418 星，总星数 2.2 万。金融研究员每天要读几十份报告，dexter 的目标是把这个过程自动化。两个金融 AI 项目同天上榜，说明这个赛道的开发者社区正在快速聚集。

### 9. [skills：集成网页浏览工具的 Claude Agent SDK](https://github.com/browserbase/skills)

browserbase 出品，把网页浏览能力直接打包进 Claude Agent SDK。今日新增 320 星。以前让 AI 浏览网页需要自己搭一堆基础设施，skills 把这层封装好了——Claude 可以直接"看网页"、"点按钮"、"填表单"，像一个真正在操作浏览器的用户。对于需要 AI 做网页自动化的开发者来说，这个 SDK 能省掉大量重复造轮子的时间。

### 10. [maigret：通过用户名从 3000+ 网站收集档案信息](https://github.com/soxoj/maigret)

输入一个用户名，它帮你在 3000 多个网站上搜这个人的公开信息，自动整理成档案。今日新增 1116 星，总星数 2.4 万。OSINT（开源情报）工具一直是安全研究和背景调查领域的刚需，maigret 把这个过程自动化到了极致。对于安全研究员、记者、HR 来说，这是一把效率利器——当然，用在正当用途上。
