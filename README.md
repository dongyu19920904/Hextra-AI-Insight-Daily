### 🚀 快速开始与部署

5. Fork 项目后，在仓库 `Settings → Pages` 把部署源改为 GitHub Actions，再手动触发 `pages.yaml`。

#### 部署到 Netlify

6. 点按钮一键部署，示例站：`news.aivora.cn`。
