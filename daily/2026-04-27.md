### 4. [Claude Opus 4.7 的视觉能力被严重低估了](https://x.com/Gorden_Sun/status/2048385307960361052)

以前做 PPT，要么自己排版，要么给模型一个现成模板让它填内容。Opus 4.7 直接跳过了这一步：你只需要给它一张参考图，它能自己还原排版风格，还能基于这个风格创作出全新的版式——生成完还会自动截图做还原度分析，多轮修复。这不是"AI 辅助做 PPT"，这是"AI 自己在做 PPT，你只负责提需求"。目前 AI 生成 PPT 有三条路线：图片生成、HTML 生成、直接生成 PPT 文件，Opus 4.7 在第三条路上已经跑得相当稳了。

### 5. [Cursor Agent 三轮对话烧掉 4000 万 token，但任务一次完成](https://x.com/Gorden_Sun/status/2048431253066743962)

改一个 4 万 token 的 HTML 文件，对话 3 轮，Cursor Agent 直接消耗了 4000 万 token——相当于 Claude Pro 订阅 5 个小时的用量。听起来很离谱，但结果是：任务一次性完成，测试流程也覆盖了。这就是 Agent 模式的本质矛盾：它确实更强，但烧钱的速度也是真实的。对于有额度的用户来说这是神器，对于自费用户来说，每次跑 Agent 都得掂量一下钱包。效果和成本，目前还没法两全。

### 6. [GPT Image 2 能在原图上"看云识物"并涂鸦](https://x.com/Gorden_Sun/status/2048080137149899133)

给 GPT Image 2 一张天空照片，让它识别云朵像什么，然后在原图上用涂鸦的方式把那个东西画出来——它做到了，而且做得相当自然。同样的任务，Banana Pro 完成不了。这个能力的核心不是"画图"，而是"理解图像内容 + 在原图上精准叠加"，这对图像编辑类应用来说是个很实用的突破口。提示词也不复杂，感兴趣的可以直接拿去试。

### 7. [GPT Image 2 序列帧测试翻车：模糊得像回到 SD 1.0](https://x.com/Gorden_Sun/status/2048062424537084187)
