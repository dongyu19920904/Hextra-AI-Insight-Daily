## **🔥 重磅 TOP 10**

### 1. [Sam Altman：是时候重新设计操作系统和互联网了](https://x.com/sama/status/2048428561481265539)

以前操作系统是给人设计的，鼠标、窗口、点击——一切都假设屏幕前坐着一个人类。但现在 Agent 也在用电脑，而且越来越多。Altman 发了条推，说现在是认真重新思考操作系统和用户界面设计的好时机，还提到互联网应该有一套"人和 Agent 都能平等使用"的协议。这不是随口一说——背后是 OpenAI 正在大力推进 Agent 产品线的现实。操作系统和网络协议如果不跟上，Agent 就永远是在给人类设计的世界里"将就着用"。这个信号值得盯紧，下一个十年的基础设施之争，可能从这里开始。

### 2. [GPT-5.5 in Codex 好到让人睡不着觉——Altman 转发的那条推](https://x.com/sama/status/2048426122854228141)

有人说"AGI 之后没人工作、经济崩溃"，另一个人说"我要改成多相睡眠，因为 GPT-5.5 in Codex 太好用了，睡那么久太浪费"。Altman 把这两条并排转发，没加评论——但意思已经很清楚：他觉得第二种反应才是真实的。微软研究员 Sebastien Bubeck 也在同一串对话里说，现在大概能把以前两周的工作压缩到一天完成。这不是夸张，是正在发生的生产力变化。如果你还没感受到这个加速，可能只是还没找到对的工具。

### 3. [Claude Opus 4.7 视觉能力被严重低估：看图就能还原 PPT 排版](https://x.com/Gorden_Sun/status/2048385307960361052)

给 Claude Opus 4.6 一个 PPT 模板，它能改内容但排版基本不动；给 Opus 4.7 一张参考图片，它能直接在 PPT 里还原出那个排版风格，甚至能基于参考图创作出风格相近的全新排版——而且每轮生成后还会自动截图做还原度分析、多轮修复。这个能力的跨度不是小步迭代，是质变。目前 AI 生成 PPT 有三条路：图片生图、HTML 前端、直接生成 PPT 文件，第三条路目前只有 Claude Opus 4.6/4.7 能几乎完美驾驭。做汇报材料的朋友，这条值得认真试一试。

![image](https://pbs.twimg.com/media/HG1S2Q3bIAI6Be-?format=jpg&name=orig)

### 4. [GPT Image 2 神操作：让它打包 PSD，直接拿到 4K 分层文件](https://x.com/dotey/status/2048571005921010029)

甲方要 4K 图、要 PSD 分层——这两个需求以前是 AI 出图的死穴。有人试着直接在 GPT 里要求生成 PSD 分层压缩包，结果它真的给了，而且里面的图片是 4K 尺寸。这个方法绕过了 GPT 图片默认输出分辨率的限制，相当于找到了一个隐藏出口。不保证每次都稳定，但作为应急方案，比手动放大靠谱多了。设计师和做汇报材料的人，这个技巧可以存一下。

![image](https://pbs.twimg.com/media/HG1BaalasAAzmr6?format=jpg&name=orig)

### 5. [GPT Image 2 × 立体浮雕风：《Relief City Atlas》城市叙事海报](https://x.com/dotey/status/2048508189600104459)

哈尔滨冬、上海秋、广州夏、北京春——每座城市锁定一个季节，用立体浮雕加微缩模型风格生成城市叙事海报。画面从右下角一个小小旅人出发，一条线串联整座城的古今与四季。这组作品的价值不只是"好看"，而是展示了 GPT Image 2 在风格一致性和叙事构图上的控制力已经到了可以做系列作品的程度。提示词在原帖评论区，想复刻的可以直接去取。

![image](https://pbs.twimg.com/media/HG0ClnMbsAE9HbW?format=jpg&name=orig)

### 6. [Cursor Agent 三轮对话烧掉 4000 万 token——但任务一次性完成了](https://x.com/Gorden_Sun/status/2048431253066743962)

改一个 4 万 token 的 HTML 文件，对话 3 轮，Cursor Agent 消耗了 4000 多万 token——相当于 Claude Pro 订阅 5 小时的用量。听起来很离谱，但结果是：任务一次性完成，测试流程也覆盖了。这暴露了 Cursor Agent 的真实成本结构：它在后台做了大量你看不见的上下文扩展和验证工作。对于有 $10,000 额度的用户来说无所谓，但对于自费用 API 的开发者，这个消耗速度需要认真算一下账再决定要不要开 Agent 模式。

![image](https://pbs.twimg.com/media/HG18dQoaYAAKntZ?format=jpg&name=orig)

### 7. [GPT Image 2 精致刺绣风插画：蚕丝白底色的复刻难题](https://x.com/dotey/status/2048529821706195442)

一组立体刺绣风插画，蚕丝白加奶白底色，小鸟停在花枝上，丝线质感细腻到让人想摸屏幕。有意思的是，有人反映复刻了很久，就是做不出原图那种"蚕丝白+奶白"的微妙质感——这说明 GPT Image 2 对颜色描述的敏感度极高，同样的提示词，措辞稍有不同，出来的结果可能差很远。提示词工程在图像生成这件事上，依然是门手艺，不是玄学。

![image](https://pbs.twimg.com/media/HG3W9gzakAAVZbc?format=jpg&name=orig)

### 8. [GPT Image 2 看云识物：在原图上用涂鸦画出云朵像什么](https://x.com/Gorden_Sun/status/2048080137149899133)

提示词是：识别云朵形状最像什么，不改原图，用涂鸦形式在原图上额外画出来。Banana Pro 做不到，GPT Image 2 做到了——它真的在原图上叠加了涂鸦，而且保留了原始照片。这个能力的核心是"图像理解 + 精准局部编辑"同时在线，缺一不可。以前这种需求要 Photoshop 加手绘，现在一句话搞定。创意工作者可以想想这个能力还能用在哪。

![image](https://pbs.twimg.com/media/HGw9fcfbcAAXVVG?format=jpg&name=orig)

### 9. [GPT Image 2 序列帧实验：透明背景稳了，但 4×4 拼图糊了](https://x.com/Gorden_Sun/status/2048062424537084187)

GPT Image 2 能稳定生成透明背景图片，有人想顺势在一张图里生成 4×4 序列帧来做小动画——结果图片模糊得像回到了 Stable Diffusion 1.0 时代。透明背景这个能力是真的好用，但序列帧这条路目前走不通。这个实验的价值在于帮大家省了时间：别在这个方向上浪费精力，等模型迭代再说。

![image](https://pbs.twimg.com/media/HGwt3OrbQAA20jv?format=jpg&name=orig)

### 10. [AI 时代的超级个体，大部分在前 AI 时代就已经是了](https://m.okjike.com/originalPosts/69ec9ea6657481ea4e89ddf3)

这句话扎心就扎心在够真。AI 工具确实在放大个人能力，但放大的前提是你本来就有东西可以被放大。那些用 AI 用得飞起的人，往往在没有 AI 的时候就已经是高效、自驱、有判断力的人。AI 是乘数，不是加法。如果基数是零，乘再大也是零。这不是泼冷水，而是一个更诚实的起点：与其焦虑"AI 会不会取代我"，不如先问"我有没有值得被放大的东西"。
