### 3. [腾讯开源 TencentDB Agent Memory：长程 Agent 的记忆终于不再是一锅乱炖](https://m.okjike.com/originalPosts/6a057fd17f82528246e6ead5)

用过长任务 Agent 的人都懂那种崩溃感：跑着跑着，上下文窗口塞满了工具调用日志、报错信息、文件 diff，模型表面上还在工作，实际上已经在信息泥潭里打转。腾讯这次开源的 TencentDB Agent Memory，核心设计是**符号化短期记忆 + 分层式长期记忆**：厚重的工具日志卸载到外部文件，中间层保留步骤摘要，最顶层只给 Agent 留一张轻量级 Mermaid 任务图。Agent 平时只看结构图，需要细节时再按 node_id 精准取用。这个思路比"把历史对话丢进向量库靠相似度召回"要扎实得多，值得做 Agent 开发的人认真读一读。

### 8. [上下文 vs 上下文窗口：一个厨房比喻说清楚了](https://x.com/dotey/status/2054774181808488756)
