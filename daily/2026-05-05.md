## **🔥 重磅 TOP 10**

### 1. [ruflo：Claude 智能体编排平台，今日狂揽 2594 星](https://github.com/ruvnet/ruflo)

你有没有想过，让一群 AI 互相协作、自动分工、自我学习，最后把活儿干完——你只需要喝杯咖啡？ruflo 就是干这个的。它是一个专门为 Claude 打造的多智能体编排平台，支持部署自主工作流集群，内置 RAG 集成和原生 Claude Code 支持，企业级架构开箱即用。今天单日新增 2594 星，总星数已破 4 万，说明这不是小圈子在自嗨。如果你正在搭 AI 工作流，这个项目值得认真看一眼——它解决的不是"AI 能不能用"，而是"怎么让一堆 AI 协同干大事"。

### 2. [TradingAgents：多智能体 LLM 金融交易框架，总星数破 6.6 万](https://github.com/TauricResearch/TradingAgents)

量化交易员花几个月调的策略，AI 可能几分钟就跑完了——这不是科幻，这是 TradingAgents 正在做的事。这个 Python 框架把多个 LLM 智能体组成"交易团队"，分别负责分析、决策、风控，协同完成金融交易任务。今日新增 2181 星，总星数已达 66359，是今天素材里体量最大的开源项目。对量化从业者来说，这是一个可以直接拿来实验的框架；对普通人来说，它揭示了一个趋势：AI Agent 正在认真盯着你的钱包。

### 3. [agency-agents：完整 AI 代理团队，总星数超 9.2 万](https://github.com/msitarzewski/agency-agents)

想象一下，你一个人开公司，但有前端工程师、社区运营、创意总监、事实核查员随时待命——而且他们都是 AI。agency-agents 就是这样一个"AI 员工团队"项目，每个智能体都有明确的个性、工作流程和可交付成果，今日新增 828 星，总星数已超 9.2 万。它的核心价值不是"又一个 AI 工具"，而是把 Agent 的分工协作做成了可复用的模板。独立开发者和小团队可以直接拿来用，省掉从零搭建的时间。

### 4. [DeepSeek-TUI：在终端里跑 DeepSeek，Rust 写的，今日 1277 星](https://github.com/Hmbown/DeepSeek-TUI)

不想开浏览器，不想装 GUI，就想在终端里直接跟 AI 聊——DeepSeek-TUI 就是为这种人准备的。用 Rust 写成，轻量、快速，把 DeepSeek 模型变成一个终端里的编程智能体。今日新增 1277 星，说明这个需求比想象中更普遍。对开发者来说，这种"终端原生"的 AI 工具有一种天然的吸引力：不打断工作流，随手就能调用。Rust 的性能加持也让它在资源占用上比同类工具更克制。

### 5. [maigret：用用户名从 3000+ 网站收集档案，今日 1116 星](https://github.com/soxoj/maigret)

只需要一个用户名，就能在 3000 多个网站上追踪一个人的数字足迹——这个工具叫 maigret，今日新增 1116 星，总星数已达 24391。它的用途是 OSINT（开源情报收集），安全研究、渗透测试、背景调查都能用到。值得注意的是，这类工具的走红本身就是一个信号：在 AI 时代，个人数字身份的暴露面比大多数人意识到的要大得多。如果你在意自己的网络隐私，这个工具反过来也能帮你摸清自己的"数字暴露程度"。

### 6. [jcode：编程智能体测试框架，今日 545 星](https://github.com/1jehuang/jcode)

写 AI 编程智能体容易，但怎么测它到底好不好用？这正是大多数开发者头疼的地方。jcode 是一个专门用来测试编程智能体的框架，用 Rust 写成，今日新增 545 星。它填补的是 Agent 开发链路里一个长期被忽视的环节——评估与验证。随着 Claude Code、Cursor 这类工具越来越普及，"怎么衡量 AI 写的代码到底靠不靠谱"会变成一个越来越重要的问题，jcode 的出现正好踩在这个节点上。

### 7. [n8n-mcp：让 Claude 直接帮你搭 n8n 工作流](https://github.com/czlonkowski/n8n-mcp)

以前搭 n8n 自动化工作流，得自己拖拽节点、查文档、调参数，费时费力。现在有了这个 MCP，Claude Desktop、Claude Code、Cursor、Windsurf 都能直接理解你的需求，帮你生成 n8n 工作流。今日新增 497 星，总星数近 2 万。它的价值在于打通了"AI 对话"和"自动化执行"之间的最后一公里——你说需求，AI 帮你把流程搭好，不用再当"工作流翻译官"。

### 8. [Pixelle-Video：AI 全自动短视频引擎，今日 497 星](https://github.com/AIDC-AI/Pixelle-Video)

从脚本到成片，全程 AI 自动完成——Pixelle-Video 做的就是这件事。这个开源项目定位是"AI 全自动短视频引擎"，今日新增 497 星，总星数已超 1 万。对内容创作者来说，它意味着批量生产短视频的门槛正在被进一步压低；对行业来说，它是又一个信号：视频生成正在从"生成单帧"走向"生成完整叙事流程"。Python 实现，可以本地部署，感兴趣的可以直接拉下来跑。

### 9. [skills：集成网页浏览的 Claude Agent SDK](https://github.com/browserbase/skills)

Claude 会写代码，但如果它还能自己上网查资料、填表单、操作浏览器呢？browserbase 的 skills 项目就是把网页浏览能力直接集成进 Claude Agent SDK，让智能体具备真实的"上网"能力。今日新增 320 星，JavaScript 实现，接入成本低。这类"给 AI 装上手脚"的工具正在快速增多，它们共同指向同一个方向：Agent 不再只是聊天机器人，而是能真正在数字世界里行动的自主体。

### 10. [dexter：用于深度金融研究的自主智能体](https://github.com/virattt/dexter)

金融分析师每天要读几十份报告、对比数据、写摘要——dexter 想把这些全部自动化。这是一个专注于深度金融研究的自主智能体，TypeScript 实现，今日新增 418 星，总星数近 2.3 万。和 TradingAgents 不同，dexter 更侧重"研究"而非"交易执行"，定位是帮分析师做信息收集和整理的前期工作。两个项目放在一起看，AI 正在从金融行业的辅助工具，变成可以独立承担部分专业工作的参与者。
