### 1. [Apple Intelligence 在中国"误上线"又被撤回](https://m.okjike.com/originalPosts/69cb27843ab5165bbaf6cc4d)
昨晚苹果突然在中国推送了 Apple Intelligence，结果早上彭博记者 Mark Gurman 说这是个失误——功能早就准备好了，但监管审批还没过。苹果火速下线，但很多用户发现升级到 iOS 26.4 后依然能装上，而且功能没被关。这波操作像极了"不小心按了发布键"，但对想尝鲜的人来说，窗口期可能不长。

### 2. [微软开源语音 AI 模型 VibeVoice，已获 27K Star](https://x.com/dotey/status/2038496784880689200)
微软一口气开源了三个语音模型：ASR（语音转文字，能处理 60 分钟长音频）、TTS（文本转语音，支持 90 分钟生成和 4 个说话人）、Realtime TTS（实时语音，延迟约 300 毫秒）。有人用 ASR 做了个语音输入法 Vibing，macOS 和 Windows 都能用。识别速度和准确率实测还行，开源社区又多了个能打的语音工具。

### 3. [CLI 突然成了 AI 时代的新宠](https://m.okjike.com/originalPosts/69c9ea139f3cd84f65874b26)
企业微信都做了 MCP，飞书、钉钉也在跟进 CLI。原因很简单：GUI 是给人看的，AI 没眼睛，CLI 才是它的原生世界。Karpathy 最近写文章吐槽，用 AI 做 app 大部分时间不是在写代码，而是在浏览器标签之间跳来跳去配 API Key。他的结论很直接："你的服务应该有一个 CLI 工具，直接赋能开发者的 AI。"AI 的实际能力 = 它能调用的工具 + 它拿到的上下文。装了飞书 CLI，AI 能查日程发消息；没装？"不好意思，这个我做不了。"

![图片](https://cdnv2.ruguoapp.com/Fod7p0kaiZGsTUghnKFJ3vNvxuZDv3.png?imageMogr2/meta-keep-list/ZXhpZixVc2VyQ29tbWVudA==/auto-orient)

### 4. [Gemini Live 升级到 Gemini 3.1 Flash Live](https://x.com/GeminiApp/status/2038647896300826853)
Google 的 Gemini Live 现在用上了 Gemini 3.1 Flash Live 模型。虽然官方没详细说升级了啥，但从命名看应该是响应速度和实时性上有提升。对语音交互重度用户来说，这种"无感升级"可能比大张旗鼓发布会更实在——打开就能用上更快的模型。

### 5. [Anthropic 科学家：LLM 已能自主挖掘漏洞](https://x.com/Gorden_Sun/status/2038611805220868152)
Anthropic 科学家 Nicholas Carlini 在演讲中透露，下一代模型（可能是 Mythos）已经能自主发现和利用漏洞。他本人用模型发现了大量 Linux 内核漏洞，多到没时间一一验证。演讲中提到两个案例：在 5 万 Star 的开源项目 Ghost 中发现未授权 SQL 注入，还能自己写攻击脚本提取管理员凭证；在 Linux 内核 NFSv4 守护进程中发现了一个自 2003 年起就存在的远程堆缓冲区溢出漏洞。这意味着 AI 不只是写代码的助手，也可能成为安全攻防的新变量。

### 6. [开源项目"同事.Skill"：把同事蒸馏成 AI](https://x.com/Gorden_Sun/status/2038607975804514442)
这个项目能把同事的技能和性格蒸馏成 AI Skill，让它替他工作。有人建议改名叫"同事 Kill"——成为 Skill 后就可以 Kill 掉了。虽然听起来像个玩笑，但背后的逻辑很真实：如果一个人的工作流程足够标准化，AI 确实能学会并替代。这个项目更像是对"AI 会取代哪些工作"的一次黑色幽默式回答。

### 7. [著名 iOS 开发者开源"Review Swarm"代码审查 Skill](https://x.com/dotey/status/2038435973156024717)
刚加入 OpenAI Codex 的 iOS/macOS 开发者 Thomas Ricouard 开源了一个多 Agent 并行审查工作流 Skill。它能在代码变更中发现四类风险：行为回归、安全隐私、性能可靠性、契约与测试覆盖。工作流分五步：确定审查范围、启动四个只读审查 Agent（并行）、汇总风险清单、生成审查报告、输出建议。这种"AI 帮你做 Code Review"的工具，可能会让很多开发者松一口气。

![图片](https://pbs.twimg.com/media/HEnx48vbgAAbIhO?format=jpg&#x26;name=orig)

### 8. [Mac Mini 当服务器，用屏幕共享就能搞定](https://x.com/dotey/status/2038441251037434192)
最近不少人因为 OpenClaw（龙虾🦞）入手了 Mac Mini 当服务器，但专门配显示器又占地方又浪费钱。其实 macOS 自带的"屏幕共享"功能就能解决——用你现有的 Mac 直接远程操控 Mac Mini，就像坐在它面前一样。设置方法很简单：在 Mac Mini 上打开"屏幕共享"，在日常用的 Mac 上打开 Screen Sharing App，输入 IP 地址或主机名，连上就行。连接时可以选"高性能"模式（需要 Apple 芯片 + macOS Sonoma 14 以上），画面更流畅。

![图片](https://pbs.twimg.com/media/HEn_B93XAAAVOxj?format=jpg&#x26;name=orig)

### 10. [CLI 不是基础设施，只是接口](https://x.com/dotey/status/2038496881135779917)
有人泼了盆冷水：每一轮 AI 叙事，都会把接口误当成基础设施。MCP 是一次，CLI 现在是第二次。真正的基础设施，从来都在接口下面那层。Google、飞书、钉钉做 CLI，是因为他们必须给 agent 一个可控的入口，但 CLI 本身撑不起生态。对绝大多数公司和人来说，盯着 Agent 构建生产力就可以了，接口只能改变接入体验，Agent 才能决定生产力。
