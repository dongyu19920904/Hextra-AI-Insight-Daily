### 9. [SpotIt+：用“找反例”的方式评测 Text-to-SQL](https://arxiv.org/abs/2603.04334)
很多 SQL 评测像老师对答案，结果两个查询长得不一样，却可能都能跑；更麻烦的是，错也不一定马上看出来。SpotIt+ 的思路很硬核：不给你靠运气过关，它主动去找能区分正确 SQL 和生成 SQL 的数据库反例。对做企业数据问答、BI Copilot 的团队来说，这种工具很实际，因为它能帮你更早抓住“表面答对、实际乱来”的坑。

### 10. [When Simulation Lies：工具调用 Agent 的“仿真高分、上线翻车”基准来了](https://arxiv.org/abs/2605.11928)
实验室里的 Agent 很能打，一到真实环境就像新人第一天上班：接口超时、工具重名、用户打错字，立刻卡住。这篇论文抓的就是这个尴尬，它专门做了 sim-to-real 基准，研究工具调用 Agent 在脏环境里怎么翻车。新意不在“再造一个更强 Agent”，而是提醒大家：未来真正分胜负的，是谁能扛住现实世界的混乱。
