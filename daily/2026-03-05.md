### 1. [GPT-5.4 即将发布：百万上下文窗口 + 极限推理模式](https://x.com/op7418/status/2029220155163853064)

你现在用Codex-5.3 写代码，塞进去一个大项目就得小心翼翼地裁上下文，生怕模型"忘了"前面写的东西。GPT-5.4 直接把上下文窗口拉到百万级别——整个代码仓库一次性喂进去，它都能记住。更狠的是新增的"极限推理模式"，允许模型花更长时间深度思考复杂任务。简单说：以前它是个聪明但记性一般的助手，现在变成了既聪明又过目不忘的全栈工程师。等等党，这次又赢了。

### 2. [Anthropic CEO硬刚白宫：直接把 OpenAI 五角大楼合同称为"安全剧场"](https://x.com/dotey/status/2029330655633363452)

AI圈的宫斗剧又上新了。Anthropic CEO 达里奥·阿莫迪在内部备忘录里直接开炮——点名 OpenAI 总裁布罗克曼夫妇给特朗普超级 PAC捐了 2500 万美元，而Anthropic 一分没捐，也没给过"独裁者式吹捧"。最辛辣的一刀？他把 OpenAI 刚拿到的五角大楼合同的安全保障叫"safety theater"（安全剧场），意思就是：演给外界看的，没实质。这种级别的互撕，在硅谷可不多见。AI 安全到底是信仰还是生意？这封备忘录撕开了一道口子。

### 3. [OpenAI Codex App 正式登陆 Windows，附带原生安全沙箱](https://x.com/dotey/status/2029308744795082981)

Windows 开发者等这一天等了不少时间。Codex App 终于原生支持 Windows，PowerShell、命令提示符、Git Bash、WSL 全部兼容。但真正值得关注的是安全设计：它在操作系统层面构建了一套沙箱机制，AI 只能在你指定的目录里写文件，默认断网，除非你手动放行。以前总担心 AI 编码助手权限太大、偷偷搞事情？这套设计直接在系统层面把笼子焊死了。而且整套沙箱实现已经开源，Rust 写的，代码就在 GitHub 上。开发者狂喜。

![图片](https://pbs.twimg.com/media/HClY67cbkAAe5xr?format=jpg&name=orig)

### 4. [OpenAI 开源Codex Windows 原生沙箱安全架构](https://www.bestblogs.dev/status/2029252477179314350)

承接上条，单独说说这个开源动作。OpenAI 这次不只是发了个产品，而是把底层安全架构的实现直接扔到了 GitHub。核心技术包括受限令牌、文件系统访问控制列表（ACL）和专用沙箱用户——都是 Windows 操作系统原生的安全能力。用人话说：它不是自己造了一个虚拟环境，而是直接借用 Windows 本身的安全机制来关AI 的"小黑屋"。对安全研究者和想做 Agent 的开发者来说，这是一份可以直接参考的工业级蓝图，AI 评分92，质量相当能打。

### 5. [苹果发布 MacBook Neo：4599 起售，用的竟然是手机芯片 A18](https://x.com/op7418/status/2029201057977704960)

苹果转性了？新发的 MacBook Neo 起售价 4599，最炸裂的是 256G 内存升级只加 700 块——要知道现在内存价格飞涨，这个定价简直反常。不过有个小细节：它用的是手机端的 A18 芯片，不是 M系列。性能天花板肯定有限，但考虑到最近 Mac Mini 被OpenClaw搞到全网断货，苹果急需一个平价入口来吃这波AI 本地部署的红利。颜色倒是挺好看的。钱包准备好了吗？

### 6. [MCP 协议一年多了还没死，Agent Skills 成为核心基础设施](https://x.com/dotey/status/2029277201250631784)

有人说 MCP 这种协议活不过半年。结果呢？一年多了，活得好好的，而且 Agent Skills 已经成了所有 Agent 框架的核心基础。OpenClaw 为什么强大？不是因为某个单一模型多厉害，而是因为它背后挂着一堆 Skills 可以随时调用。规范可能会迭代升级，但这套"给AI 装技能包"的思路，大概率会存在很久。还在观望要不要学MCP 的朋友，别再等了，这条路已经被验证过了。

### 7. [Codepilot 四小时内同时接入飞书和 Discord，架构的力量](https://x.com/op7418/status/2029220817704501457)
