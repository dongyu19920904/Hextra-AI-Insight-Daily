## **🔥 重磅 TOP 10**

### 1. [Claude Code 复合工程插件正式开源](https://github.com/EveryInc/compound-engineering-plugin)

以前用 Claude Code 写代码，遇到复杂工程项目就得来回切换、手动拆分任务。现在官方直接放出了"复合工程插件"——一个项目里多个模块并行开发，Claude帮你自动协调依赖关系。5400+ Star说明开发者是真的等这东西等很久了。Python 写的，拿来就能用，不用再自己造轮子了。

![图片](https://images.weserv.nl/?url=https%3A%2F%2Fopengraph.githubassets.com%2F33c5641faa027b3cd06a53012a4ebbad3616c1b0429133ba5f7ccfdb5dd4a4fe%2FEveryInc%2Fcompound-engineering-plugin)

---

### 2. [tambo：React 生成式 UI SDK来了](https://github.com/tambo-ai/tambo)

做前端的朋友有福了。tambo 这个 SDK 让你用几行代码就能在 React 项目里接入生成式 UI——用户输入一句话，界面自动生成。不是那种半成品 demo，是真的能用在生产环境的东西。TypeScript 写的，3000 Star，文档也挺全。以后做 AI 产品原型，速度能快一倍不止。

![图片](https://images.weserv.nl/?url=https%3A%2F%2Fopengraph.githubassets.com%2F5360f4f175c69bceb93e10d7a35beec82b899bd6b948996bd3c64142ce47771c%2Ftambo-ai%2Ftambo)

---

### 3. [微软 Agent Lightning：给 AI Agent 的"健身教练"](https://github.com/microsoft/agent-lightning)

训练 AI Agent 一直是个玄学活，效果好不好全靠调参运气。微软这次开源的 Agent Lightning 相当于给 Agent 配了个专业教练——标准化的训练流程、可复现的评估指标、1.1 万Star 的社区验证。想做 Agent 产品的团队，这东西能省掉至少一个月的踩坑时间。

---

### 4. [PageIndex：不用向量库的 RAG 新思路](https://github.com/VectifyAI/PageIndex)

RAG 现在几乎是标配了，但向量检索那套东西部署起来还是挺重的。PageIndex 换了个思路：直接基于文档结构做推理式索引，不需要向量数据库。6000 Star，适合那些文档量不算巨大但对延迟敏感的场景。我试了下，响应确实快，但复杂查询还是得看场景。

---

### 5. [Claude Code 多窗口工作流分享](https://x.com/op7418/status/2013896350648410441)

有人晒出了自己用 Claude Code 开多窗口干活的日常——左边写后端，右边调前端，中间还开着测试窗口。这种工作方式正在成为 AI 辅助编程的新常态。不是炫技，是真的提效。评论区一堆人问配置，看来大家都想试试。

![图片](https://images.weserv.nl/?url=https%3A%2F%2Fpbs.twimg.com%2Fmedia%2FG_LL8EiWEAA8f3S%3Fformat%3Djpg%26name%3Dorig)

---

### 6. [Grok-1 开源持续火热](https://github.com/xai-org/grok-1)

xAI 的 Grok-1 开源后热度不减，Star 数已经突破 5万。虽然是老消息了，但最近社区基于它做的微调版本越来越多。有人拿它做中文对话，有人拿它做代码补全，生态正在慢慢成型。对大模型开源生态感兴趣的，可以关注下 fork榜单。

![图片](https://images.weserv.nl/?url=https%3A%2F%2Favatars.githubusercontent.com%2Fu%2F130314967%3Fs%3D400%26v%3D4)

---

### 7. [X 推荐算法源码依然值得一读](https://github.com/twitter/the-algorithm)

X（原Twitter）开源的推荐算法源码已经 7 万+ Star 了。虽然发布有一段时间，但最近又被翻出来研究——主要是大家想看看怎么把大模型和传统推荐系统结合。做推荐系统或者信息流产品的，这份代码是难得的工业级参考。

---

### 8. [HAVEN：长视频理解的新框架](https://arxiv.org/abs/2601.13719)

看一部两小时的电影，让AI 总结剧情、追踪角色关系，以前的模型经常前后矛盾。HAVEN 这篇论文提出了"音视频实体聚合+层级索引"的方案，在LVBench 上跑出 84.1% 的准确率。学术味重了点，但做视频类 AI 产品的可以关注下思路。

---

### 9. [微软数据科学入门课程](https://github.com/microsoft/Data-Science-For-Beginners)

10 周、20 节课、完全免费。微软这套数据科学入门课程用Jupyter Notebook 写的，3.2 万 Star 说明质量经得起检验。适合想转行或者想补基础的朋友，比市面上很多付费课程实在多了。

![图片](https://images.weserv.nl/?url=https%3A%2F%2Frepository-images.githubusercontent.com%2F344191198%2F8ccb9f17-6cae-4511-ac05-63ab9251c10b)

---

### 10. [票据风格提示词终于来了](https://x.com/op7418/status/2013921013927420186)

之前很多人问怎么用AI 生成那种复古票据风格的图片，现在歸藏直接放出了提示词模板，还做了个批量生成小红书配图的 Skill。做内容运营的应该会很需要这个，省得每次都要从零开始调。
